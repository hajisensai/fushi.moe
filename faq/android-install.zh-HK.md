Fushi 的安卓版不在應用商店裡，直接從[下載頁](/zh-hk/download)下載 APK 安裝。最低要求 **Android 7.0（API 24）**，比這更老的系統裝不上。

## APK 該下哪一個？

下載頁「正式版」下面有三行安卓包，區別只在 CPU 架構：

| 下載頁那一行 | 檔名結尾 | 適合誰 |
|---|---|---|
| Android (arm64) | `-arm64-v8a.apk` | 絕大多數手機選這個，需 Android 7.0+ |
| Android (arm32) | `-armeabi-v7a.apk` | 較老的 32 位機型 |
| Android (x86_64) | `-x86_64.apk` | 模擬器 / x86 平板 |

拿不準就選 **arm64**：近幾年的手機、平板、大部分電子墨水閱讀器都是 64 位 ARM。只有它裝不上（系統提示與裝置不相容、解析包出錯之類）時，再換 arm32 試試。在電腦上用安卓模擬器跑 Fushi 的，選 x86_64。

切到「除錯版」後，安卓只剩**一行 arm64 包**（檔名結尾 `-debug.apk`），不用再挑；32 位老機型和 x86 模擬器裝不了除錯版，請用正式版對應的包。正式版和除錯版的區別見[正式版和除錯版有什麼區別？](/faq/channels.zh-HK)。

## 安裝步驟

1. 用手機瀏覽器開啟[下載頁](/zh-hk/download)，點對應那一行的「下載」。下載頁會分段併發拉取並做 SHA-256 校驗，看到「SHA-256 校驗通過」說明檔案完整。網路慢可以改用旁邊的「GitHub 直鏈」，見[下載很慢或者打不開怎麼辦？](/faq/download.zh-HK)。也可以在電腦上下載好，再傳到手機裡。
2. 點開下載好的 APK。第一次從瀏覽器或檔案管理器裝應用時，系統會要求允許它「安裝未知應用」，按提示去開啟，再回來點安裝。各家系統措辭不同，有的還會額外彈一次安全掃描，選繼續安裝即可。
3. 裝好後開啟 Fushi，第一次啟動會進入新手引導：選介面語言和主題、勾選要用的功能、下載推薦包、連線 AnkiDroid。詳見[新手引導中途關掉了，怎麼重新開啟？](/faq/onboarding.zh-HK)。

推薦包（日語詞典 + 日 / 英發音音訊庫）約 9.5 GB，在手機上下載前先確認儲存空間夠、最好連著 Wi-Fi。只學別的語言可以跳過，自己匯入詞典，見[只能學日語嗎？](/faq/languages.zh-HK)。

## 安卓上怎麼更新？

不用每次回下載頁手動下載。Fushi 會自己檢查新版本，**設定 → 系統與關於** 的「更新設定」裡有：

- **更新通道**：穩定版 / 測試版 / 除錯版。
- **首選下載源**：自動（推薦）/ Cloudflare 映象 / GitHub 直連，所選來源不可用時會自動回退。
- **檢查更新**：手動立刻檢查一次；「檢視更新日誌」可以看各版本改了什麼。
- **自動安裝更新**：開啟後發現新版會自動下載並拉起安裝。

應用內更新會**按你手機的架構自動挑包**：裝的是 arm64 就繼續拿 arm64，不會給你下錯。第一次走應用內更新時，系統會彈「允許安裝更新」——這是安卓要求每個能裝 APK 的應用單獨授權，去系統設定裡允許 Fushi 安裝應用，回來點「重試安裝」就行。

## 平板和墨水屏閱讀器能用嗎？

能。安卓平板裝的是同一個 APK，介面會按螢幕寬度自動排版，橫屏看番、分欄讀書都沒問題；接上鍵盤或手柄也能操作，大部分頁面可以用方向鍵和確認鍵走完。

用文石、掌閱這類安卓系統的電子墨水閱讀器讀輕小說、看漫畫時，到 **設定 → 外觀與互動 → 介面** 開啟「墨水屏模式」：它會換成純黑白主題、關掉動畫、把高亮改成線式，減少墨水屏重新整理時的殘影。查詞設定裡還有一項「查詞彈窗瞬時滾動」，配合起來重新整理會少很多。這類裝置大多也是 64 位 ARM，下 arm64 包即可；少數老款是 32 位，裝不上時換 arm32。

## 常見問題和坑

- **正式版和除錯版不能同時裝**。兩者是同一個應用（同一個包名），裝除錯版會直接覆蓋正式版、資料接著用，反過來也一樣。
- **從新版退回舊版會裝不上**。安卓不允許用版本號更低的包覆蓋安裝，所以從較新的除錯版退回較早的正式版，系統會拒絕。這時只能先在 **設定 → 同步與備份** 匯出備份，解除安裝後裝舊版，再匯入備份。換通道前先匯出一份備份，就是為了這一刻。
- **解除安裝會刪掉資料**。安卓上 Fushi 的資料庫（閱讀進度、學習記錄、設定）、匯入進來的詞典和書都放在應用自己的儲存空間裡，解除安裝即清空；只有你直接從手機儲存裡引用的影片這類原檔案還留在原處。解除安裝前務必先備份，或者開好雲備份 / [互聯備份](/faq/interconnect.zh-HK)。
- **AnkiDroid 制卡**：安卓上制卡連的是 AnkiDroid，先從應用商店裝好 AnkiDroid，再在引導或 **設定 → 制卡** 裡連線，見[怎麼連線 Anki？](/faq/anki.zh-HK)。
- **桌面才有的功能**：Galgame 文本 / 語音捕獲只在 Windows 上，手機上可以用[遊戲串流](/faq/game-streaming.zh-HK)玩電腦裡的遊戲；書庫很大、不想在手機上重複匯入的，讓電腦當 [Fushi 互聯](/faq/interconnect.zh-HK)主機，手機直接瀏覽、拉流。
