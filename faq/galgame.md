Galgame 是几乎完美的沉浸材料：有声音、有画面、有文本，而且文本是逐句给的。以前要 Textractor + Yomitan + ShareX / GSM 四五个工具串起来，Fushi 把这条链收进了一个模块（**仅 Windows**）。

## 第 1 步：把游戏加进来

底栏 **游戏** → **添加游戏**，选游戏的 exe；或者把 exe 直接拖进游戏库。加进来的游戏会自动找封面（游戏目录 / 程序图标），也可以 **刮削元数据**，从 VNDB / Bangumi 拉简介和封面（见[刮削](/faq/scraping)）。

## 第 2 步：启动并捕获

点 **启动并捕获**：Fushi 拉起游戏，把自己的 hook 组件注入进去，开始收台词。游戏已经开着的话用 **附着并捕获**。

启动时 Fushi 顺手做两件事：

- **日语区域**：判断这个游戏需不需要转区（目录 / 程序里的 Shift-JIS 证据），需要就自动用内置的 Locale Emulator 以日文区域启动——只支持 32 位游戏。文字乱码或脚本报错，可以在游戏设置里把「日语区域」改成始终 / 永不。
- **窗口超分**：老游戏原生分辨率低，可以在游戏设置里把「窗口超分」设为 **自动**，Fushi 用内置的 Magpie 把窗口放大到全屏（机器上已经在跑 Magpie 就用你的）。没自动放大时按 **Win+Shift+A**。会占显卡，每个游戏各自设。

## 第 3 步：选台词线程

大多数引擎第一次会抓到好几条**文本线程**（台词、人名、系统提示、逐字重复的伪影……），会话面板里**选那条干净的台词线程**，捕获才正式开始。标着「N 行有音频」的通常就是对白线程；标「伪影」的不用管。

引擎不认（注入后超时没文本）的游戏，可以粘贴 **特殊码**（Textractor 那种 `/HQN4@4CE90:game.exe` 的 H-code，社区里一般能找到；会绑定到这个 exe，下次自动复用）。特殊码也没有的，就是引擎还没适配，等更新。

## 第 4 步：在浮窗里读、查、制卡

台词出现在 **台词浮窗** 里，浮在游戏窗口上：

- **点字查词**，和阅读器一样弹词典；
- **加号制卡**：卡上带这句台词、**这句的原声**、当时的截图，直接进 Anki；
- 浮窗按钮：跟随新台词 / 锁定位置 / 保持置顶 / 鼠标穿透到游戏 / 切换底板（透明成桌面歌词式）/ 重播本句语音 / 重新录制语音（漏录了在游戏里重播一次）/ 打开 **取材工作台**（回看本局所有台词，挑句制卡）；
- 字体、字号、颜色、描边、背景透明度都在 **设置 → Galgame 台词浮窗** 里。

再进一步是 **游戏内查词**：不看浮窗，直接点游戏画面里的字查词。**KiriKiri（krkr）和 SiglusEngine 的大部分游戏能直接用**，其他引擎要等适配。有的游戏需要先校准一次正文区域（在游戏里依次点三个探针字形），另外裸左击可能同时推进台词或触发选项，Fushi 会先让你确认风险、并且只对当前这个 exe 生效。会话面板的「游戏内查词」里能看到当前引擎的状态。

## 语音是怎么来的

制卡的句子音频优先取游戏自己的语音（游戏资源文件或引擎的播放缓冲，干净、不带 BGM），这两条路都走不通时才录系统混音兜底。没配音的句子照常制卡，只是不带音频。

## 健康状态

会话面板的 **健康状态** 一眼看出哪一环没接上：游戏进程 / 游戏窗口 / 文本来源 / 音频来源 / Hook Helper / 窗口超分 / Anki 出卡。哪项红了就点开看原因。

## 常见状况

- **注入被拦截 / 组件没回应**：把 Fushi 和游戏加进杀毒软件白名单，检查隔离区。
- **游戏以更高权限运行**：以管理员身份启动 Fushi 再启动游戏。
- **组件位数不匹配 / 版本不一致**：完全关掉游戏再开；还不行就重跑一次 Fushi 安装程序（上次更新时游戏开着，组件文件没换掉）。
- **注入了但没文本**：引擎还没支持，试特殊码（上面第 3 步），没有就等适配。
- **文字乱码**：日语区域改成「始终开启」；64 位游戏不能转区，装个系统级的日文区域。
- **还残留上一次的捕获会话**：重启一次游戏。
- **窗口还没出现，暂时无法截图**：正常，窗口出现后自动绑定。
