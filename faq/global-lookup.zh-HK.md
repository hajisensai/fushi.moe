可以。Fushi 的詞典不只在它自己的閱讀器和播放器裡用：開著 Fushi 的時候，你在瀏覽器、PDF 閱讀器、聊天軟體、遊戲、任何能選中文字的程式裡，都能直接查詞，而且彈出來的是和 app 內一模一樣的查詞卡片——同一套詞典、同樣的音調和詞頻、同樣的加號制卡。

先說平臺：

| 平臺 | 有什麼 |
|---|---|
| **Windows** | 全域性查詞快捷鍵、應用外懸浮球（剪貼簿查詞 / 截圖識字）、瀏覽器擴充套件 |
| **macOS** | 同 Windows（第一次要授權「輔助功能」） |
| **Linux** | 暫無應用外查詞卡片和應用外懸浮球；網頁可以用瀏覽器擴充套件 |
| **Android** | 系統文字選單 / 分享查詞、應用外懸浮球 |
| **iOS** | 系統不允許應用在別的 app 上面彈窗，沒有應用外查詞；在 Fushi 裡貼上到查詞頁查 |

## Windows / macOS：選中文字，按快捷鍵

1. 在任意程式裡**拖選一個詞**，保持選中。
2. 按 **Ctrl+Alt+D**（macOS 上是 **⌘⌥D**）。
3. Fushi 抓取選區，在**滑鼠旁邊**開啟查詞卡片。

幾個關鍵點：

- **卡片不搶焦點**：它浮在當前程式上面，但你正在用的程式仍然是前臺視窗，鍵盤輸入、遊戲操作不受影響。按 Esc 或點卡片外面就收起。
- **再按一次 = 查新的選區**：選中另一個詞再按快捷鍵，卡片直接換成新詞，不用先關。
- **卡片裡能繼續查**：釋義裡的詞點一下，會在旁邊彈出下一層卡片，可以一層層往下查（巢狀查詞），和 app 內彈窗一樣，見[查詞彈窗怎麼用](/faq/lookup-popup.zh-HK)。
- **能聽、能制卡**：喇叭播單詞發音，加號直接做 Anki 卡；詞已經在 Anki 裡時 ✓ 會讓你選覆寫、在 Anki 中開啟或新增為重複卡。
- **Fushi 要開著**：查詞用的是 Fushi 主程式裡的詞典，Fushi 退出了快捷鍵就沒了。最小化、放在後臺都行。

### 改快捷鍵、用滑鼠側鍵或手柄

**設定 → 快捷鍵設定 → 全域性（應用外）** 裡有兩條：

- **應用外查詞快捷鍵**：就是上面這個動作，預設 Ctrl+Alt+D。可以改成別的組合鍵；也可以綁**滑鼠側鍵**（後退 / 前進）——滑鼠觸發只接受側鍵，其它按鈕在別的程式裡有各自的固有含義，會被拒絕錄入。手柄按鈕也能綁（預設不綁，因為它會優先於頁面裡的手柄操作）。
- **喚起主窗並開啟查詞頁**：預設 Ctrl+Alt+F。不抓任何選區，只是把 Fushi 主窗喚到前臺、落在查詞頁上，讓你自己輸入或貼上。

新手引導裡也有一步「全域性查詞」，演示這套操作並顯示你當前繫結的鍵。

### 把整句也帶上：抓取選中文本上下文

預設情況下，快捷鍵只拿到你選中的那幾個字（Fushi 會模擬一次複製來讀選區）。**設定 → 查詞 → 查詞觸發** 裡的「**抓取選中文本上下文**」開啟後，Fushi 還會從前臺應用讀取選區周圍的文本，在查詞卡片裡顯示當前句，制卡時這句會作為例句進卡（Windows / macOS）。

這個開關預設關：它會讀取別的程式窗口裡的文字，屬於隱私敏感功能，需要時再開。讀不到上下文的程式（不提供無障礙文本介面的）會自動退回只查選中的詞。

### macOS：先授權「輔助功能」

macOS 需要輔助功能許可權才能讀取其他應用中選中的文字；未授權時快捷鍵只查當前剪貼簿文本。第一次按快捷鍵時 Fushi 會請求授權，也可以在 **設定 → 查詞 → 查詞觸發** 點「**為應用外查詞授權輔助功能**」。授權路徑是系統設定的「隱私與安全性 > 輔助功能」，啟用 Fushi 後再按一次快捷鍵即可。

### 截圖、錄屏、直播時不想拍到查詞卡

**設定 → 查詞 → 彈窗視窗** 裡的「**防截圖 / 防錄屏**」會把查詞懸浮窗從截圖、錄屏、直播串流中排除（Windows / macOS）。預設關，也就是預設截圖能拍到卡片；直播或錄教程時不想讓觀眾看到查詞過程就開啟它。

## 應用外懸浮球：剪貼簿查詞、截圖識字

有些地方選不了文字，或者你更習慣點按鈕。**設定 → 懸浮球** 裡開啟「**應用外顯示**」，切到其他程式後懸浮球仍浮在最上層。展開後可以放這些按鈕：

- **應用外查詞**：查前臺程式當前選中的文字，和快捷鍵是同一件事。
- **剪貼簿查詞**：讀剪貼簿裡的文字，在懸浮球旁彈出查詞卡片。適合「先複製、再查」的場景——比如 Textractor 之類的工具把遊戲臺詞自動複製到剪貼簿時，點一下球就查。
- **截圖識字**：截下懸浮球所在的顯示器，用系統自帶的文字識別找出畫面上的文字，蓋一層凍結畫面讓你**直接點字查詞**。圖片裡的字、遊戲畫面、影片截圖、不能選中的介面文字都能這樣查。
- **查詞**：把 Fushi 喚到前臺並開啟查詞頁。
- **開啟 Fushi**、立即同步等。

前三個查詞按鈕需要「查詞」模組開著（**設定 → 外觀與互動 → 功能模組**）。懸浮球的按鈕可以按場景分別勾選（閱讀器、漫畫、影片、其它頁面、應用外）。

注意 Fushi **不會在後臺自動監聽剪貼簿**：只有你點「剪貼簿查詞」時它才讀一次剪貼簿。想要「每複製一句就自動顯示」的遊戲查詞體驗，用下面說的文本鉤子。

## Android：文字選單和懸浮球

Android 通過文字選單或分享面板把選中文本交給 Fushi：

1. 在其他應用裡**長按一個詞**，拖動手柄覆蓋它。
2. 在彈出的文字選單裡點 **Fushi**；沒有就點「分享」，再選 Fushi。
3. 查詞彈窗蓋在原應用上，關掉就回去。彈窗裡同樣能巢狀查詞、聽發音、制卡。

Android 也有應用外懸浮球：在 **設定 → 懸浮球** 開啟「應用外顯示」，需要授予「顯示在其他應用上層」許可權，懸浮球才能系統常駐。安卓的懸浮球上有「應用外查詞」（不進主窗，直接彈一個帶搜尋欄的查詞窗）、「剪貼簿查詞」、「截圖識字」和「拍照查詞」（拍紙質書、招牌、別的裝置的螢幕再點字查詞）。

## 瀏覽器、遊戲、其他工具

- **網頁**：任意網頁上按住 Shift 移到詞上就查，用的是 Fushi 的瀏覽器擴充套件（電腦上的 Chrome、Edge 這類 Chromium 瀏覽器），安裝步驟見[瀏覽器裡怎麼查詞](/faq/browser-lookup.zh-HK)。它和全域性查詞共用同一套詞典，網頁上用擴充套件比用快捷鍵更順手。
- **Galgame**：Windows 上 Fushi 能直接 Hook 遊戲臺詞，在浮窗裡逐詞點查、制卡，見[Galgame 怎麼接進 Fushi](/faq/galgame.zh-HK)。
- **Textractor / LunaTranslator / mpv 等抓文本工具**：**設定 → 查詞 → 外部整合** 裡的「文本鉤子（接收文本）」連它們的 WebSocket，臺詞推進 Fushi 後逐詞點查。
- **GameSentenceMiner 等走 yomitan-api 協議的工具**：開「Fushi API 伺服器」，讓它們改查 Fushi 的詞典。
- **Anki 卡片裡的詞典交叉引用**：Fushi 制卡時會把釋義裡的詞典內部連結改寫成 `fushi://lookup` 連結，在 Windows 和 Android 上點它會開啟 Fushi 查這個詞。

## 常見狀況

- **按了快捷鍵沒反應**：確認 Fushi 在執行、「查詞」模組沒關；快捷鍵可能和別的軟體衝突，到 設定 → 快捷鍵設定 → 全域性（應用外） 換一個組合。
- **查到的是別的詞 / 上一次複製的內容**：有的程式不響應模擬複製，選區沒被抓到。換個程式試試，或者用懸浮球的「剪貼簿查詞」：先手動複製再查。
- **macOS 上只能查剪貼簿**：沒授權輔助功能，見上文。
- **卡片裡沒有例句**：「抓取選中文本上下文」預設是關的；開了之後仍沒有，說明那個程式不提供周圍文本。
- **截圖識字認不出字**：系統文字識別對小字、藝術字、低對比度畫面效果有限；能選中的文字優先用快捷鍵。
- **Linux 上沒有快捷鍵查詞和懸浮球**：目前 Linux 只有 app 內查詞和瀏覽器擴充套件，各平臺差異見[各平臺都支援什麼](/faq/platforms.zh-HK)。
