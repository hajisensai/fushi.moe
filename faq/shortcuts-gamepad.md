支持。Fushi 的快捷键是一张统一的注册表：键盘、手柄、鼠标按键、鼠标滚轮四种输入都能绑定到同一个动作上，绝大多数动作都能改键。典型用法是坐在电脑前用键盘翻页、查词；或者把电脑接到电视上、拿着手柄躺在沙发上看番和读书。

## 在哪里改键

**设置 → 系统与关于 → 通用 → 快捷键设置**。

页面按作用域分组：**返回·退出**、**全局**、**全局（应用外）**、**首页**、**阅读器**、**有声书**、**漫画**、**视频**、**手柄**、**查词弹窗**。每个动作后面列着它当前的键盘、手柄、鼠标绑定，点一下就进入录键（「请按下快捷键组合...」，Esc 取消）。

几个好用的功能：

- **搜索**：顶部搜索框按动作名或按键搜（「搜索动作或按键」）。
- **按键反查**：按下一个键或手柄按钮，列出「绑定了这个键的动作」——不知道某个键为什么没反应时先查它。
- **冲突处理**：新键已经被别的动作占用时，会提示「已被占用」，可以选 **替换**（移到当前动作）、**交换**，或 **两者都保留**（同时生效时按作用域先后仲裁）。
- **手柄可视化图**：除了列表视图，还可以切到「手柄可视化图」，直接在手柄示意图上看每个键做什么；「手柄按钮样式」可以选 Xbox、PlayStation 或 Nintendo Switch 的按键标识。
- **恢复默认**：可以按分组恢复，也可以「全部恢复默认」。改过的动作会标「已自定义」。

**macOS** 上默认键位里的 Ctrl 自动换成 Cmd；几个会被系统截走的键换成了空闲的同义键：有声书播放 / 暂停是 Option+Space，窗口全屏是 Ctrl+Cmd+F。

## 常用默认键位（桌面）

### 阅读器（EPUB / 轻小说）

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 下一页 | PageDown / → / ↓ / Space | RB、十字键右 |
| 上一页 | PageUp / ← / ↑ / Shift+Space | LB、十字键左 |
| 显示/隐藏控制栏 | M | Y |
| 进入选字查词光标 / 查词 | Enter | A |
| 从弹窗制卡 | Ctrl+Enter | — |
| 打开设置菜单 | T | — |
| 打开导航（目录） | Ctrl+F | — |
| 打开插图画廊 | G | — |
| 打开阅读统计 | I | — |
| 打开有声书面板 | B | — |
| 暂停 / 继续阅读计时 | P | — |
| 切换振假名 | — | R3（按下右摇杆） |

竖排从右往左翻的书（日文默认），← 是下一页、→ 是上一页，和书的翻页方向一致。

「选字查词光标」是给没有鼠标的情况准备的：按 Enter 或手柄 A 进入光标，用方向键把光标移到要查的词上，再确认就查词，不需要点屏幕。光标停在查词弹窗上时，`]` / `[` 跳下 / 上一本词典，`.` / `,` 跳下 / 上一个词条，手柄上是 RT / LT。

### 有声书（在阅读器里听书时）

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 播放/暂停 | Ctrl+Space（macOS 为 Option+Space） | L3（按下左摇杆） |
| 下一句 | Ctrl+→ | X |
| 上一句 | Ctrl+← | B |

有声书激活时，裸 Space 也从「翻页」改成「播放/暂停」，和一般播放器的习惯一致。注意这时手柄 B 归「上一句」，不再是返回——听书时要退出这本书，用键盘 Esc 或界面上的返回按钮。

### 漫画

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 下一页 / 上一页 | PageDown、→、↓、Space / PageUp、←、↑ | RB、十字键右 / LB、十字键左 |
| 切换漫画界面 | M | Y |
| 平移（放大后） | Ctrl+方向键 | — |

左右键会按漫画的翻页方向（日漫默认从右往左）自动校正。

### 视频

视频页的键位比较多，大体沿用 asbplayer 的习惯：Space / P 播放暂停，← / → 快退快进，Ctrl+← / Ctrl+→ 上一句 / 下一句字幕，R 重播当前句，F 全屏，L 字幕列表，B 字幕模糊，S 截图。手柄上 A 播放暂停、X / Y 上一句 / 下一句、LB / RB 快退快进、十字键上下调音量、RT 全屏、Start 打开字幕列表、Select 进入字幕选词光标、LT 重播当前句。完整列表见[看视频有哪些快捷键](/faq/video-shortcuts)。

### 首页与全局

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 返回上一级 | Esc / Alt+← | B |
| 书架标签 / 词典标签 / 设置标签 | Ctrl+1 / Ctrl+2 / Ctrl+3 | — |
| 上一个 / 下一个标签页 | — | LT / RT |
| 聚焦搜索 | Ctrl+F | Y |
| 向下 / 向上翻一屏 | PageDown / PageUp | RB / LB |
| 向下 / 向上滚动一行 | ↓ / ↑ | — |
| 滚动到顶部 / 底部 | Home / End | — |
| 全屏切换 | F11（macOS 为 Ctrl+Cmd+F） | — |

「返回上一级」只有这一个动作：在阅读器、漫画里有查词弹窗就先关弹窗，否则退出这本书；在视频里会逐级退出（先收起字幕列表、侧栏、全屏等，最后才退出页面）。改了它的键，所有页面一起生效。

### 查词弹窗

| 动作 | 默认 |
|---|---|
| 下一个 / 上一个词条 | Alt+滚轮下 / Alt+滚轮上；手柄十字键下 / 上 |
| 制卡（加号） | Ctrl+Enter；手柄 X |
| 播放单词发音 | 手柄 Y |

鼠标停在弹窗上就生效。裸滚轮永远留给弹窗内容滚动，所以滚轮绑定必须带修饰键。

### 应用外查词（Windows / macOS）

在任何程序里选中文字，按「应用外查词快捷键」（默认 Ctrl+Alt+D），查词卡片就在鼠标旁弹出；「唤起主窗并打开查词页」默认 Ctrl+Alt+F（macOS 上 Ctrl 同样换成 Cmd）。这一组的鼠标触发只接受侧键。手机上由系统触发（选中文本菜单、分享、悬浮球），不能自定义。详见[全局查词](/faq/global-lookup)。

## 焦点导航：完全不用鼠标

**设置 → 系统与关于 → 通用 → 键盘/手柄焦点导航**，默认关闭。打开后：

- 用方向键或手柄摇杆移动焦点，当前选中的控件有焦点环；
- **Enter 或手柄 A 确认**（点按钮、切开关）；Slider、分段选择这类控件用方向键调；
- 裸 Space 不会触发按钮——确认统一走 Enter / A，避免看书时误触；
- 文本框里按上 / 下可以跳出文本框；
- 返回统一是 Esc / Alt+← / 手柄 B。

不开焦点导航时，↑ / ↓ 照样能滚动页面，PageUp / PageDown 整页翻，只是没有焦点环。

## 各平台的手柄支持

- **Windows**：通过系统的 GameInput 组件读取手柄。快捷键设置里提示「未检测到 GameInput 组件，手柄功能不可用」时，安装 Windows 的「游戏服务（Gaming Services）」即可。
- **macOS / iOS**：使用系统的手柄框架，蓝牙配对后即可用。
- **Android**：系统把手柄按键当按键事件交给应用，连上蓝牙或 USB 手柄即可用。
- **Linux**（从源码构建）：通过系统输入设备读取。

手机和平板上，主屏的键盘快捷键默认不启用（只保留手柄），但阅读器、漫画、视频页和「返回上一级」的键盘绑定仍然有效——接上蓝牙键盘就能翻页和控制播放。

## 常见问题

- **按了没反应**：先用「按键反查」看这个键绑给了谁；同一个键在同一页上只会触发一个动作，排在前面的作用域会静默盖住后面的。
- **把 Esc 绑给了别的动作，退不出页面了**：页面专属键优先于「返回上一级」，这种覆盖不会出冲突提示。到快捷键设置里改回来，或「恢复默认」即可。
- **玩 Galgame**：游戏里查词制卡见 [Galgame 怎么查词制卡](/faq/galgame)；串流到手机上用触屏或手柄玩见[游戏串流](/faq/game-streaming)。
