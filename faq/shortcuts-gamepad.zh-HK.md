支援。Fushi 的快捷鍵是一張統一的登錄檔：鍵盤、手柄、滑鼠按鍵、滑鼠滾輪四種輸入都能繫結到同一個動作上，絕大多數動作都能改鍵。典型用法是坐在電腦前用鍵盤翻頁、查詞；或者把電腦接到電視上、拿著手柄躺在沙發上看番和讀書。

## 在哪裡改鍵

**設定 → 系統與關於 → 通用 → 快捷鍵設定**。

頁面按作用域分組：**返回·退出**、**全域性**、**全域性（應用外）**、**首頁**、**閱讀器**、**有聲書**、**漫畫**、**影片**、**手柄**、**查詞彈窗**。每個動作後面列著它當前的鍵盤、手柄、滑鼠繫結，點一下就進入錄鍵（「請按下快捷鍵組合...」，Esc 取消）。

幾個好用的功能：

- **搜尋**：頂部搜尋框按動作名或按鍵搜（「搜尋動作或按鍵」）。
- **按鍵反查**：按下一個鍵或手柄按鈕，列出「綁定了這個鍵的動作」——不知道某個鍵為什麼沒反應時先查它。
- **衝突處理**：新鍵已經被別的動作佔用時，會提示「已被佔用」，可以選 **替換**（移到當前動作）、**交換**，或 **兩者都保留**（同時生效時按作用域先後仲裁）。
- **手柄視覺化圖**：除了列表檢視，還可以切到「手柄視覺化圖」，直接在手柄示意圖上看每個鍵做什麼；「手柄按鈕樣式」可以選 Xbox、PlayStation 或 Nintendo Switch 的按鍵標識。
- **恢復預設**：可以按分組恢復，也可以「全部恢復預設」。改過的動作會標「已自定義」。

**macOS** 上預設鍵位裡的 Ctrl 自動換成 Cmd；幾個會被系統截走的鍵換成了空閒的同義鍵：有聲書播放 / 暫停是 Option+Space，視窗全屏是 Ctrl+Cmd+F。

## 常用預設鍵位（桌面）

### 閱讀器（EPUB / 輕小說）

| 動作 | 鍵盤 | 手柄 |
|---|---|---|
| 下一頁 | PageDown / → / ↓ / Space | RB、十字鍵右 |
| 上一頁 | PageUp / ← / ↑ / Shift+Space | LB、十字鍵左 |
| 顯示/隱藏控制欄 | M | Y |
| 進入選字查詞游標 / 查詞 | Enter | A |
| 從彈窗制卡 | Ctrl+Enter | — |
| 開啟設定選單 | T | — |
| 開啟導航（目錄） | Ctrl+F | — |
| 開啟插圖畫廊 | G | — |
| 開啟閱讀統計 | I | — |
| 開啟有聲書面板 | B | — |
| 暫停 / 繼續閱讀計時 | P | — |
| 切換振假名 | — | R3（按下右搖桿） |

豎排從右往左翻的書（日文預設），← 是下一頁、→ 是上一頁，和書的翻頁方向一致。

「選字查詞游標」是給沒有滑鼠的情況準備的：按 Enter 或手柄 A 進入游標，用方向鍵把游標移到要查的詞上，再確認就查詞，不需要點螢幕。游標停在查詞彈窗上時，`]` / `[` 跳下 / 上一本詞典，`.` / `,` 跳下 / 上一個詞條，手柄上是 RT / LT。

### 有聲書（在閱讀器裡聽書時）

| 動作 | 鍵盤 | 手柄 |
|---|---|---|
| 播放/暫停 | Ctrl+Space（macOS 為 Option+Space） | L3（按下左搖桿） |
| 下一句 | Ctrl+→ | X |
| 上一句 | Ctrl+← | B |

有聲書啟用時，裸 Space 也從「翻頁」改成「播放/暫停」，和一般播放器的習慣一致。注意這時手柄 B 歸「上一句」，不再是返回——聽書時要退出這本書，用鍵盤 Esc 或介面上的返回按鈕。

### 漫畫

| 動作 | 鍵盤 | 手柄 |
|---|---|---|
| 下一頁 / 上一頁 | PageDown、→、↓、Space / PageUp、←、↑ | RB、十字鍵右 / LB、十字鍵左 |
| 切換漫畫介面 | M | Y |
| 平移（放大後） | Ctrl+方向鍵 | — |

左右鍵會按漫畫的翻頁方向（日漫預設從右往左）自動校正。

### 影片

影片頁的鍵位比較多，大體沿用 asbplayer 的習慣：Space / P 播放暫停，← / → 快退快進，Ctrl+← / Ctrl+→ 上一句 / 下一句字幕，R 重播當前句，F 全屏，L 字幕列表，B 字幕模糊，S 截圖。手柄上 A 播放暫停、X / Y 上一句 / 下一句、LB / RB 快退快進、十字鍵上下調音量、RT 全屏、Start 開啟字幕列表、Select 進入字幕選詞游標、LT 重播當前句。完整列表見[看影片有哪些快捷鍵](/faq/video-shortcuts.zh-HK)。

### 首頁與全域性

| 動作 | 鍵盤 | 手柄 |
|---|---|---|
| 返回上一級 | Esc / Alt+← | B |
| 書架標籤 / 詞典標籤 / 設定標籤 | Ctrl+1 / Ctrl+2 / Ctrl+3 | — |
| 上一個 / 下一個標籤頁 | — | LT / RT |
| 聚焦搜尋 | Ctrl+F | Y |
| 向下 / 向上翻一屏 | PageDown / PageUp | RB / LB |
| 向下 / 向上滾動一行 | ↓ / ↑ | — |
| 滾動到頂部 / 底部 | Home / End | — |
| 全屏切換 | F11（macOS 為 Ctrl+Cmd+F） | — |

「返回上一級」只有這一個動作：在閱讀器、漫畫裡有查詞彈窗就先關彈窗，否則退出這本書；在影片裡會逐級退出（先收起字幕列表、側欄、全屏等，最後才退出頁面）。改了它的鍵，所有頁面一起生效。

### 查詞彈窗

| 動作 | 預設 |
|---|---|
| 下一個 / 上一個詞條 | Alt+滾輪下 / Alt+滾輪上；手柄十字鍵下 / 上 |
| 制卡（加號） | Ctrl+Enter；手柄 X |
| 播放單詞發音 | 手柄 Y |

滑鼠停在彈窗上就生效。裸滾輪永遠留給彈窗內容滾動，所以滾輪繫結必須帶修飾鍵。

### 應用外查詞（Windows / macOS）

在任何程式裡選中文字，按「應用外查詞快捷鍵」（預設 Ctrl+Alt+D），查詞卡片就在滑鼠旁彈出；「喚起主窗並開啟查詞頁」預設 Ctrl+Alt+F（macOS 上 Ctrl 同樣換成 Cmd）。這一組的滑鼠觸發只接受側鍵。手機上由系統觸發（選中文本選單、分享、懸浮球），不能自定義。詳見[全域性查詞](/faq/global-lookup.zh-HK)。

## 焦點導航：完全不用滑鼠

**設定 → 系統與關於 → 通用 → 鍵盤/手柄焦點導航**，預設關閉。開啟後：

- 用方向鍵或手柄搖桿移動焦點，當前選中的控制元件有焦點環；
- **Enter 或手柄 A 確認**（點按鈕、切開關）；Slider、分段選擇這類控制元件用方向鍵調；
- 裸 Space 不會觸發按鈕——確認統一走 Enter / A，避免看書時誤觸；
- 文本框裡按上 / 下可以跳出文本框；
- 返回統一是 Esc / Alt+← / 手柄 B。

不開焦點導航時，↑ / ↓ 照樣能滾動頁面，PageUp / PageDown 整頁翻，只是沒有焦點環。

## 各平臺的手柄支援

- **Windows**：通過系統的 GameInput 元件讀取手柄。快捷鍵設定裡提示「未檢測到 GameInput 元件，手柄功能不可用」時，安裝 Windows 的「遊戲服務（Gaming Services）」即可。
- **macOS / iOS**：使用系統的手柄框架，藍牙配對後即可用。
- **Android**：系統把手柄按鍵當按鍵事件交給應用，連上藍牙或 USB 手柄即可用。
- **Linux**（從原始碼構建）：通過系統輸入裝置讀取。

手機和平板上，主屏的鍵盤快捷鍵預設不啟用（只保留手柄），但閱讀器、漫畫、影片頁和「返回上一級」的鍵盤繫結仍然有效——接上藍牙鍵盤就能翻頁和控制播放。

## 常見問題

- **按了沒反應**：先用「按鍵反查」看這個鍵綁給了誰；同一個鍵在同一頁上只會觸發一個動作，排在前面的作用域會靜默蓋住後面的。
- **把 Esc 綁給了別的動作，退不出頁面了**：頁面專屬鍵優先於「返回上一級」，這種覆蓋不會出衝突提示。到快捷鍵設定裡改回來，或「恢復預設」即可。
- **玩 Galgame**：遊戲裡查詞制卡見 [Galgame 怎麼查詞制卡](/faq/galgame.zh-HK)；串流到手機上用觸屏或手柄玩見[遊戲串流](/faq/game-streaming.zh-HK)。
