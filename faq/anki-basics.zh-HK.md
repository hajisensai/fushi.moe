[連上 Anki](/faq/anki.zh-HK) 和[做出第一張卡](/faq/first-card.zh-HK)之後，Anki 本身還有幾件事值得一開始就弄對。這些不是 Fushi 的設定，是 Anki 的。

## 1. 把演算法換成 FSRS

Anki 內建了 **FSRS**——目前最好的間隔重複演算法之一——但**預設沒開**，不開就一直走三十多年前的 SM-2。FSRS 拿你的真實複習記錄預測遺忘時點，同樣的記憶效果複習量更少。

Fushi 的新手引導裡有一步就是它（設定 → 系統 → 新手引導 → Anki）：

1. 桌面 Anki 點牌組右邊的齒輪 → **選項**（AnkiDroid 2.17+ / AnkiMobile 長按牌組 → 選項）；
2. 滾到最底下的 **FSRS** 區塊，把開關開啟——對整個收藏生效，開一次就夠；
3. 點 **最佳化** 再儲存。複習記錄不到一千條時預設引數已經比 SM-2 準，攢夠了再最佳化一次。

開了 FSRS 以後**不要再手動干預排程**：某張卡排到幾十天后是演算法算出來的，不信它就別用它。按鈕上顯示的「下次複習時間」干擾你判斷的話，在 Anki 設定裡關掉顯示。

## 2. 四個按鈕只用兩個

看到正面先回憶背面，翻過去檢驗，然後：

| 回憶結果 | 按 |
|---|---|
| 沒想起來、想錯了 | **重來**（按鈕 1） |
| 費了不少勁才想起來 | 困難（按鈕 2）——沒答對就別按 |
| 比較輕鬆想起來 | **良好**（按鈕 3），最常用 |
| 滾瓜爛熟 | 簡單（按鈕 4），很少用 |

拿不準就只用 **1 和 3**。「困難」和「簡單」按錯的代價比不按大。

## 3. 正面不放發音

卡片正面只放**詞**（Lapis 模板預設就是這樣）。正面放了發音，你複習的就不是「看到這個詞能不能想起讀音和意思」，而是「聽到讀音能不能想起意思」——前者才是你在字幕和書裡遇到它的場景。發音放背面，翻過去再聽。

## 4. Fushi 這邊能幫上的

- **按詞頻重排新卡**：Fushi 的 Anki 設定裡有「按詞頻重排新卡」，用你裝的詞頻詞典（或 Lapis 的 FreqSort 欄位）把新卡按常用程度排序——先背常見詞，罕見詞往後放。做了一堆卡之後跑一次。
- **幾句合一張卡**：影片裡一句臺詞跨了兩三條字幕，在字幕列表裡**多選**再製卡，句子和音訊按整段截；查詞時也會把相鄰的字幕句合併。
- **一天做多少**：寧少勿多。每天十幾張新卡、堅持看下去，比某天做一百張然後第二天不想開啟 Anki 強。什麼詞值得做卡見[第一張卡](/faq/first-card.zh-HK#什麼詞值得做卡)。
- **卡的模板**：Fushi 一鍵建立的牌組用 Lapis 模板，欄位對映在 Fushi 的 Anki 設定裡改；自己有模板的也能對映過去。

## 常見狀況

- **卡組匯入報錯**：多半是從第三方站下的舊版 Anki，去 [apps.ankiweb.net](https://apps.ankiweb.net/) 裝官方版。
- **卡進了錯的牌組 / 欄位是空的**：Fushi 的 Anki 設定裡看牌組和欄位對映；換過筆記型別要重新對映。
- **手機上做的卡想進電腦的 Anki**：用 [Fushi 互聯](/faq/interconnect.zh-HK)的「制卡到 Fushi 互聯服務端」。
