Galgame 的文本 Hook 只能在 Windows 上做（見[Galgame 怎麼接進 Fushi？](/faq/galgame.zh-HK)），但很多人更想躺著用手機或 iPad 玩。Fushi 的 **遊戲串流** 就是為這個場景做的：遊戲照常在電腦上跑、Hook 照常在電腦上抓臺詞，Fushi 把遊戲視窗的畫面和聲音、連同 Hook 到的臺詞一起推到另一臺裝置上，你在那臺裝置上看、聽、點詞查詞、制卡，觸屏和手柄的操作再送回電腦上的遊戲。

這個功能目前是**實驗性**的：音影片、臺詞同步和查詞已經在真實遊戲和安卓裝置上跑通過，但輸入實效、遠端啟動和真卡寫入的端到端驗收還沒全部完成。遇到問題歡迎[反饋](/faq/feedback.zh-HK)。

## 它是怎麼工作的？誰負責什麼？

理解分工能少走很多彎路：

- **Windows 電腦（主機）**：運行遊戲、注入 Hook、採集遊戲視窗畫面和遊戲聲音、儲存詞典、連著 Anki，制卡也在這裡完成；
- **手機 / 平板（接收端）**：只負責顯示畫面、播放聲音、顯示臺詞、傳送輸入。接收端**不需要裝詞典**——你點的詞會發回電腦，由電腦上的詞典查好再把結果送回來；
- **連線方式**：兩邊通過 [Fushi 互聯](/faq/interconnect.zh-HK)配對，經加密連線協商，然後在**區域網**裡直連傳輸音影片。目前不支援跨網際網路串流（不經中轉伺服器），手機和電腦要在同一個區域網裡。

串流的是**遊戲那一個視窗**，不是整個桌面：遊戲視窗被別的視窗擋住也能繼續串（最小化則會停）。同一時刻一個串流只接一臺接收裝置。

## 哪些裝置能當接收端？

遊戲模組在不同平臺上是兩種形態：

- **Windows**：本機遊戲庫 + 文本 Hook 工作臺；遊戲頁裡另有 **串流** 分割槽，也能當接收端去看另一臺 Windows 電腦；
- **Android、iOS / iPadOS、macOS**（以及從原始碼構建的 Linux 版）：遊戲模組就是串流客戶端，副標題寫著「在電腦上啟動遊戲並串流到這裡」。

所以主機永遠是 Windows 電腦；接收端用手機、平板、Mac 都行。iOS 版在 App Store 合規上少了幾樣線上功能（見[iOS 版少了哪些功能？](/faq/ios-limits.zh-HK)），但遊戲串流客戶端是保留的。

## 第一次怎麼連上？

1. **配對**：先按[Fushi 互聯](/faq/interconnect.zh-HK)把手機和電腦配對。接收端遊戲頁顯示「還沒有配對的 Windows 主機」時，點 **開啟互聯設定** 去配。
2. **主機開加密**：Windows 端的互聯設定裡開啟 **互聯加密（HTTPS/TLS）**。沒開的話接收端會提示「主機未開啟 HTTPS」。
3. **主機開著遊戲模組**：Windows 端要啟用「遊戲」模組；否則接收端會提示主機沒有開啟遊戲庫。
4. **電腦上開始串流**：照常 **啟動並捕獲** 一個遊戲（Hook 連上之後才能串，否則會提示「請先啟動一個已連線 Hook 的遊戲」），在捕獲工作臺點 **開始串流**，狀態變成「串流已開啟，等待已配對裝置加入」。
5. **手機上加入**：開啟接收端的 **遊戲** 頁，它按主機列出「線上 · N 款遊戲」和 **正在串流** 的會話，點 **加入**。

也可以從 Fushi 互聯設定裡的「加入遊戲串流」入口進。

## 從手機直接啟動電腦上的遊戲

不想每次跑去電腦前點「啟動並捕獲」，可以在 Windows 端的互聯設定裡開啟 **允許遠端啟動**（預設關閉）：已配對的裝置就能從主機的遊戲庫裡選一款遊戲直接啟動並串流。手機上會依次顯示「正在啟動遊戲…」「等待遊戲視窗…」「正在連線串流…」。

幾個常見提示：

- 「這臺主機未開啟遠端啟動」：去電腦上開啟上面那個開關；沒開也不影響加入電腦上已經開始的串流；
- 「主機正在執行另一款遊戲」：同一時間只跑一款，先在電腦上關掉它，或者直接加入它的串流；
- 「主機缺少捕獲元件」：電腦上的 Fushi 需要重新安裝或更新；
- 「遊戲已啟動，但遊戲視窗沒有及時出現」：有啟動器、更新彈窗或載入很慢的遊戲會這樣，去電腦上看一眼。

遠端啟動的會話只留給發起啟動的那臺裝置。

## 在手機上怎麼玩、怎麼查詞、怎麼制卡？

- **臺詞**：畫面旁邊是 **當前臺詞** 面板——橫屏顯示在側邊欄，豎屏顯示在底部，可以拖動調整大小，也可以用「展開或收起查詞面板」收起來只看畫面。
- **查詞**：點臺詞裡的字，就從你點的位置開始交給電腦的詞典查詞，彈窗和影片字幕查詞是同一套。接了鍵盤時也能用方向鍵在臺詞裡移動游標、按 Enter 查詞。
- **制卡**：在查詞結果裡點加號，卡由**電腦**做好寫進**電腦的 Anki**，提示「主機已建立卡片」。卡上用的是這一句臺詞當時的截圖和這句的語音（有語音的話）；沒有對應語音時照常寫入不帶句子音訊的卡，不會拿別的臺詞的聲音湊數。如果臺詞已經翻過很久，會提示「這句臺詞在主機上已過期，請對當前臺詞查詞」。
- **觸屏**：有兩種方式，選單裡切換——**直接點選**（點哪裡就是點遊戲的哪裡；雙指點按是右鍵、雙指拖動是滾輪）和 **觸控板**（像筆記本觸控板一樣移動游標，點按是左鍵）。
- **手柄**：螢幕上可以顯示虛擬手柄（「顯示或隱藏手柄」），**配置手柄按鍵** 可以調按鍵對映，只對本次串流有效；接實體手柄、硬體鍵盤也能用，還有軟鍵盤。部分遊戲不接受觸控點選，會提示改用手柄按鍵。
- **聲音**：可以隨時靜音 / 播放遊戲聲音。

## 畫質卡頓、操作沒反應怎麼調？

串流設定（**串流設定**，帶「推薦值」一鍵恢復）裡能調：

- **解析度上限**：360p 到 4K，預設 1080p，不會超過主機遊戲視窗本身的尺寸；
- **幀率**：30 / 60 / 90 / 120，預設 60；Galgame 畫面大多是靜止的，降到 30 也夠用；
- **位元速率**：0.5–150 Mbps，預設 20 Mbps；**自適應位元速率** 預設開，從一半位元速率起步再逐步提升；
- **頻寬不足時**：均衡 / 保持幀率 / 保持清晰度，預設保持清晰度，文字類遊戲建議保持清晰度，字更清楚；
- **影片編碼**：自動 / H.264 / VP8 / VP9 / AV1，下次連線生效，裝置不支援時自動回退；
- **遊戲視窗輸入**：預設 **僅視窗**（遊戲可以留在後臺，輸入直接投給遊戲視窗）；部分引擎在後臺不接收輸入，觸控無效時改成 **切到前臺**。

開啟「顯示效能統計」可以看到實際解析度、幀率、位元速率、丟包、丟幀。提示「輸入未送達」時，看後面跟的原因：遊戲視窗被最小化或隱藏、或者需要切到前臺。電腦上視窗被最小化、遊戲關閉、Hook 會話結束，或者 10 分鐘沒有接收端活動，串流都會自動停止。
