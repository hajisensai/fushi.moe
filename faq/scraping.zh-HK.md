## 刮削是什麼

你的硬碟上有一個檔案叫

```
[VCB-Studio] Sousou no Frieren [01][Ma10p_1080p][x265_flac].mkv
```

對電腦來說它只是一串字元。**刮削**（scrape）做的事是：先從檔名裡認出「這是《葬送的芙莉蓮》第 1 集」，再去線上資料庫把這部作品的**海報、簡介、評分、季和集的列表、放送時間**拉下來存到本地。刮完之後，你的影片庫就從一堆檔名變成帶封面的作品牆，點進一部能看到每集的標題和縮圖。

這個詞來自 Jellyfin / Plex / Kodi 那類媒體庫軟體（英文 scraper，"刮取" 網頁上的資料），資料庫則是 [TMDB](https://www.themoviedb.org/)、[MAL](https://myanimelist.net/)、[AniDB](https://anidb.net/)、[Bangumi](https://bgm.tv/) 這些站。

## Fushi 刮什麼

| 型別 | 資料來源 | 拿到什麼 |
|---|---|---|
| **影片**（番劇、劇集、電影） | MAL（經 Jikan）為主，TMDB 兜底；可選 AniDB 檔案識別 | 海報、簡介、評分、季 / 集列表、放送資訊 |
| **書、漫畫** | Bangumi | 封面 |
| **遊戲**（galgame） | VNDB、Bangumi | 封面、簡介、發行日等 |

影片是刮削的主戰場，下面主要講它。

## 影片：預設就是自動的

匯入本地資料夾時有兩種組織方式：

- **按作品**（預設）：按檔名識別作品與分集，再匹配作品資料——**會刮削**。
- **按資料夾**：每個一級子資料夾一個合集，只整理不刮。適合按難度、課程、主題分的目錄。

選了「按作品」，掃描完成後 Fushi 就自動開始刮（來源的「掃描後自動刮削」和全域性「自動刮削條目資料」預設都開著）；番劇下載來的影片在入庫前也會自動刮一遍（`下載 → 整理 → 字幕 → 刮削 → 入庫`）。刮完還有一步 **刮削後自動補字幕**：沒字幕的影片自動從已配置的線上字幕源取一條。

刮削是按**置信度**來的：檔名解析出的標題在資料源裡有**唯一精確命中**才自動應用；有好幾個同名候選、或者兩邊都查不到，就不瞎猜，丟進 **待確認** 等你點。影片庫頂上會有一條「N 部作品還沒確認身份」提示，點「去確認」。

## 待確認：手動指定作品

影片來源頁的 **後臺任務** 面板分 **當前任務 / 待確認 / 最近任務** 三欄。在「待確認」裡點一部作品：

- **按標題**搜：搜尋結果帶封面和年份，選中即繫結；
- **按作品 ID**：選 MAL、TMDB 電影或 TMDB 電視劇，輸入 ID，或者直接把作品頁的官方連結貼進來。

已經刮錯的作品也能改：合集選單 → **重新刮削資料與封面** → 選正確的條目。手動指定過的繫結受保護，以後自動刮不會再改它；自己設的封面（手動選的本地圖、目錄裡自帶的 poster）也一律不覆蓋。

## 檔名怎麼起才認得準

Fushi 的檔名解析和 Jellyfin / anitomy 一路：能剝掉字幕組 tag、畫質、編碼，認 `S01E01`、`第2季`、`2nd Season`、`Season 2` 這些寫法。穩妥的佈局：

```
番劇/
  葬送的芙莉蓮/
    [VCB-Studio] Sousou no Frieren [01][Ma10p_1080p].mkv
    [VCB-Studio] Sousou no Frieren [02][Ma10p_1080p].mkv
  Hibike! Euphonium/
    Season 2/
      Hibike! Euphonium - 01.mkv
```

幾條經驗：

- **一部作品一個資料夾**，季號可以只寫在子資料夾名上（`Season 2` / `S02` / `第2季`）；
- 集號**兩位補零**（`01` 而不是 `1`）——`Show 2.mkv` 到底是第 2 季還是第 2 集是猜不準的，不過同一目錄下 `Show 1 … Show 12` 這種成批的檔案 Fushi 會拿兄弟檔案對比出集號；
- 標題用**原名或官方英文名**比自己起的中文簡稱好認；
- 檔名認不出來又不想改名，用 **識別詞**（下面）或者開 AniDB 檔案識別。

## 進階設定

都在 **設定 → 服務 → 後設資料刮削** 和各來源的 **來源刮削設定** 裡：

- **主資料源**：預設 MAL；主源沒有唯一命中時自動問另一個源。資料語言（簡介、TMDB 海報的語言）可以按來源單獨設。
- **識別詞**：刮之前先改寫檔名，一行一條規則——遮蔽直接寫正則；替換 `A => B`；集偏移 `前 <> 後 >> EP+1`（比如把從 13 開始編號的第二季偏回 1）。
- **通過 AniDB ED2K 識別檔案**：按檔案內容的雜湊去 AniDB 認作品和集號，檔名亂成什麼樣都認得出。需要自己的 AniDB 賬號，AniDB 的 UDP 登入不加密，只在可信網路下開。
- **TMDB API Key**：內建了一個，刮不動或想用自己的配額時再填。
- **NFO 與圖片寫入策略**：刮到的資料可以寫成 `.nfo` 檔案和 `poster.jpg` 放到影片旁邊——Jellyfin / Kodi 也認這套格式。預設「僅缺失時寫入」，第三方或你改過的檔案受保護，不會被覆蓋。
- **鎖定欄位**：作品詳情裡鎖住標題、封面等欄位，下次重刮保留你改的值。
- **清理全部刮削記錄**：把資料、繫結和 Fushi 自己生成的 NFO / 封面全清掉，影片檔案、觀看進度、字幕不動。

## 書、漫畫、遊戲

- **書 / 漫畫**：編輯對話方塊裡 **線上匹配封面**，按書名 / 作者搜 Bangumi，選一個用。
- **遊戲**：卡片選單 **刮削後設資料**，開啟就按當前名字自動搜 VNDB / Bangumi，候選帶封面，點「使用」封面和簡介一起落。
- 庫頁選單裡的 **全部刮削** 可以批次跑：影片按標題、年份綜合打分，書和遊戲要求標題唯一且完全一致才自動應用，其餘進待確認。

## 用互聯時

手機連著電腦主機看遠端影片，資料以主機刮的為準，會自動同步到手機；某部沒刮的可以在手機上選 **在主機上刮削**，或 **本機刮削並回寫主機**。見[Fushi 互聯](/faq/interconnect.zh-HK)。

## 常見狀況

- **認錯作品**：待確認 / 重新刮削裡手動指定；反覆認錯的檔名加一條識別詞。
- **一部番被拆成好幾部**：一般是檔名裡的季 / 集寫法不一致（有的 `S02E01`、有的 `- 13`），統一一下或者用識別詞的集偏移。
- **海報是別的語言**：改來源的「資料語言」。
- **搜尋失敗 / 限流**：MAL 走 Jikan 有速率限制，批次刮會慢一點是正常的；連不上就在設定裡配代理。
- **刮削和「Bangumi 同步」不是一回事**：刮削是把資料拉進來，Bangumi 同步是把你的觀看 / 閱讀進度記到 Bangumi 賬號上。
