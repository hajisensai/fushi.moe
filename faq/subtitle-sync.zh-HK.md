外掛字幕不是跟著這個影片檔案做的，對不上很正常。先分清是哪一種偏，再對症調。

## 兩種偏法

**整體偏一段**：從頭到尾字幕都比聲音早（或晚）固定的幾秒。原因是字幕和影片的**版本不一樣**：

- 藍光版和電視 / WEB 版剪輯不同——BD 版可能多了幾秒黑場、少了廣告位的過場，OP 前有沒有冷開場也不一樣；
- 有的版本把 OP / ED 剪掉了，字幕是按完整版做的。

**越往後差越多**：開頭是對的，看到二十分鐘時字幕晚了兩三秒。這是**幀率不同**——字幕按 25 fps 的 PAL 版做，影片是 23.976 fps，或者反過來；每分鐘差幾幀，累計到一集末尾就是幾秒。這種調一個固定偏移不夠，需要把字幕整體拉伸。

還有一種是**只有幾句對不上**：那是字幕本身打軸不準，換一份字幕吧。

## 在 Fushi 裡調

播放器的快速設定裡有 **字幕調軸**：

- **滑條 / 步進**：直接拖，或者按 ±100 ms 之類的步長點。字幕早了就往正調（延後），晚了就往負調。看著一句臺詞開口的瞬間和字幕出現的瞬間對齊即可。
- **自動對軸**：讓 Fushi 自己算一個偏移。
- **波形對軸**（本地影片）：點開後能看到整條音訊的波形，字幕的每句起點畫成一條條線，橫向拖動、把線對到說話的峰值上。肉眼對一次比反覆試滑條快得多；手機上可能生成不了波形，那就用滑條。

調好的偏移**按集記住**：換集、重進都還在。制卡時截的音訊和畫面也會按這個偏移取，做出來的卡不會串句。

## 對軸後還是慢慢漂

那就是幀率問題，固定偏移救不了。辦法：

- 去 [Jimaku](https://jimaku.cc) 找**和你的影片同版本**的字幕——條目下常常同時有 BD 版和 WEB 版，檔名裡會寫；
- 或者換一份和字幕同版本的影片；
- 實在要自己修，用 [Aegisub](https://aegisub.org/) 或 [Subtitle Edit](https://www.nikse.dk/subtitleedit) 做「幀率轉換」或「兩點同步」，把字幕拉伸到正確的時長後再放回來。

## 一開始就選對版本能省很多事

用 Fushi 番劇下載勾「附帶字幕」自動配到的字幕不合適時，可以手動補一條：看一眼資源名裡是 **BDRip** 還是 **WEB-DL**（[怎麼看資源名](/faq/release-names.zh-HK)），到 Jimaku 找對應版本的字幕匯入。
