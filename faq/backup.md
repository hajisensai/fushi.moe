Fushi 不需要注册，所有数据默认都只在你自己的设备上（见[我的数据存在哪里？](/faq/data)）。好处是隐私，坏处是：手机丢了、电脑重装了，如果你什么都没做，书架、阅读进度、学习统计就一起没了。所以值得花五分钟设好一条备份通道。

Fushi 里和「备份」有关的东西都在 **设置 → 同步与备份**（副标题「云端、局域网与本地备份」），另外还有一个独立的 **设置 → Fushi 互联**。下面按用途分开讲。

## 三种备份方式，怎么选

| 方式 | 适合谁 | 特点 |
|---|---|---|
| **本地备份文件**（导出备份） | 一次性迁移、偶尔留个底 | 打包成一个 `fushi-backup-日期.fushi.zip`，自己保管；不联网 |
| **云同步**（同步方式选云盘 / 网盘） | 想要自动、持续备份 | Google Drive、OneDrive、Dropbox、WebDAV、FTP、SFTP 任选一个；凭据只存在本机 |
| **Fushi 互联** | 家里有一台常开的电脑或 NAS | 数据直接放到你自己的电脑或 [Fushi 服务端](/faq/server)上，不经过任何云盘 |

三者不冲突：可以平时开云同步，换设备前再导出一个备份文件兜底。

## 方法一：导出 / 导入备份文件

### 导出

**设置 → 同步与备份 → 本地备份 → 导出备份**。

点开后先弹「选择要导出的内容」，可以逐项勾选：

- **词典**（已导入的词典及其文件）
- **书籍内容**（EPUB 及解压内容）——还可以点「选择书籍」只打包其中几本
- **有声书音频**（有声书音频与对齐数据）
- **自定义字体**
- **视频**（本地视频文件）——同样可以「选择视频」
- **本地音频数据库**（本地发音音频库）
- **游戏**（游戏库、元数据来源与封面）
- **阅读进度**、**统计数据**、**设置**、**配置方案**

视频、有声书、本地发音库通常是最大的几项。只想迁移阅读记录的话，把这几项取消勾选，备份会小很多；这些大文件可以之后直接拷贝过去重新导入。

注意提示里的那句：**取消勾选「书籍」会连同这些书的正文和记录一并移除**——也就是说备份里不会有这本书的进度。想保留进度就要连书一起打包。

导出完成后：

- **Android / iOS**：弹出系统分享面板，存到「文件」、网盘，或者发给自己；
- **Windows / macOS**：弹出保存对话框，选个位置存成 `.zip`。

如果有词典的原文件在这台设备上已经找不到了，会提示「导出完成，但有 N 本词典被跳过」，其它内容照常导出。

### 导入

在新设备上装好 Fushi（[下载页](/zh-cn/download)），**设置 → 同步与备份 → 本地备份 → 导入备份**，选那个 `.zip`。Fushi 会先校验并预览备份内容，然后让你选：

- **导入方式**：
  - **合并到现有库**——新设备上已经有书时用这个，会提示「合并将新增 N 本书、更新 N 条阅读进度」；
  - **覆盖整库**——用备份替换当前全部数据，适合全新安装的设备。
- **此备份包含**：列出备份里的各项，取消勾选某项即可跳过它。
- **导入设置与 Profile**：打开就是完整恢复（字体、外观、Profile 都来自备份）；关掉就保留本机的字体 / 外观 / Profile，只恢复书籍与阅读数据。

确认后应用会自动重启。本设备的同步配置（账户与凭据）会保留，不会被备份里的覆盖掉。

常见提示：

- **「无效的备份文件」**：选错了文件，或者文件没下载完整。Hibiki 时代导出的 `*.hibiki.zip` 老备份仍然可以导入。
- **「此备份需要更新版本的应用」**：备份是用更新的 Fushi 导出的，先把这台设备上的 Fushi 更新到同一版本或更新。
- 导入过程中界面会显示「正在恢复数据，请勿关闭应用」，大备份可能要几分钟，别中途退出。

## 方法二：云同步（自动备份）

**设置 → 同步与备份 → 同步方式**，在「存储后端」里选一个：

- **Google Drive / OneDrive / Dropbox**：点「登录」，在浏览器里授权。桌面端会打开默认浏览器；没打开或页面报错时，可以「复制登录链接」到别的浏览器打开。
- **WebDAV / FTP / SFTP**：进「服务器设置」填服务器地址、用户名、密码（SFTP 还可以填私钥），点「测试连接」。支持 WebDAV 的网盘、群晖等 NAS、自建服务器都可以用。

选好之后看下面三组：

**同步内容**

- **同步统计**：学习时长、字数这些统计也跟着同步。
- **上传书籍文件**、**同步有声书文件**、**上传视频文件**：把文件本体也传上去。默认不传大文件的话，云端只有进度和记录，换设备后需要自己再导入一次书；打开后才会把书本身也放到云端（会占云盘空间和流量）。

**何时同步**

- **自动同步**：打开后，Fushi 会在打开应用、切到后台、关书这些时机自动推送；
- **立即同步**：手动做一次完整双向同步；
- **对比数据**：并排看「本地 vs 远端」，每本书可以选用本地、用远端或跳过，适合两台设备进度打架时手动裁决。

**词典与本地音频传输**

词典、本地发音库、字体这几样体积大，**不会自动同步**，在这一组里点「传输」手动选「上传」（把本机有、远端没有的推上去）或「下载」（把远端有、本机没有的取回来）。新设备上第一件事就是在这里把词典「下载」下来，比重新下推荐包省事。

几点说明：

- 云端的凭据只存在本机，备份恢复时也不会被覆盖。
- 自己从源码构建的版本可能没有内置 Google 登录凭据，会提示「此构建未配置谷歌同步凭据」，换 WebDAV 等其它后端即可。
- 云盘满了会提示「云端存储空间已满」，关掉视频 / 有声书文件上传或清理云盘。

## 方法三：用 Fushi 互联放到自己的电脑上

如果你已经按[互联教程](/faq/interconnect)配好了手机和电脑，可以完全不用云盘：

- **与已配对设备共享**：阅读 / 观看进度、统计（「共享统计」）、收藏的词与句子两边双向合并，默认开启。一台设备坏了，另一台上还有完整记录。
- **上传到互联对端**：书籍、词典、有声书、视频四个开关默认全关，想把手机上的内容存一份到电脑就勾上对应的。
- **用互联做备份后端**：在互联设置里点「设为备份后端」，原本写到云盘的备份与同步改写到已配对的电脑或服务端。
- **配置文件**：「上传配置到对端」/「从对端下载配置」可以把一整套 Profile（阅读器、查词、制卡设置）搬到另一台设备，落成一份新配置，不覆盖原有的。

没有常开电脑的话，可以在 NAS 上跑一个 [Fushi 服务端](/faq/server)当这台「家里的主机」。

## 换手机 / 换电脑：推荐步骤

1. **旧设备上**：先「立即同步」一次（用了云同步或互联的话），再「导出备份」留一份文件。
2. **新设备上**：装 Fushi。打算从旧设备搬词典的话，先不急着下[推荐包](/faq/pack)，等恢复完再看缺什么。
3. 按你用的方式恢复：
   - 用备份文件：**导入备份 → 覆盖整库**（新设备没数据时）；
   - 用云同步：选同一个存储后端、登录同一个账号，点「立即同步」，再在「词典与本地音频传输」里把词典和发音库「下载」下来；
   - 用互联：配对后在书架 / 视频库里的 Fushi 互联来源直接看电脑上的内容，进度会自动合并。
4. 检查 Anki 连接：卡片本身存在 Anki 里，不在 Fushi 的备份里——换设备后在 **设置 → 制卡** 重新连上 Anki（见[怎么连接 Anki？](/faq/anki)），Anki 那边的牌组用 Anki 自己的同步（AnkiWeb 或自建同步服务器）迁移。
5. AI 提供商的配置是设备本地的，不进备份和同步，新设备上要在 **设置 → 模型 → LLM** 里重新填。

### 从别的阅读器搬过来

- **Hoshi Reader**：**设置 → 同步与备份 → 本地备份 → 第三方导入**，选 Hoshi Reader 导出的 `.hoshi` 书库备份，书、阅读位置和统计都会导入；同一份备份重复导入不会重复计数。
- **旧版 Hibiki（Android）**：Android 上这一组里有「从 Hibiki 导入」，导入旧版 Hibiki 导出的数据。

## 常见问题

- **备份文件存在哪？** 导出时你自己选的位置；Fushi 不会自动替你存一份。导出过程中的临时包如果残留，会出现在 **设置 → 存储** 的「遗留的备份包」里，可以清掉。
- **数据目录能放到别的盘吗？** 可以，**设置 → 存储**（数据位置与磁盘占用）。数据位置所在的盘暂时读不到时，Fushi 会提示「数据位置未响应」，可以重试，或「仍用默认位置启动」——不会改动原来的数据。
- **两台设备进度不一致**：用「对比数据」手动选，或在两边都点一次「立即同步」。
- **备份能跨平台吗？** 能。Android 导出的备份可以在 Windows / macOS / iOS 上导入，反过来也一样。
