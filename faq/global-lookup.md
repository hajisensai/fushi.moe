可以。Fushi 的词典不只在它自己的阅读器和播放器里用：开着 Fushi 的时候，你在浏览器、PDF 阅读器、聊天软件、游戏、任何能选中文字的程序里，都能直接查词，而且弹出来的是和 app 内一模一样的查词卡片——同一套词典、同样的音调和词频、同样的加号制卡。

先说平台：

| 平台 | 有什么 |
|---|---|
| **Windows** | 全局查词快捷键、应用外悬浮球（剪贴板查词 / 截屏识字）、浏览器扩展 |
| **macOS** | 同 Windows（第一次要授权「辅助功能」） |
| **Linux** | 暂无应用外查词卡片和应用外悬浮球；网页可以用浏览器扩展 |
| **Android** | 系统文字菜单 / 分享查词、应用外悬浮球 |
| **iOS** | 系统不允许应用在别的 app 上面弹窗，没有应用外查词；在 Fushi 里粘贴到查词页查 |

## Windows / macOS：选中文字，按快捷键

1. 在任意程序里**拖选一个词**，保持选中。
2. 按 **Ctrl+Alt+D**（macOS 上是 **⌘⌥D**）。
3. Fushi 抓取选区，在**鼠标旁边**打开查词卡片。

几个关键点：

- **卡片不抢焦点**：它浮在当前程序上面，但你正在用的程序仍然是前台窗口，键盘输入、游戏操作不受影响。按 Esc 或点卡片外面就收起。
- **再按一次 = 查新的选区**：选中另一个词再按快捷键，卡片直接换成新词，不用先关。
- **卡片里能继续查**：释义里的词点一下，会在旁边弹出下一层卡片，可以一层层往下查（嵌套查词），和 app 内弹窗一样，见[查词弹窗怎么用](/faq/lookup-popup)。
- **能听、能制卡**：喇叭播单词发音，加号直接做 Anki 卡；词已经在 Anki 里时 ✓ 会让你选覆写、在 Anki 中打开或新增为重复卡。
- **Fushi 要开着**：查词用的是 Fushi 主程序里的词典，Fushi 退出了快捷键就没了。最小化、放在后台都行。

### 改快捷键、用鼠标侧键或手柄

**设置 → 快捷键设置 → 全局（应用外）** 里有两条：

- **应用外查词快捷键**：就是上面这个动作，默认 Ctrl+Alt+D。可以改成别的组合键；也可以绑**鼠标侧键**（后退 / 前进）——鼠标触发只接受侧键，其它按钮在别的程序里有各自的固有含义，会被拒绝录入。手柄按钮也能绑（默认不绑，因为它会优先于页面里的手柄操作）。
- **唤起主窗并打开查词页**：默认 Ctrl+Alt+F。不抓任何选区，只是把 Fushi 主窗唤到前台、落在查词页上，让你自己输入或粘贴。

新手引导里也有一步「全局查词」，演示这套操作并显示你当前绑定的键。

### 把整句也带上：抓取选中文本上下文

默认情况下，快捷键只拿到你选中的那几个字（Fushi 会模拟一次复制来读选区）。**设置 → 查词 → 查词触发** 里的「**抓取选中文本上下文**」打开后，Fushi 还会从前台应用读取选区周围的文本，在查词卡片里显示当前句，制卡时这句会作为例句进卡（Windows / macOS）。

这个开关默认关：它会读取别的程序窗口里的文字，属于隐私敏感功能，需要时再开。读不到上下文的程序（不提供无障碍文本接口的）会自动退回只查选中的词。

### macOS：先授权「辅助功能」

macOS 需要辅助功能权限才能读取其他应用中选中的文字；未授权时快捷键只查当前剪贴板文本。第一次按快捷键时 Fushi 会请求授权，也可以在 **设置 → 查词 → 查词触发** 点「**为应用外查词授权辅助功能**」。授权路径是系统设置的「隐私与安全性 > 辅助功能」，启用 Fushi 后再按一次快捷键即可。

### 截图、录屏、直播时不想拍到查词卡

**设置 → 查词 → 弹窗窗口** 里的「**防截屏 / 防录屏**」会把查词悬浮窗从截图、录屏、直播串流中排除（Windows / macOS）。默认关，也就是默认截图能拍到卡片；直播或录教程时不想让观众看到查词过程就打开它。

## 应用外悬浮球：剪贴板查词、截屏识字

有些地方选不了文字，或者你更习惯点按钮。**设置 → 悬浮球** 里打开「**应用外显示**」，切到其他程序后悬浮球仍浮在最上层。展开后可以放这些按钮：

- **应用外查词**：查前台程序当前选中的文字，和快捷键是同一件事。
- **剪贴板查词**：读剪贴板里的文字，在悬浮球旁弹出查词卡片。适合「先复制、再查」的场景——比如 Textractor 之类的工具把游戏台词自动复制到剪贴板时，点一下球就查。
- **截屏识字**：截下悬浮球所在的显示器，用系统自带的文字识别找出画面上的文字，盖一层冻结画面让你**直接点字查词**。图片里的字、游戏画面、视频截图、不能选中的界面文字都能这样查。
- **查词**：把 Fushi 唤到前台并打开查词页。
- **打开 Fushi**、立即同步等。

前三个查词按钮需要「查词」模块开着（**设置 → 外观与交互 → 功能模块**）。悬浮球的按钮可以按场景分别勾选（阅读器、漫画、视频、其它页面、应用外）。

注意 Fushi **不会在后台自动监听剪贴板**：只有你点「剪贴板查词」时它才读一次剪贴板。想要「每复制一句就自动显示」的游戏查词体验，用下面说的文本钩子。

## Android：文字菜单和悬浮球

Android 通过文字菜单或分享面板把选中文本交给 Fushi：

1. 在其他应用里**长按一个词**，拖动手柄覆盖它。
2. 在弹出的文字菜单里点 **Fushi**；没有就点「分享」，再选 Fushi。
3. 查词弹窗盖在原应用上，关掉就回去。弹窗里同样能嵌套查词、听发音、制卡。

Android 也有应用外悬浮球：在 **设置 → 悬浮球** 打开「应用外显示」，需要授予「显示在其他应用上层」权限，悬浮球才能系统常驻。安卓的悬浮球上有「应用外查词」（不进主窗，直接弹一个带搜索栏的查词窗）、「剪贴板查词」、「截屏识字」和「拍照查词」（拍纸质书、招牌、别的设备的屏幕再点字查词）。

## 浏览器、游戏、其他工具

- **网页**：任意网页上按住 Shift 移到词上就查，用的是 Fushi 的浏览器扩展（电脑上的 Chrome、Edge 这类 Chromium 浏览器），安装步骤见[浏览器里怎么查词](/faq/browser-lookup)。它和全局查词共用同一套词典，网页上用扩展比用快捷键更顺手。
- **Galgame**：Windows 上 Fushi 能直接 Hook 游戏台词，在浮窗里逐词点查、制卡，见[Galgame 怎么接进 Fushi](/faq/galgame)。
- **Textractor / LunaTranslator / mpv 等抓文本工具**：**设置 → 查词 → 外部集成** 里的「文本钩子（接收文本）」连它们的 WebSocket，台词推进 Fushi 后逐词点查。
- **GameSentenceMiner 等走 yomitan-api 协议的工具**：开「Fushi API 服务器」，让它们改查 Fushi 的词典。
- **Anki 卡片里的词典交叉引用**：Fushi 制卡时会把释义里的词典内部链接改写成 `fushi://lookup` 链接，在 Windows 和 Android 上点它会打开 Fushi 查这个词。

## 常见状况

- **按了快捷键没反应**：确认 Fushi 在运行、「查词」模块没关；快捷键可能和别的软件冲突，到 设置 → 快捷键设置 → 全局（应用外） 换一个组合。
- **查到的是别的词 / 上一次复制的内容**：有的程序不响应模拟复制，选区没被抓到。换个程序试试，或者用悬浮球的「剪贴板查词」：先手动复制再查。
- **macOS 上只能查剪贴板**：没授权辅助功能，见上文。
- **卡片里没有例句**：「抓取选中文本上下文」默认是关的；开了之后仍没有，说明那个程序不提供周围文本。
- **截屏识字认不出字**：系统文字识别对小字、艺术字、低对比度画面效果有限；能选中的文字优先用快捷键。
- **Linux 上没有快捷键查词和悬浮球**：目前 Linux 只有 app 内查词和浏览器扩展，各平台差异见[各平台都支持什么](/faq/platforms)。
