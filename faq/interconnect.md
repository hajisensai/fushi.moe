Fushi 互联是**你自己设备之间的直连**（在家走局域网，出门也能连回来）：一台设备当**主机**（把自己的库开放出去），其他设备当**客户端**连上它。最常见的用法就是电脑当主机——番剧、书、漫画、9.5 GB 的词典包、Anki 都在电脑上；手机当客户端，躺着看、随手查、制的卡进电脑的 Anki，进度和统计两边一起走。

同一台设备同一时间只能当主机或客户端之一。互联和云备份（Google Drive / WebDAV…）是两条独立通道，可以同时开。

## 准备

- 第一次配对时手机和电脑最好连**同一个 Wi-Fi / 局域网**（不在同一网络也能配，见下面「不在同一局域网」）。
- 两边都装好 Fushi 并更新到同一个大版本，旧版本配对会提示「对方版本过旧」。
- 电脑端在 Windows / macOS 都可以当主机；手机端 Android / iOS 当客户端（iOS 不能当主机）。

## 第 1 步：电脑开主机服务

电脑上：**设置 → Fushi 互联**

1. 打开 **启用互联**。
2. 进 **主机服务**，打开 **启用同步服务**。默认端口 **38765**，新设备第一次开主机会默认打开 **互联加密（HTTPS/TLS）**——留着，后面「制卡到主机的 Anki」「同步主机服务配置」之类的功能要它。
3. 状态变成「运行中 · 端口 38765」就行了。Windows 第一次会弹防火墙询问，勾上专用 / 私有网络允许。

主机是被动的一方：它自己不需要点「同步」，一切由客户端发起。

## 第 2 步：手机配对

手机上：**设置 → Fushi 互联 → 启用互联 → 配对与设备**

- 下方 **局域网设备** 列表会自动发现同网络里开了主机的电脑，**点它**；
- 电脑上弹出「配对请求」，点 **允许**；
- 手机提示「配对成功，已自动填入 token」。完成。

之后「已添加的对端」里就有这台电脑，电脑的「已配对设备」里也有这台手机。配对是一次性的，以后自动连上。

**扫码 / 链接 / NFC 配对**：电脑的主机服务里点 **显示配对二维码**，手机上点 **扫码配对** 扫一下就配好，不用在电脑上再点允许，也不用手输地址（二维码 5 分钟内有效、只能配一台）。扫不了码的设备用「复制配对链接」+「粘贴配对链接」。Android 上已经配对过的手机还能 **写入 NFC 贴纸**，之后别的手机碰一下贴纸就能发起配对（仍要主机确认）。

**列表里没发现电脑？** 多半是路由器开了 AP 隔离、或者电脑防火墙拦了 mDNS。改成手动添加对端地址：在电脑上看一眼本机局域网 IP（Windows：`ipconfig`；macOS：系统设置 → Wi-Fi → 详细信息），在手机上填

```
https://192.168.1.23:38765
```

主机开了 TLS 就用 `https://`，没开用 `http://`（只写 `IP:端口` 会按 http 处理）——填反了 Fushi 会直接提示该用哪个。

### 不在同一局域网（出门在外、Tailscale、公网等）

配好之后，手机会自动学到电脑的全部地址（局域网、IPv6、Tailscale 这类虚拟网卡、你填的公网地址），每次连接同时探测、挑能通的那条，不用你手动切换：

- 电脑有公网地址或反代域名的话，填进主机服务的 **公网 / 反代地址**，已配对设备会自动学到；
- 两边都没有公网 IP，打开 **允许经 P2P 隧道远程连接**：直连都不通时走 P2P 隧道（会用到 iroh 的中继与发现服务器，走中继时看视频可能较慢；也可以填自建中继）。

不在同一网络时第一次配对，最省事的是扫配对二维码；也可以手动填一个手机能连到的地址（比如两边都装了 [Tailscale](https://tailscale.com/)），这时会多一道 **PIN**：电脑点「允许」后屏幕上会常驻显示一个 6 位 PIN，手机上输入它。PIN 不经过网络传输，是防止别人冒充配对的。

第一次连上时手机会记住电脑的证书指纹；以后再连时如果证书变了（电脑重装过 Fushi），会弹「证书已变更」——确认是自己重装的，就点「清除已存指纹并重新信任」重新配对。

## 第 3 步：手机上能做什么

配好之后手机上什么都不用再设，各处会自动多出来一些东西：

**看电脑上的东西**

- 视频、书、漫画各自的来源列表里多一个 **Fushi 互联** 来源，点进去就是电脑的库：视频直接流播，书直接读，漫画（含电脑上 OCR 过的 mokuro）直接翻。
- 想离线带走就点 **下载到本机**。
- 网络差的时候，电脑的互联设置里打开 **为对端转码视频**，手机播电脑的视频时实时转成低码率（需要 ffmpeg，会占电脑 CPU）。
- 「同步」设置里的 **显示远端条目**（默认开）会把电脑有、手机没有的书和视频显示成带云角标的占位卡，书架上一眼看到，点了就播 / 下载。

**用电脑的词典和发音**

- **查词 → 远端词典查询**：手机本地查不到的词去电脑上查。手机不装 9.5 GB 的推荐包，也能查到电脑上装的所有词典。
- **管理音频来源 → Fushi 互联**：单词发音从电脑的本地发音库拿。

**制的卡进电脑的 Anki**

- 手机的 **Fushi 互联 → 交给 Fushi 互联服务端** 里打开 **制卡到 Fushi 互联服务端**（制卡设置里也有同一个开关）：手机上点加号做的卡走电脑，用电脑的牌组和字段设置，进电脑那个 Anki。手机上不用装 AnkiDroid / AnkiMobile 也行。
- 漫画 OCR 引擎也可以选 **交给已配对的 Fushi 互联服务端来跑**，手机不下任何模型。

**让电脑替手机干活**

- 下载的「下载到」/「下载执行设备」选电脑，番剧、书等就下在电脑上；[AI 下载](/faq/ai-download)也能交给电脑办。
- 电脑上的 Galgame 可以[串流到 Android 手机](/faq/galgame#手机上玩电脑里的游戏)上玩、查词。

**进度和统计自动同步**

- 阅读 / 观看进度、阅读与观看时长、查词与制卡计数、收藏的词和句子，两边**双向合并**（「与已配对设备共享」里的两个开关，默认开）。

**手机往电脑传**

- **上传到互联对端** 里有书籍 / 词典 / 有声书 / 视频四个开关，**默认全关**：想把手机上的东西同步给电脑再勾对应那个。
- **用互联做备份后端**：把云备份那条通道也指到电脑上，不用云盘。

## 电脑当客户端也可以

角色不是绑死的：家里台式机当主机、笔记本当客户端，笔记本上一样能流播台式机的番剧、用它的词典。只是一台设备不能同时既开主机服务又连别的主机——想换角色先把主机服务关掉。

## 没有电脑常开？用无头服务端

NAS / 家用服务器 / VPS 上可以跑 [fushi_server](https://github.com/hajisensai/Fushi/blob/develop/packages/fushi_server/README.md)：没有界面的 Fushi 主机，带 WebUI，手机和电脑都当它的客户端。配对方式一样（设置 → 互联 → 添加 `<host>:38765`，PIN 显示在它的终端和 WebUI「配对」页），还能把漫画整卷 OCR、字幕识别、番剧下载和追更、小说 / 漫画 / 有声书下载、AI 下载都丢给它跑，也能托管有声书音频库。

## 常见状况

- **局域网设备一直「未发现设备」**：确认同一个 Wi-Fi、电脑主机服务确实在「运行中」；路由器 AP 隔离 / 访客网络会挡广播，改手动填地址。
- **手动填了地址连不上**：端口 38765 有没有被电脑防火墙拦；`https://` 和 `http://` 有没有和主机的 TLS 开关对上。
- **切换了主机的 TLS 开关**：已配对设备要重新配对一次（主机页上有提示）。
- **远端视频加载失败**：对端设备是不是在线；电脑休眠了主机也就停了。在外面连不上的话，看看主机有没有填公网地址或打开 P2P 隧道。
- **想解除某台设备**：主机的 **主机服务 → 已配对设备 → 移除**；客户端侧在「已添加的对端」里删掉。
- **「重新配对」**：对端列表里每台设备都有这个按钮，token 出问题时点一下重走一遍配对即可。
