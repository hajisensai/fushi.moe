[连上 Anki](/faq/anki) 和[做出第一张卡](/faq/first-card)之后，Anki 本身还有几件事值得一开始就弄对。这些不是 Fushi 的设置，是 Anki 的。

## 1. 把算法换成 FSRS

Anki 内置了 **FSRS**——目前最好的间隔重复算法之一——但**默认没开**，不开就一直走三十多年前的 SM-2。FSRS 拿你的真实复习记录预测遗忘时点，同样的记忆效果复习量更少。

Fushi 的新手引导里有一步就是它（设置 → 系统 → 新手引导 → Anki）：

1. 桌面 Anki 点牌组右边的齿轮 → **选项**（AnkiDroid 2.17+ / AnkiMobile 长按牌组 → 选项）；
2. 滚到最底下的 **FSRS** 区块，把开关打开——对整个收藏生效，开一次就够；
3. 点 **优化** 再保存。复习记录不到一千条时默认参数已经比 SM-2 准，攒够了再优化一次。

开了 FSRS 以后**不要再手动干预排程**：某张卡排到几十天后是算法算出来的，不信它就别用它。按钮上显示的「下次复习时间」干扰你判断的话，在 Anki 设置里关掉显示。

## 2. 四个按钮只用两个

看到正面先回忆背面，翻过去检验，然后：

| 回忆结果 | 按 |
|---|---|
| 没想起来、想错了 | **重来**（按钮 1） |
| 费了不少劲才想起来 | 困难（按钮 2）——没答对就别按 |
| 比较轻松想起来 | **良好**（按钮 3），最常用 |
| 滚瓜烂熟 | 简单（按钮 4），很少用 |

拿不准就只用 **1 和 3**。「困难」和「简单」按错的代价比不按大。

## 3. 正面不放发音

卡片正面只放**词**（Lapis 模板默认就是这样）。正面放了发音，你复习的就不是「看到这个词能不能想起读音和意思」，而是「听到读音能不能想起意思」——前者才是你在字幕和书里遇到它的场景。发音放背面，翻过去再听。

## 4. Fushi 这边能帮上的

- **按词频重排新卡**：Fushi 的 Anki 设置里有「按词频重排新卡」，用你装的词频词典（或 Lapis 的 FreqSort 字段）把新卡按常用程度排序——先背常见词，罕见词往后放。做了一堆卡之后跑一次。
- **几句合一张卡**：视频里一句台词跨了两三条字幕，在字幕列表里**多选**再制卡，句子和音频按整段截；查词时也会把相邻的字幕句合并。
- **一天做多少**：宁少勿多。每天十几张新卡、坚持看下去，比某天做一百张然后第二天不想打开 Anki 强。什么词值得做卡见[第一张卡](/faq/first-card#什么词值得做卡)。
- **卡的模板**：Fushi 一键创建的牌组用 Lapis 模板，字段映射在 Fushi 的 Anki 设置里改；自己有模板的也能映射过去。

## 常见状况

- **卡组导入报错**：多半是从第三方站下的旧版 Anki，去 [apps.ankiweb.net](https://apps.ankiweb.net/) 装官方版。
- **卡进了错的牌组 / 字段是空的**：Fushi 的 Anki 设置里看牌组和字段映射；换过笔记类型要重新映射。
- **手机上做的卡想进电脑的 Anki**：用 [Fushi 互联](/faq/interconnect)的「制卡到 Fushi 互联服务端」。
