## Anki 是什么

**Anki**（取名自日语「暗記」）是一个免费的**间隔重复**（SRS）记忆软件：你把想记的东西做成卡片，它算出每张卡快要忘的时候再让你复习——记得牢的越来越少出现，记不住的反复出现。用最少的复习时间换最好的记忆效果，是沉浸学习里唯一必须的"主动学习"工具。

Fushi 和它的关系：**Fushi 负责产卡，Anki 负责复习**。看番、读书时点词查到的东西，点加号就做成一张带例句、原声、截图的卡送进 Anki；每天打开 Anki 把到期的卡过一遍。两个软件各干各的，Fushi 不做复习。

## 装哪个

| 设备 | 装什么 | 说明 |
|---|---|---|
| Windows / macOS / Linux | **Anki 桌面版** | 去官网 [apps.ankiweb.net](https://apps.ankiweb.net/) 下，免费；再装 [AnkiConnect](https://ankiweb.net/shared/info/2055492159) 插件，Fushi 靠它送卡 |
| Android | **AnkiDroid** | Google Play 或 [GitHub](https://github.com/ankidroid/Anki-Android/releases)，免费 |
| iOS / iPadOS | **AnkiMobile** | App Store，付费买断（几十美元），是官方给开发筹经费的方式 |

**只从官网和上面这几个地方下。** 国内搜「Anki 下载」排前面的往往是第三方站放的**多年前的旧版**——最常见的后果就是：别人分享的卡组（`.apkg`）一导入就报错、Fushi 建的 Lapis 牌组认不出来、FSRS 找不到开关。装错了就卸掉，去官网重装，数据不会丢（卡在 `collection.anki2` 里，重装会保留；不放心先在 Anki 里「文件 → 导出」备份一次）。

多设备同步：注册一个免费的 **AnkiWeb** 账号，桌面和手机都登录，每次复习完点同步。电脑上 Fushi 做的卡，手机上就能复习。

## 卡片长什么样

Fushi 一键创建的牌组用 **Lapis** 模板（沉浸学习圈最常用的日语卡模板之一）。一张卡分两面：

**正面**：只有一个词。

```
   気配
```

你要做的是：看着这个词，回忆它的读音和意思。**正面故意什么都不放**——没有例句、没有发音——因为你在字幕和书里遇到它时也只有这个词。

**背面**（翻过去之后，从上到下）：

- 词 + 振假名 + **音调**标记（高低音在哪个位置）；
- **发音**：单词的读音音频，来自你的发音库；
- **例句**：你制卡时那句台词 / 那行文字，词在句里高亮，旁边是那一幕的**截图**和这一句的**原声**；
- **释义**：你选的那本词典的解释（默认日日在前）；
- 词频等辅助信息。

例句、图片、音频在背面的位置和高亮样式，在 Fushi 的 **Anki 设置** 里的 Lapis 外观选项里调，不用碰 Anki 的模板代码。Lapis 模板本身还支持「正面显示整句、猜句中加粗的词」的句子卡，那是模板字段层面的开关，进阶再折腾。

## 每天怎么复习

1. 打开 Anki，点 Fushi 建的那个牌组。
2. 它会按顺序给你**今天到期的旧卡**和**一定数量的新卡**（默认每天 20 张新卡，可以在牌组选项里改；建议 10–20，坚持比数量重要）。
3. 每张卡：看正面回忆 → 翻面 → 按「重来」或「良好」（怎么按见[Anki 怎么用](/faq/anki-basics)）。
4. 牌组显示 0 就完事，一般 15–30 分钟。做多了就减新卡，别停。

**卡片来源始终是你自己看的东西**。不要去下别人的"N1 词汇卡组"当主力——那些词没有你的上下文，背起来又慢又枯燥；唯一的例外是入门时的 [Kaishi 1.5k](/zh-cn/immersion) 这种为零基础准备的启动卡组。

## 常见状况

- **卡组导入报错 / 「文件格式不支持」**：装的是第三方站的旧版 Anki，去官网重装最新版。
- **Fushi 说连不上 Anki**：桌面版要开着 Anki 且装了 AnkiConnect；手机看[连接 Anki](/faq/anki)。
- **卡进了但是空的 / 字段错位**：Fushi 的 Anki 设置里重新映射字段，或直接让 Fushi 重建 Lapis 牌组。
- **复习堆到几百张**：降新卡数、开 [FSRS](/faq/anki-basics)，然后照常做——积压是习惯断了的结果，不是软件的问题。
