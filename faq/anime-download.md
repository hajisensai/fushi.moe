Fushi 里看番有两条路，各有各的用处：

| | 在线看（视频源扩展） | 下载 |
|---|---|---|
| 怎么来 | 装 Aniyomi 视频源扩展，点开即播 | 搜作品 → 挑资源（BT）→ 下载 → 自动入库 |
| 字幕 | 线路自带什么就是什么，不一定有日语 | 自动匹配 [Jimaku](https://jimaku.cc) 日语字幕，逐集配对 |
| 入库 / 离线 | 可以加入媒体库、下载到本机 | 入库，按作品归组，元数据自动刮削 |
| 追更 | 手动翻新集 | 订阅，新集自动下载入库 |
| 适合 | 随手找一部看看 | 认真沉浸 + 制卡 |

学日语要点词制卡的话，**优先走下载**：生肉 + Jimaku 字幕这一对是查词制卡最顺的组合。在线看的用法见[怎么用视频源在线看番剧？](/faq/anime-online)，下面说下载。

**Windows、macOS、Android 可用；iOS 版按 App Store 规定没有搜索和下载功能。**

## 找作品

底栏 **浏览 → 发现**（视频库的「发现」子标签也一样），在搜索框里搜电影、剧集、动漫，或者从热门推荐、本季动漫、放送日历里挑。点进作品页：

- **搜索资源**：Fushi 用作品的原名 / 别名去各个资源索引一起搜——动漫走 Nyaa，电影剧集走 apibay / Knaben，再加上你自己的 Torznab 索引器（见[BT 那篇](/faq/bittorrent)）。结果按发布组和分辨率归成一个个「版本」，也可以切到「全部条目」看原始列表。
- **订阅**：还在播的番，按选定的发布组和分辨率追新集。
- **搜索字幕**：单独给这部作品找字幕。
- **⋯ → 让 AI 帮我下**：说一句话让 AI 找作品、挑版本，见[AI 下载是什么？](/faq/ai-download)。

已经入库的合集里补缺集、或者从「相关作品」去下载时，会打开 **番剧下载** 对话框：先在 AniList 选中作品，「Nyaa 查询词」自动填好原名，结果可以按 **生肉 / 英译 / 非英译** 筛（学日语选生肉）、勾 **仅可信** 只看可信发布者、按 **做种数 / 发布时间 / 体积** 排序，整季打包的标「合集」。

搜不到东西多半是查询词的问题，见[搜不到番剧？](/faq/search-tips)。

## 下载

选好版本点下载就进任务队列，在 **浏览 → 下载** 里看进度。Fushi 内置 libtorrent，不用另开下载器；也可以外接 qBittorrent，「推送下载」交给它。

- **边下边播**：任务开始后可以先入库，从视频库打开边下边播。
- 下载完成自动入库，按作品 / 文件夹归组，元数据自动匹配。
- 上传（做种）默认关闭；想回馈网络就在下载设置里打开「启用上传 / 做种」。
- 手上有磁力链接或种子文件：**浏览 → 下载** 右上角的 **添加任务**，粘贴磁力链接或「选择种子文件」；桌面端也可以直接把 `.torrent` 文件拖进窗口。
- 配了 [Fushi 互联](/faq/interconnect)的话，「下载到」可以选互联主机，让电脑或 Fushi 服务端替手机下。

## 字幕

下载时选 **附带字幕**（或「必须有字幕」），Fushi 会到 Jimaku 自动匹配这部番的日语字幕，下载完成后按包内文件逐集配对；视频里本来带内嵌字幕轨的话，还会按它自动校正时间轴。要先在 **设置 → 在线服务 → 字幕来源** 里填 Jimaku API 密钥（在 Jimaku 网站免费申请）。匹配不上的集可以手动补一条。

有了字幕，播放时点字幕上的词就能查词，点加号制卡，卡上带这一句的画面和原声。

## 追更

在作品页或搜索结果里 **订阅**：「追更」会定期检查新集，命中后自动排队下载入库；「单次」只下当前这一批。逐集状态在 **浏览 → 下载 → 订阅** 里看。

已经有视频文件？不用搜，直接从本地文件夹或 WebDAV 等远程来源导入视频库即可。
