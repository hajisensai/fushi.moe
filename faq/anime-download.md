Fushi 里看番有两条路，各有各的用处：

| | 在线看（视频源扩展） | 下载（番剧下载） |
|---|---|---|
| 怎么来 | 装 Aniyomi 视频源扩展，点开即播 | 搜作品名（Nyaa）→ 种子下载 → 自动入库 |
| 字幕 | 线路自带什么就是什么，不一定有日语 | 自动匹配 [Jimaku](https://jimaku.cc) 日语字幕，逐集配对 |
| 离线 / 入库 | 不入库，暂不能下载 | 入库，按作品归组，元数据自动刮削 |
| 追更 | 手动翻新集 | 订阅，新集自动下载入库 |
| 适合 | 随手找一部看看 | 认真沉浸 + 制卡 |

学日语要点词制卡的话，**优先走下载**：生肉 + Jimaku 字幕这一对是查词制卡最顺的组合。在线看的用法见[怎么用视频源在线看番剧？](/faq/anime-online)，下面说下载。

**Windows、macOS、Android 可用；iOS 版按 App Store 规定没有搜索和下载功能。**

## 搜索

底栏 **下载** → 番剧下载，在上面输入作品名搜索（数据来自 Nyaa）。结果可以：

- 按 **生肉 / 英译 / 非英译** 筛——学日语选生肉；
- 勾 **仅 Trusted** 只看可信发布者；
- 按 **做种数 / 发布时间 / 体积** 排序；整季合集会标成「合集」。

站点连不上时，在下载设置里配一下网络代理。

## 下载

点 **下载** 就进任务队列，Fushi 内置 libtorrent，不用另开下载器；装了 qBittorrent 的话也可以「推送下载」交给它。

- **边下边播**：任务开始后可以先入库，从视频库打开边下边播。
- 下载完成自动入库，按作品 / 文件夹归组，元数据自动匹配。
- 上传（做种）默认关闭；想回馈网络就在设置里打开。
- 有磁力链接的话直接 **粘贴链接下载**。

## 字幕

搜索时勾上 **附带字幕**，Fushi 会到 Jimaku 自动匹配这部番的日语字幕，下载完成后按包内文件逐集配对。要先在 **设置 → 服务** 里填 Jimaku API key（在 Jimaku 网站免费申请）。匹配不上的集可以手动补一条。

有了字幕，播放时点字幕上的词就能查词，点加号制卡，卡上带这一句的截图和原声。

## 追更

在搜索结果里 **订阅**：「追更」模式会定期检查新集，命中后自动排队下载入库；「单次」只下当前这一批。逐集状态在订阅页看得到。

已经有视频文件？不用搜，直接从本地文件夹或 WebDAV 导入视频库即可。
