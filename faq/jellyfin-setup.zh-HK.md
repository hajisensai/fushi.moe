家裡有 Jellyfin、Emby 或 Plex 的話，不用把番劇再拷一份到 Fushi 裡：登入一次，伺服器上的影片直接在 Fushi 裡播，該點詞點詞、該制卡制卡。Jellyfin 和 Emby 的介面是一套，下面的步驟兩家通用；Plex 見文末。（不知道它們是什麼？先看[Jellyfin、Emby、Plex 是什麼](/faq/media-servers.zh-HK)。）

## 準備

- 伺服器已經裝好、掃過庫，能在它自己的網頁或 app 裡看到番劇。
- 知道伺服器地址：區域網裡一般是 `http://192.168.x.x:8096`（Jellyfin 和 Emby 預設埠都是 8096；開了 HTTPS 的 Jellyfin 是 8920，反代過的就是你自己的域名）。手機上用 IP 地址，Android / iOS 解析不了 `.local` 或 Windows 計算機名。
- 一個伺服器上的賬號（使用者名稱 + 密碼）。Emby 用 Emby Connect 登入的話，要在伺服器上給這個使用者設一個本地密碼。

## 第 1 步：登入

**設定 → 線上服務 → Jellyfin · Emby**

1. **新增伺服器**，**伺服器地址** 填上面那個地址。中文輸入法下注意冒號和點別打成全形。
2. 填使用者名稱、密碼，點 **登入**。成功後它出現在「已登入的伺服器」裡。可以登入好幾臺伺服器。

登入用的令牌存在本機；**退出登入** 會刪掉它和這臺伺服器的快取。

同一臺伺服器有好幾個地址（區域網、公網、反代）的話，在它的 **線路** 裡「新增線路」，之後隨時切換，登入狀態在每條線路上通用。

## 第 2 步：在「媒體伺服器」分割槽裡看

影片庫頂上有一個 **媒體伺服器** 分割槽：選伺服器 → 媒體庫 → 劇 → 季 → 集，按伺服器自己的目錄一層層瀏覽，也能「搜尋此伺服器」。點一集：

- **直接串流**：不轉碼，伺服器把原檔案流過來，Fushi 用自己的播放器解，所以 HEVC / 10-bit / mkv 都不挑；
- **字幕**：伺服器上這條影片的文本字幕（外掛 `.srt` / `.ass`，或 mkv 裡的文本軌）會自動取下來當外掛字幕載入，**能點詞、能制卡**；PGS 這類圖形字幕軌沒有文字，要靠 OCR，見[外掛、內封、內嵌字幕](/faq/subtitle-types.zh-HK)。伺服器上沒日語字幕的，和本地影片一樣手動匯入一份或讓 Jimaku 配。
- **進度雙向同步**：看到哪伺服器就記到哪（和 Jellyfin 網頁端一樣每 10 秒報一次），Fushi 裡也讀伺服器上的斷點——手機 Jellyfin app 看了一半，Fushi 開啟接著播；反過來也一樣。
- **下載到本機**：想離線看、或者要匯出片段，卡片選單裡下載整個檔案；匯出片段只對本機檔案可用。
- 線上流制卡會慢一些，「設定 → 制卡 → 線上影片制卡」可以選後臺製卡或看完再製卡，見[線上看番那篇](/faq/anime-online.zh-HK#線上影片制卡)。

## 想和本地影片混在一起看

預設媒體伺服器的條目只在「媒體伺服器」分割槽裡。想讓它們和本地影片一起出現在首頁、系列、全部影片裡，開啟伺服器設定裡的 **在影片庫中混排顯示**，再按需調兩項：

- **要列出的媒體庫**：不勾 = 列出全部影片庫。伺服器很大（幾萬條以上、或者是公共服）就**只勾你真正會看的那一兩個庫**——混排要把清單一頁頁翻下來，整臺伺服器列舉一遍既慢，也容易被伺服器當成濫用。
- **進入影片頁時自動列出條目**：超大伺服器建議關掉，改成在影片庫裡**下拉重新整理**時才列。

## Plex

**設定 → 線上服務 → Plex**：**使用 Plex 賬號登入**（瀏覽器裡授權 Fushi，賬號下能連上的伺服器自動加進來），或者 **手動連線**，填伺服器地址和 X-Plex-Token。之後同樣在「媒體伺服器」分割槽裡瀏覽；播放直接串流原檔案，不用 Plex 轉碼。

## 常見狀況

- **登入失敗**：先在手機 / 電腦瀏覽器裡開啟同一個地址確認能進；地址要帶埠；反代 + HTTPS 的寫 `https://`；Jellyfin / Emby 的使用者名稱密碼是伺服器賬號，不是 Emby Connect 那種雲賬號。
- **列表是空的**：庫型別不是影片（Jellyfin 裡庫型別要是 電影 / 劇集 / 混合內容）；混排模式下還可能是「自動列出」關著——下拉重新整理一下。
- **混排只列出了一部分**：幾十萬條的伺服器會觸發翻頁熔斷，Fushi 會提示拿到的不是全部；勾少幾個庫，或者直接用「媒體伺服器」分割槽瀏覽。
- **伺服器拒絕了本應用的訪問**：有的伺服器只允許特定客戶端，找伺服器管理員。
- **不想裝伺服器**：電腦上的 Fushi 自己就能當主機，見[Fushi 互聯](/faq/interconnect.zh-HK)。
