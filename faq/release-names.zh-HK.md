在 Nyaa 或者 Fushi 的番劇下載裡搜一部番，會出來一長串標題差不多、後面一堆方括號的結果。它們各說了什麼、學日語該挑哪個，這篇講清楚。

## 生肉 / 熟肉

- **生肉（Raw）**：沒有翻譯字幕的原片。可能完全沒字幕，也可能帶日語字幕（CC 字幕、藍光自帶）。
- **熟肉**：帶翻譯（中文、英文…）字幕的版本。字幕可能是[外掛、內封或內嵌](/faq/subtitle-types.zh-HK)。

學日語**要生肉**：翻譯字幕在畫面上會不自覺去讀，學不到東西。生肉配一份日語字幕（Fushi 能從 [Jimaku](https://jimaku.cc) 自動配）是查詞制卡最順的組合。Fushi 番劇下載裡的「生肉 / 英譯 / 非英譯」篩選就是按這個分的。

## 來源：BDRip、WEB-DL、TVRip

| 縮寫 | 來自 | 特點 |
|---|---|---|
| **BDRip / BDMV / Remux** | 藍光碟 | 畫質最好，無修正、無臺標；播出結束幾個月後才有 |
| **WEB-DL / WEBRip** | 流媒體（Crunchyroll、Netflix、B 站…） | 播出當天就有，畫質中等；常帶該平臺的字幕 |
| **TVRip / HDTV** | 電視臺錄製 | 最早出，有臺標、跑馬燈、可能有和諧光 |

- **BDMV** 是藍光原盤目錄，幾十 GB；**Remux** 是把原盤的流原樣重新封裝成 mkv，不重新壓制，畫質等於原盤、體積還是很大；**BDRip** 是壓制過的，一集一兩 GB，最常見。
- **WEB-DL** 是直接從流媒體拿下來的流，**WEBRip** 是錄屏或二壓，稍差一點。
- 資源名裡的 **CR / NF / AMZN / B-Global** 指來源平臺（Crunchyroll、Netflix、Amazon、Bilibili 國際版）。

## 畫質那一段

`1080p`、`x265`、`Hi10P`、`FLAC` 這些講畫面編碼和音軌，見[影片的這些詞是什麼意思](/faq/video-basics.zh-HK)。簡單說：

- 挑 **1080p** 或 **720p** 都行，動畫原生解析度通常不到 1080p；
- **x265 / HEVC** 體積小，老裝置可能解不動，那就選 x264；
- **10-bit** 色彩更細膩，手機硬解要看支援。

## 釋出組

方括號裡最前面一般是釋出組的名字。BDRip 界的老牌組（VCB-Studio、Moozzi2、Beatrice-Raws…）以畫質穩定出名；字幕組（各種 Sub）出的是熟肉；**Erai-raws、SubsPlease** 這類是搬運流媒體 WEB 版的組，出得最快，通常帶多語言外掛字幕。

## 字幕標記

- **CHS / CHT / JPN / ENG**：字幕語言，簡中 / 繁中 / 日 / 英；
- **Multi-Subs**：多語言字幕；**Dual Audio**：雙音軌（一般是日語 + 英語配音）；
- **CC**：Closed Caption，為聽障觀眾做的同語言字幕，會寫出「（ドアの音）」這類環境音。日本流媒體的日語 CC 字幕對學日語很好用。

## 合集與做種

- **Batch / 合集**：整季打包一個種子，Fushi 番劇下載會標「合集」。追完結的番直接下合集最省事。
- **做種數（Seeders）**：越多下得越快；幾年前的老資源可能沒人做種，下不動就換一個。
- **Trusted**：Nyaa 認證過的可信釋出者，Fushi 搜尋裡可以只看它們。

## 學日語怎麼挑

按這個順序：

1. **生肉**優先，有日語 CC 字幕的 WEB 版更好；
2. 完結番選 **BDRip 合集**，追更選 **WEB-DL**；
3. 解析度 1080p / 720p 隨意，裝置老就避開 x265 和 10-bit；
4. 下載時勾上 Fushi 的「附帶字幕」讓 Jimaku 自動配日語字幕——BD 版和 WEB 版的字幕時間軸可能不一樣，配錯了看[字幕對不上怎麼辦](/faq/subtitle-sync.zh-HK)。

下載的具體操作見[番劇是線上看還是下載？](/faq/anime-download.zh-HK)。
