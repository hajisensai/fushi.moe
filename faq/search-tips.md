搜「葬送的芙莉莲」什么都没有，不是没资源，是**索引站不认中文**。

## 资源标题长什么样

Fushi 接的 Nyaa（动漫）、apibay / Knaben（影视）这些索引站是全世界发布者共用的，标题里的作品名以**罗马音**为主，其次是日文：

```
[SubsPlease] Sousou no Frieren - 01 (1080p) [ABCD1234].mkv
[VCB-Studio] 葬送のフリーレン [01][Ma10p_1080p][x265_flac].mkv
Frieren - Beyond Journey's End S01E01 ...
```

同一部番可能三种写法都有，但**罗马音出现得最多**，字幕组发布也大多带罗马音。中文译名只在少数国内字幕组的标题里出现，靠它搜等于漏掉九成资源。

## 在 Fushi 里怎么搜

**番剧下载**是两步：先搜**作品**，再搜**资源**。

1. 第一步的作品搜索走 AniList，中文、日文、英文、罗马音都能搜到作品条目；
2. 选中作品后，下面的 **Nyaa 查询词** 会自动填成这部作品的**原名 / 别名**（罗马音和日文），直接搜就行。

结果太少或太杂时再自己改查询词，几条经验：

- **罗马音优先**：`Sousou no Frieren`、`Kimetsu no Yaiba`。AniList 页面上的 "Romaji" 标题就是索引站最常用的写法。
- **日文原名其次**：`葬送のフリーレン`，日本 BD 组和部分字幕组用它。
- **英文官方名再次**：`Frieren: Beyond Journey's End`，流媒体抽出的 WEB 版常用。
- **简称能搜到更多**：`Frieren` 比全名命中多；太短又会混进别的，看情况。
- **不要带季数、集数写法**：`第二季`、`S2` 这类各家写法不一，先搜作品名再在结果里筛。
- **中文只在最后试**：想找特定国内字幕组的熟肉时再用。

漫画在 Nyaa 上一样是罗马音 / 日文标题；书籍和有声书的目录搜索按各自来源的语言来（Jimaku 的字幕匹配同样走 AniList，所以作品选对了字幕一般不会配错）。

## 罗马音怎么写

不会写也不用背规则，两个办法：

- AniList / MAL 作品页的标题直接复制；
- 日文输入法里打出假名后看 Hepburn 式罗马音：し = shi、ち = chi、つ = tsu、ふ = fu、ん = n；长音一般省略（東京 = Tokyo）、の写 no、は作助词写 wa。索引站的标题偶尔也会用 si / ti / tu 之类的训令式，搜不到时换一种拼法。

## 常见状况

- **作品搜到了，资源是 0**：换短一点的查询词；很老或很冷的番做种数可能为 0，看[BT 那篇](/faq/bittorrent#常见状况)。
- **结果全是熟肉**：勾「生肉」筛选，或者在查询词后面加 `raw`。
- **漫画只搜到连载话，没有单行本**：Nyaa 上单行本一般写 `第01巻` / `v01`，用日文原名加 `巻` 试试。
