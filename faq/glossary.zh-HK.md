按主題分組，每個詞一兩句。帶連結的有整篇文章細講。

## 學習方法

- **沉浸（immersion）**：大量看、聽、讀自己感興趣的目標語言內容，從中習得語言，而不是背規則做題。Fushi 整個 app 就是為這件事造的，理論看[沉浸學習指南](/zh-hk/immersion)。
- **可理解輸入 / i+1**：內容難度剛好比你當前水平高一點點——大部分能懂、少數不懂——這種輸入最有效。選語料的標準。
- **主動學習 / 被動沉浸**：主動 = 查詞、做卡、複習；被動 = 開著番當背景聽。兩者都要，前者少而精，後者量大。
- **SRS（間隔重複）**：快忘的時候再複習的記憶法；實現它的軟體就是 Anki。
- **Anki**：免費的 SRS 軟體，Fushi 做的卡都送到這裡複習。[是什麼、裝哪個](/faq/anki-intro.zh-HK)。
- **FSRS**：Anki 內建的新一代排程演算法，預設沒開，[要手動開啟](/faq/anki-basics.zh-HK)。
- **制卡（mining / 挖詞）**：從正在看的內容裡把不認識的詞做成 Anki 卡片。Fushi 裡就是查詞彈窗上的加號。
- **牌組 / 卡組（deck）**：Anki 裡一組卡片；**筆記型別（note type）/ 模板**：決定一張卡有哪些欄位、正反面怎麼顯示。Fushi 預設用 **Lapis** 模板。
- **Kaishi 1.5k**：給零基礎準備的 1500 詞啟動卡組，背到能看懂簡單句子就開始沉浸。

## 日語相關

- **假名 / 五十音**：平假名、片假名各 46 個基本音，日語書寫的基礎，唯一必須先背的東西。
- **振假名（ふりがな / furigana）**：標在漢字上方的讀音小字。Fushi 的閱讀器和詞典都能顯示。
- **音調（アクセント / pitch accent）**：日語單詞裡音高的高低變化，比如「はし」高低不同是「箸」還是「橋」。查詞彈窗裡的音調標記、音調詞典說的就是它。
- **詞頻（frequency）**：一個詞在語料裡出現的頻繁程度，數字越小越常用。用來判斷值不值得做卡、[給新卡排序](/faq/anki-basics.zh-HK)。
- **日日 / 日中 / 日英 / 雙解**：詞典按解釋語言分類。日日 = 日語解釋日語（國語辭典），雙解 = 日語解釋外加翻譯。學到中期建議主用日日。
- **國語辭典**：日本人自己用的日語詞典（明鏡、大辭泉、新明解這類）。
- **羅馬音（romaji）**：用拉丁字母拼日語，`Sousou no Frieren`。[搜資源要用它](/faq/search-tips.zh-HK)。
- **生肉 / 熟肉**：沒翻譯字幕的原片 / 帶翻譯的版本，學日語要生肉。[更多資源名詞](/faq/release-names.zh-HK)。

## 查詞與詞典

- **查詞彈窗**：點詞後彈出的詞典視窗，釋義、音調、詞頻、發音、加號都在裡面。
- **Yomitan**：瀏覽器查詞擴充套件（前身 Yomichan），它的詞典格式成了事實標準，Fushi 直接用。[Shift 查詞是什麼](/faq/browser-lookup.zh-HK)。
- **Yomitan 詞典 / MDX / DSL**：Fushi 認的三種詞典格式，[怎麼匯入](/faq/dictionaries.zh-HK)。
- **推薦包**：新手引導裡一鍵下載的那 9.5 GB：詞典、音調、詞頻、發音庫。[能不能不裝](/faq/pack.zh-HK)。
- **發音庫 / 音訊來源**：查詞時點喇叭放的單詞讀音從哪來；本地發音庫和線上來源都可以配。
- **全域性查詞**：在別的應用裡選中文字，用快捷鍵（Windows）或文字選單（Android）叫出 Fushi 查詞。
- **變形還原**：把「食べなかった」還原成「食べる」再查。詞典按原形收詞，點到哪個形態都能查到靠的是它。

## 字幕與影片

- **外掛 / 內封 / 內嵌**：字幕放在影片旁邊的檔案裡 / 打包在 mkv 裡的軌 / 直接畫進畫面。[哪種能點詞](/faq/subtitle-types.zh-HK)。
- **SRT / ASS / VTT**：三種文本字幕格式。[區別](/faq/subtitle-formats.zh-HK)。
- **主字幕 / 副字幕**：Fushi 裡同時顯示的兩條字幕，主字幕用來點詞，副字幕當翻譯參考。[怎麼用副字幕過渡](/faq/secondary-subtitle.zh-HK)。
- **調軸**：把字幕整體提前或延後，讓它和聲音對上。[對不上怎麼辦](/faq/subtitle-sync.zh-HK)。
- **Jimaku**：社群維護的日語字幕站，Fushi 番劇下載能自動去配。
- **mkv / mp4、H.264 / HEVC、1080p、位元速率**：容器、編碼、解析度、清晰度。[影片的這些詞](/faq/video-basics.zh-HK)。
- **BDRip / WEB-DL / TVRip、字幕組、合集**：資源來源和釋出形式。[資源名怎麼看](/faq/release-names.zh-HK)。
- **刮削**：按檔名認出作品，去網上拉海報、簡介、集列表。[是什麼、怎麼用](/faq/scraping.zh-HK)。
- **後設資料（metadata）**：刮削拉回來的那些資料。**NFO**：把它們存在影片旁邊的檔案格式，Jellyfin / Kodi 也認。
- **Jellyfin / Emby / Plex**：媒體伺服器，裝在 NAS 上把影片串流給各裝置。[是什麼](/faq/media-servers.zh-HK)、[怎麼接](/faq/jellyfin-setup.zh-HK)。
- **串流 / 轉碼**：邊傳邊播 / 伺服器即時把影片轉成客戶端認的格式。

## 漫畫與書

- **OCR**：把圖片上的文字識別成文本。漫畫要先 OCR 才能點字查詞，Fushi 內建模型本機跑。[線上看漫畫](/faq/manga-online.zh-HK)。
- **mokuro / .mokuro**：一種帶 OCR 結果的漫畫格式（每頁文字的位置和內容），Fushi 的漫畫點字靠它；內建 Mokuro 目錄裡的漫畫已經帶好了。
- **EPUB / TXT**：Fushi 認的電子書格式；其他格式（mobi、azw3）用 Calibre 轉。
- **有聲書 / 對齊檔案**：朗讀音訊 + 一份把音訊和正文對上的字幕。[三者關係](/faq/audiobook.zh-HK)。
- **轉錄（ASR）**：讓機器聽音訊把文字寫出來。Fushi 用它給沒字幕的有聲書生成對齊檔案，全在本機。
- **匹配率**：有聲書的字幕在正文裡找到落點的比例，低了要調搜尋視窗。

## 線上源與下載

- **擴充套件（extension）/ 源（source）/ 倉庫（repo）**：擴充套件是一個 APK 檔案，裡面裝著若干線上源（某網站的介面卡）；倉庫是列出可安裝擴充套件的地址。Fushi 相容 **Mihon**（漫畫）和 **Aniyomi**（影片）的擴充套件。[怎麼裝](/faq/mihon.zh-HK)。
- **線路（hoster）**：影片源裡同一集的不同播放來源，畫質、可用性各異。
- **BT / 種子 / 磁力連結 / 做種 / Tracker / DHT**：[BT 那篇](/faq/bittorrent.zh-HK)全講了。
- **Nyaa**：最大的日本動漫資源索引站，Fushi 番劇下載的預設搜尋來源；**Torznab**：統一的索引站介面，Jackett / Prowlarr 提供。
- **qBittorrent**：常見的 BT 客戶端，Fushi 可以外接它。
- **訂閱 / 追更**：讓 Fushi 定期檢查有沒有新集，自動下載。
- **AniList / MAL / AniDB / VNDB / Bangumi**：作品資料庫，Fushi 用它們認作品、拉資料、記進度。

## Galgame

- **Galgame / 視覺小說（VN）**：以文字 + 立繪 + 語音推進的遊戲，沉浸材料裡資訊最全的一種。[怎麼接進 Fushi](/faq/galgame.zh-HK)。
- **hook / 文本鉤子**：從遊戲程序裡把正在顯示的臺詞抓出來。**特殊碼（H-code）**：針對某個遊戲手寫的抓取規則，引擎不認時用。
- **文本執行緒**：hook 抓到的各路文字流，要挑出乾淨的臺詞那一條。
- **轉區 / Locale Emulator**：讓不轉系統語言也能以日文區域啟動老遊戲，避免亂碼。
- **超分 / Magpie**：把低解析度的遊戲視窗放大到全屏的工具。

## Fushi 自己的

- **互聯**：Fushi 裝置之間的區域網直連，一臺當**主機**開放庫，其他當**客戶端**。[怎麼配](/faq/interconnect.zh-HK)。
- **fushi_server**：沒有介面的 Fushi 主機，跑在 NAS 上。
- **正式版 / 除錯版**：兩個下載渠道，除錯版先拿到新功能。[區別](/faq/channels.zh-HK)。
- **新手引導**：第一次啟動的配置嚮導，設定 → 系統 裡能重跑。
- **瀏覽器擴充套件**：Fushi 自帶的、在任意網頁查詞的擴充套件。[Shift 查詞](/faq/browser-lookup.zh-HK)。
- **雲備份 / 同步與備份**：把資料備份到 Google Drive / WebDAV 或本地檔案，[資料存在哪](/faq/data.zh-HK)。
