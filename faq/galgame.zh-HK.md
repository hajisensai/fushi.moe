Galgame 是幾乎完美的沉浸材料：有聲音、有畫面、有文本，而且文本是逐句給的。以前要 Textractor + Yomitan + ShareX / GSM 四五個工具串起來，Fushi 把這條鏈收進了一個模組（**僅 Windows**）。

## 第 1 步：把遊戲加進來

底欄 **遊戲** → **新增遊戲**，選遊戲的 exe；或者把 exe 直接拖進遊戲庫。加進來的遊戲會自動找封面（遊戲目錄 / 程式圖示），也可以 **刮削後設資料**，從 VNDB / Bangumi 拉簡介和封面（見[刮削](/faq/scraping.zh-HK)）。

## 第 2 步：啟動並捕獲

點 **啟動並捕獲**：Fushi 拉起遊戲，把自己的 hook 元件注入進去，開始收臺詞。遊戲已經開著的話用 **附著並捕獲**。

啟動時 Fushi 順手做兩件事：

- **日語區域**：判斷這個遊戲需不需要轉區（目錄 / 程式裡的 Shift-JIS 證據），需要就自動用內建的 Locale Emulator 以日文區域啟動——只支援 32 位遊戲。文字亂碼或指令碼報錯，可以在遊戲設定裡把「日語區域」改成始終 / 永不。
- **視窗超分**：老遊戲原生解析度低，可以在遊戲設定裡把「視窗超分」設為 **自動**，Fushi 用內建的 Magpie 把視窗放大到全屏（機器上已經在跑 Magpie 就用你的）。沒自動放大時按 **Win+Shift+A**。會佔顯示卡，每個遊戲各自設。

## 第 3 步：選臺詞執行緒

大多數引擎第一次會抓到好幾條**文本執行緒**（臺詞、人名、系統提示、逐字重複的偽影……），會話面板裡**選那條幹淨的臺詞執行緒**，捕獲才正式開始。標著「N 行有音訊」的通常就是對白執行緒；標「偽影」的不用管。

引擎不認（注入後超時沒文本）的遊戲，可以貼上 **特殊碼**（Textractor 那種 `/HQN4@4CE90:game.exe` 的 H-code，社群裡一般能找到；會繫結到這個 exe，下次自動複用）。特殊碼也沒有的，就是引擎還沒適配，等更新。

## 第 4 步：在浮窗裡讀、查、制卡

臺詞出現在 **臺詞浮窗** 裡，浮在遊戲視窗上：

- **點字查詞**，和閱讀器一樣彈詞典；
- **加號制卡**：卡上帶這句臺詞、**這句的原聲**、當時的截圖，直接進 Anki；
- 浮窗按鈕：跟隨新臺詞 / 鎖定位置 / 保持置頂 / 滑鼠穿透到遊戲 / 切換底板（透明成桌面歌詞式）/ 重播本句語音 / 重新錄製語音（漏錄了在遊戲裡重播一次）/ 開啟 **取材工作臺**（回看本局所有臺詞，挑句制卡）；
- 字型、字號、顏色、描邊、背景透明度都在 **設定 → Galgame 臺詞浮窗** 裡。

再進一步是 **遊戲內查詞**：不看浮窗，直接點遊戲畫面裡的字查詞。**KiriKiri（krkr）和 SiglusEngine 的大部分遊戲能直接用**，其他引擎要等適配。有的遊戲需要先校準一次正文區域（在遊戲裡依次點三個探針字形），另外裸左擊可能同時推進臺詞或觸發選項，Fushi 會先讓你確認風險、並且只對當前這個 exe 生效。會話面板的「遊戲內查詞」裡能看到當前引擎的狀態。

## 語音是怎麼來的

制卡的句子音訊優先取遊戲自己的語音（遊戲資原始檔或引擎的播放緩衝，乾淨、不帶 BGM），這兩條路都走不通時才錄系統混音兜底。沒配音的句子照常制卡，只是不帶音訊。

## 健康狀態

會話面板的 **健康狀態** 一眼看出哪一環沒接上：遊戲程序 / 遊戲視窗 / 文本來源 / 音訊來源 / Hook Helper / 視窗超分 / Anki 出卡。哪項紅了就點開看原因。

## 常見狀況

- **注入被攔截 / 元件沒回應**：把 Fushi 和遊戲加進防毒軟體白名單，檢查隔離區。
- **遊戲以更高許可權執行**：以管理員身份啟動 Fushi 再啟動遊戲。
- **元件位數不匹配 / 版本不一致**：完全關掉遊戲再開；還不行就重跑一次 Fushi 安裝程式（上次更新時遊戲開著，元件檔案沒換掉）。
- **注入了但沒文本**：引擎還沒支援，試特殊碼（上面第 3 步），沒有就等適配。
- **文字亂碼**：日語區域改成「始終開啟」；64 位遊戲不能轉區，裝個系統級的日文區域。
- **還殘留上一次的捕獲會話**：重啟一次遊戲。
- **視窗還沒出現，暫時無法截圖**：正常，窗口出現後自動繫結。
