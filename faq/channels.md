[下载页](/zh-cn/download)有两个**渠道**：

| | 正式版 | 调试版 |
|---|---|---|
| 更新节奏 | 攒一批改动再发，几周一次 | 每次代码合并后自动构建，几乎每天有新包 |
| 新功能 | 等下一个正式版 | **先在这里出现**——比如视频源扩展、互联刮削同步，都是先进调试版 |
| 稳定性 | 经过一轮测试 | 偶尔会撞上刚引入的 bug |
| 适合谁 | 只想安安静静看番的 | 想第一时间用新东西、遇到问题愿意到 Discord / QQ 群说一声的 |

## 怎么换

下载页顶部把渠道切到「调试版」，下载对应平台的包安装即可；调试版是每次代码合并后自动构建的，版本号带 `debug` 字样。换渠道前先在 **设置 → 同步与备份** 里导出一份备份——正常情况下数据是接着用的，但调试版可能已经用上正式版还没有的新数据格式，万一要退回正式版，有备份才稳。

## 用调试版的建议

- 常见问题里说「目前只在调试版」的功能，就是还没进正式版的意思，等下一个正式版发布会自动带上。
- 遇到问题先看是不是当天的包：调试版的 bug 通常第二天就修了，更新一下再试。
- 报 bug 时带上版本号（设置 → 关于）和复现步骤，去哪报见[反馈](/faq/feedback)。
- 备份不嫌多：设置 → 同步与备份 里导出一份，或者开云备份 / [互联备份](/faq/interconnect)。
