## 先說「Shift 查詞」

在 Fushi 的閱讀器和影片裡查詞，是**點**一下那個詞。但在瀏覽器網頁上，點選會觸發連結、按鈕、選中文字，沒法拿來查詞。所以瀏覽器查詞工具（[Yomitan](https://yomitan.wiki/)、以前的 Yomichan）用的是另一套習慣：

> **按住 Shift，把滑鼠移到詞上**，詞典就彈出來；鬆開 Shift、移開滑鼠，彈窗關掉。不用點、不用選。

用過 Yomitan 的人對這個動作有肌肉記憶；沒用過的第一次會以為擴充套件裝壞了——它在等你按 Shift。

Fushi 裡三種地方，觸發方式不一樣：

| 在哪 | 怎麼查 |
|---|---|
| app 內閱讀器、本地影片 / 番劇字幕、漫畫 | **點選**詞（桌面還可以在設定裡開「懸停即查詞」，滑鼠停上去就查） |
| 內建網頁播放器裡的 **Fushi 字幕** | **Shift 懸停** 和 **點選** 都行 |
| 瀏覽器擴充套件（任意網頁） | 只有 **Shift 懸停** |

## 瀏覽器擴充套件：在任意網頁查詞

Fushi 自帶一個瀏覽器擴充套件，讓你在任何網頁上用 app 裡的詞典查詞、制卡。桌面專用（Windows / macOS），Chrome / Edge 這類 Chromium 瀏覽器；手機瀏覽器裝不了擴充套件，手機上直接在 app 內讀。

### 安裝

**設定 → 瀏覽器擴充套件**，跟著頁面上的步驟走：

1. 點 **準備擴充套件檔案**。Fushi 會自動開啟查詞服務（Yomitan API 伺服器），把擴充套件解壓到本機，並把資料夾路徑複製到剪貼簿。
2. 在瀏覽器位址列開啟 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 開啟右上角的 **開發者模式**。
4. 點 **載入已解壓的擴充套件程式**，貼上剛才複製的路徑，選那個資料夾。
5. 回 Fushi 點 **檢測連線**，顯示「外掛已連線」就好了。擴充套件不需要再配任何東西，連線資訊已經自動寫好。

不放心的話點 **開啟試用網頁**：Fushi 自己提供的一張網頁，右上角點擴充套件圖示應該彈面板，按住 Shift 移到練習句的詞上應該彈詞典。

### 使用

- **按住 Shift，滑鼠移到詞上** → 彈出和 app 裡一樣的詞典彈窗（同一套詞典、同一個排版）。
- 彈窗裡點 **加號** 就制卡，整句會自動帶上，卡進你連的 Anki。
- 釋義裡還有不認識的詞，繼續 Shift 移上去，巢狀查。
- 彈窗大小在 **設定 → 查詞** 裡的「擴充套件彈窗最大寬度 / 高度」調，可以和 app 內彈窗分開設。

### 裝不上 / 沒反應

- **「查詞服務未開啟」**：設定 → 瀏覽器擴充套件裡先開「Yomitan API 伺服器」，或者再點一次「準備擴充套件檔案」。
- **埠 19633 被佔用**：多半是你之前裝的 Yomitan 拉起的 yomitan-api 元件（一個 Python 程序）。Fushi 會提示，可以直接結束它，或在 Yomitan 進階設定裡關掉 Yomitan API 再重開 Fushi 的伺服器。
- **「瀏覽器中載入的擴充套件不是最新版本」**：Fushi 更新後擴充套件檔案也更新了，去 `chrome://extensions` 點那個擴充套件的「重新載入」。
- **某些網頁取不到詞**：文字是畫在 canvas 上或者嵌在圖片裡的頁面（一些漫畫站、PDF 預覽）擴充套件沒法取字，屬正常。
- Fushi 關了擴充套件也就斷了——它查的是本機 Fushi 的詞典。

## 內建網頁播放器：看網頁影片

流媒體、B 站、YouTube 這類網頁影片，不用下載也能在 Fushi 裡邊看邊查：**影片 → 匯入**，貼上網頁地址（不是直鏈），會用內建網頁播放器開啟。

- **播放模式**：**內建**（1080p，可超分、可截圖制卡）或 **原生視窗**（4K、硬體 DRM 的站點用這個；制卡先排隊，之後「切到內建模式製作排隊卡片」一次做完）。
- **字幕軌**：Fushi 即時採集頁面上的字幕，渲染成自己的一層——這一層就是上表說的「Fushi 字幕」，**Shift 懸停和點選都能查詞**。開 **隱藏站點字幕**，就只剩 Fushi 這層。
- 站點本身沒字幕、或者字幕是畫在畫面裡的，採集不到，那就只剩 Shift 查網頁上別的文字。

## 已經在用 Yomitan？

兩邊可以共存，也可以只留一邊：

- **繼續用 Yomitan 查網頁**沒問題，Fushi 的擴充套件只是多一個選擇；兩者都用 Shift，裝在一起會各彈各的，建議網頁查詞只留一個。
- 想讓 **GameSentenceMiner 之類走 yomitan-api 協議的工具** 改查 Fushi 的詞典：開 Fushi 的 Yomitan API 伺服器（埠 19633，可設金鑰），把工具指向它。
- Textractor / LunaTranslator / mpv 這類抓文本的工具，可以直接把文本推給 Fushi 的 texthooker（設定裡連它們的 WebSocket），在 Fushi 裡逐詞點查、制卡，不再需要 texthooker 網頁 + Yomitan 那一套。

## 瀏覽器之外

- **Windows 全域性查詞**：在任何應用裡拖選一個詞，按快捷鍵（設定 → 快捷鍵 → 全域性），查詞卡片在滑鼠旁彈出。
- **Android 全域性查詞**：在其他應用里長按選中文字，文字選單裡點 Fushi（沒有就走分享），彈窗蓋在原應用上。
