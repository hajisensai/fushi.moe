## 先說「Shift 查詞」

在 Fushi 的閱讀器和影片裡查詞，是**點**一下那個詞。但在瀏覽器網頁上，點選會觸發連結、按鈕、選中文字，沒法拿來查詞。所以瀏覽器查詞工具（[Yomitan](https://yomitan.wiki/)、以前的 Yomichan）用的是另一套習慣：

> **按住 Shift，把滑鼠移到詞上**，詞典就彈出來；鬆開 Shift、移開滑鼠，彈窗關掉。不用點、不用選。

用過 Yomitan 的人對這個動作有肌肉記憶；沒用過的第一次會以為擴充套件裝壞了——它在等你按 Shift。

Fushi 裡三種地方，觸發方式不一樣：

| 在哪 | 怎麼查 |
|---|---|
| app 內閱讀器、影片 / 番劇字幕、漫畫 | **點選**詞（桌面還可以在 設定 → 查詞 裡開「懸停即查詞」，滑鼠停上去就查） |
| 影片網站上，擴充套件疊在影片上的 **Fushi 字幕** | **點選** 和 **Shift 懸停** 都行（擴充套件設定裡開「懸浮字幕自動查詞」就不用按 Shift） |
| 瀏覽器擴充套件（任意網頁的文字） | **Shift 懸停** |

## 瀏覽器擴充套件：在任意網頁查詞

Fushi 自帶一個瀏覽器擴充套件，讓你在任何網頁上用 app 裡的詞典查詞、制卡。桌面專用（Windows / macOS），Chrome / Edge 這類 Chromium 瀏覽器；手機上直接在 app 內讀。

### 安裝

**設定 → 查詞 → 外部整合 → 瀏覽器擴充套件**，跟著頁面上的步驟走：

1. 點 **準備擴充套件檔案**。Fushi 會自動開啟查詞服務（Yomitan API 伺服器），把擴充套件解壓到本機，並把資料夾路徑複製到剪貼簿。
2. 在瀏覽器位址列開啟 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 開啟右上角的 **開發者模式**。
4. 點 **載入已解壓的擴充套件程式**，貼上剛才複製的路徑，選那個資料夾。
5. 回 Fushi 點 **檢測連線**，顯示「外掛已連線」就好了。擴充套件不需要再配任何東西，連線資訊已經自動寫好。

不放心的話點 **開啟試用網頁**：Fushi 自己提供的一張網頁，右上角點擴充套件圖示應該彈面板，按住 Shift 移到練習句的詞上應該彈詞典。

### 使用

- **按住 Shift，滑鼠移到詞上** → 彈出和 app 裡一樣的詞典彈窗（同一套詞典、同一個排版）。
- 彈窗裡點 **加號** 就制卡，整句會自動帶上，卡進你連的 Anki。
- 釋義裡還有不認識的詞，繼續 Shift 移上去，巢狀查。
- 彈窗大小在 **設定 → 查詞** 裡的「擴充套件彈窗最大寬度 / 高度」調，可以和 app 內彈窗分開設。

### 裝不上 / 沒反應

- **「查詞服務未開啟」**：在瀏覽器擴充套件那一頁先開「Yomitan API 伺服器」，或者再點一次「準備擴充套件檔案」。
- **埠 19633 被佔用**：多半是你之前裝的 Yomitan 拉起的 yomitan-api 元件（一個 Python 程序）。Fushi 會提示，可以直接結束它，或在 Yomitan 進階設定裡關掉 Yomitan API 再重開 Fushi 的伺服器。
- **「瀏覽器中載入的擴充套件不是最新版本」**：Fushi 更新後擴充套件檔案也更新了，去 `chrome://extensions` 點那個擴充套件的「重新載入」。
- **某些網頁取不到詞**：文字是畫在 canvas 上或者嵌在圖片裡的頁面（一些漫畫站、PDF 預覽）擴充套件沒法取字，屬正常。
- Fushi 關了擴充套件也就斷了——它查的是本機 Fushi 的詞典。

## 網頁影片：擴充套件的 Fushi 字幕

流媒體、YouTube 這類網頁影片，擴充套件可以直接在瀏覽器裡幫你邊看邊查：

- **在影片上顯示 Fushi 字幕**：把當前字幕軌疊在影片上，點詞或 Shift 懸停就查；字幕可以拖到任意位置、調大小；YouTube 自動字幕這類逐詞蹦出來的，開「替代站點原生字幕」改成按整句顯示。字幕外觀（字型、顏色、底板）在擴充套件設定裡改，字型可以用 Fushi 字型庫裡的。
- **字幕側邊欄**：Netflix、YouTube、TVer、Bilibili.tv、Hulu（日本）、Prime Video 播放時會自動抓整集字幕進字幕列表，可以從工具欄選單開啟，點一句跳過去；其它站點走通用採集。播放器控制欄裡也有一顆 Fushi 按鈕。
- **站點沒給日語字幕**：擴充套件的字幕面板裡可以搜線上字幕（Jimaku / OpenSubtitles / AJATT），或者把 SRT / ASS / VTT 檔案直接拖到影片上。
- **制卡**：查詞彈窗裡點制卡，卡先進位制卡佇列，之後在擴充套件選單裡一次生成（帶這一句的畫面和聲音）。
- 網頁上看影片也會計入 Fushi 的沉浸時間。

app 以前的「內建網頁播放器」（在 Fushi 裡開啟網頁影片）目前已暫時停用，網頁影片請用瀏覽器擴充套件。

## 已經在用 Yomitan？

兩邊可以共存，也可以只留一邊：

- **繼續用 Yomitan 查網頁**沒問題，Fushi 的擴充套件只是多一個選擇；兩者都用 Shift，裝在一起會各彈各的，建議網頁查詞只留一個。
- 想讓 **GameSentenceMiner 之類走 yomitan-api 協議的工具** 改查 Fushi 的詞典：開 Fushi 的 Yomitan API 伺服器（埠 19633，可設金鑰），把工具指向它。
- Textractor / LunaTranslator / mpv 這類抓文本的工具，可以直接把文本推給 Fushi 的「文本鉤子（接收文本）」（設定 → 查詞 → 外部整合裡連它們的 WebSocket），在 Fushi 裡逐詞點查、制卡，不再需要 texthooker 網頁 + Yomitan 那一套。

## 瀏覽器之外

- **Windows / macOS 全域性查詞**：在任何應用裡選中一個詞，按「應用外查詞快捷鍵」（**設定 → 快捷鍵設定 → 全域性（應用外）**），查詞卡片在滑鼠旁彈出；macOS 第一次要給 Fushi 授權「輔助功能」。同一組裡還有「喚起主窗並開啟查詞頁」。
- **Android 全域性查詞**：在其他應用里長按選中文字，文字選單裡點 Fushi（沒有就走分享），彈窗蓋在原應用上；也可以用系統級懸浮球。
