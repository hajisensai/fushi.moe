Fushi 裡看番有兩條路，各有各的用處：

| | 線上看（影片源擴充套件） | 下載 |
|---|---|---|
| 怎麼來 | 裝 Aniyomi 影片源擴充套件，點開即播 | 搜作品 → 挑資源（BT）→ 下載 → 自動入庫 |
| 字幕 | 線路自帶什麼就是什麼，不一定有日語 | 自動匹配 [Jimaku](https://jimaku.cc) 日語字幕，逐集配對 |
| 入庫 / 離線 | 可以加入媒體庫、下載到本機 | 入庫，按作品歸組，後設資料自動刮削 |
| 追更 | 手動翻新集 | 訂閱，新集自動下載入庫 |
| 適合 | 隨手找一部看看 | 認真沉浸 + 制卡 |

學日語要點詞制卡的話，**優先走下載**：生肉 + Jimaku 字幕這一對是查詞制卡最順的組合。線上看的用法見[怎麼用影片源線上看番劇？](/faq/anime-online.zh-HK)，下面說下載。

**Windows、macOS、Android 可用；iOS 版按 App Store 規定沒有搜尋和下載功能。**

## 找作品

底欄 **瀏覽 → 發現**（影片庫的「發現」子標籤也一樣），在搜尋框裡搜電影、劇集、動漫，或者從熱門推薦、本季動漫、放送日曆裡挑。點進作品頁：

- **搜尋資源**：Fushi 用作品的原名 / 別名去各個資源索引一起搜——動漫走 Nyaa，電影劇集走 apibay / Knaben，再加上你自己的 Torznab 索引器（見[BT 那篇](/faq/bittorrent.zh-HK)）。結果按釋出組和解析度歸成一個個「版本」，也可以切到「全部條目」看原始列表。
- **訂閱**：還在播的番，按選定的釋出組和解析度追新集。
- **搜尋字幕**：單獨給這部作品找字幕。
- **⋯ → 讓 AI 幫我下**：說一句話讓 AI 找作品、挑版本，見[AI 下載是什麼？](/faq/ai-download.zh-HK)。

已經入庫的合集裡補缺集、或者從「相關作品」去下載時，會開啟 **番劇下載** 對話方塊：先在 AniList 選中作品，「Nyaa 查詢詞」自動填好原名，結果可以按 **生肉 / 英譯 / 非英譯** 篩（學日語選生肉）、勾 **僅可信** 只看可信釋出者、按 **做種數 / 釋出時間 / 體積** 排序，整季打包的標「合集」。

搜不到東西多半是查詢詞的問題，見[搜不到番劇？](/faq/search-tips.zh-HK)。

## 下載

選好版本點下載就進任務佇列，在 **瀏覽 → 下載** 裡看進度。Fushi 內建 libtorrent，不用另開下載器；也可以外接 qBittorrent，「推送下載」交給它。

- **邊下邊播**：任務開始後可以先入庫，從影片庫開啟邊下邊播。
- 下載完成自動入庫，按作品 / 資料夾歸組，後設資料自動匹配。
- 上傳（做種）預設關閉；想回饋網路就在下載設定裡開啟「啟用上傳 / 做種」。
- 手上有磁力連結或種子檔案：**瀏覽 → 下載** 右上角的 **新增任務**，貼上磁力連結或「選擇種子檔案」；桌面端也可以直接把 `.torrent` 檔案拖進視窗。
- 配了 [Fushi 互聯](/faq/interconnect.zh-HK)的話，「下載到」可以選互聯主機，讓電腦或 Fushi 服務端替手機下。

## 字幕

下載時選 **附帶字幕**（或「必須有字幕」），Fushi 會到 Jimaku 自動匹配這部番的日語字幕，下載完成後按包內檔案逐集配對；影片裡本來帶內嵌字幕軌的話，還會按它自動校正時間軸。要先在 **設定 → 線上服務 → 字幕來源** 裡填 Jimaku API 金鑰（在 Jimaku 網站免費申請）。匹配不上的集可以手動補一條。

有了字幕，播放時點字幕上的詞就能查詞，點加號制卡，卡上帶這一句的畫面和原聲。

## 追更

在作品頁或搜尋結果裡 **訂閱**：「追更」會定期檢查新集，命中後自動排隊下載入庫；「單次」只下當前這一批。逐集狀態在 **瀏覽 → 下載 → 訂閱** 裡看。

已經有影片檔案？不用搜，直接從本地資料夾或 WebDAV 等遠端來源匯入影片庫即可。
