Fushi 裡看番有兩條路，各有各的用處：

| | 線上看（影片源擴充套件） | 下載（番劇下載） |
|---|---|---|
| 怎麼來 | 裝 Aniyomi 影片源擴充套件，點開即播 | 搜作品名（Nyaa）→ 種子下載 → 自動入庫 |
| 字幕 | 線路自帶什麼就是什麼，不一定有日語 | 自動匹配 [Jimaku](https://jimaku.cc) 日語字幕，逐集配對 |
| 離線 / 入庫 | 不入庫，暫不能下載 | 入庫，按作品歸組，後設資料自動刮削 |
| 追更 | 手動翻新集 | 訂閱，新集自動下載入庫 |
| 適合 | 隨手找一部看看 | 認真沉浸 + 制卡 |

學日語要點詞制卡的話，**優先走下載**：生肉 + Jimaku 字幕這一對是查詞制卡最順的組合。線上看的用法見[怎麼用影片源線上看番劇？](/faq/anime-online.zh-HK)，下面說下載。

**Windows、macOS、Android 可用；iOS 版按 App Store 規定沒有搜尋和下載功能。**

## 搜尋

底欄 **下載** → 番劇下載，在上面輸入作品名搜尋（資料來自 Nyaa）。結果可以：

- 按 **生肉 / 英譯 / 非英譯** 篩——學日語選生肉；
- 勾 **僅 Trusted** 只看可信釋出者；
- 按 **做種數 / 釋出時間 / 體積** 排序；整季合集會標成「合集」。

站點連不上時，在下載設定裡配一下網路代理。

## 下載

點 **下載** 就進任務佇列，Fushi 內建 libtorrent，不用另開下載器；裝了 qBittorrent 的話也可以「推送下載」交給它。

- **邊下邊播**：任務開始後可以先入庫，從影片庫開啟邊下邊播。
- 下載完成自動入庫，按作品 / 資料夾歸組，後設資料自動匹配。
- 上傳（做種）預設關閉；想回饋網路就在設定裡開啟。
- 有磁力連結的話直接 **貼上連結下載**。

## 字幕

搜尋時勾上 **附帶字幕**，Fushi 會到 Jimaku 自動匹配這部番的日語字幕，下載完成後按包內檔案逐集配對。要先在 **設定 → 服務** 裡填 Jimaku API key（在 Jimaku 網站免費申請）。匹配不上的集可以手動補一條。

有了字幕，播放時點字幕上的詞就能查詞，點加號制卡，卡上帶這一句的截圖和原聲。

## 追更

在搜尋結果裡 **訂閱**：「追更」模式會定期檢查新集，命中後自動排隊下載入庫；「單次」只下當前這一批。逐集狀態在訂閱頁看得到。

已經有影片檔案？不用搜，直接從本地資料夾或 WebDAV 匯入影片庫即可。
