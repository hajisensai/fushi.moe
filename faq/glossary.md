按主题分组，每个词一两句。带链接的有整篇文章细讲。

## 学习方法

- **沉浸（immersion）**：大量看、听、读自己感兴趣的目标语言内容，从中习得语言，而不是背规则做题。Fushi 整个 app 就是为这件事造的，理论看[沉浸学习指南](/zh-cn/immersion)。
- **可理解输入 / i+1**：内容难度刚好比你当前水平高一点点——大部分能懂、少数不懂——这种输入最有效。选语料的标准。
- **主动学习 / 被动沉浸**：主动 = 查词、做卡、复习；被动 = 开着番当背景听。两者都要，前者少而精，后者量大。
- **SRS（间隔重复）**：快忘的时候再复习的记忆法；实现它的软件就是 Anki。
- **Anki**：免费的 SRS 软件，Fushi 做的卡都送到这里复习。[是什么、装哪个](/faq/anki-intro)。
- **FSRS**：Anki 内置的新一代排程算法，默认没开，[要手动打开](/faq/anki-basics)。
- **制卡（mining / 挖词）**：从正在看的内容里把不认识的词做成 Anki 卡片。Fushi 里就是查词弹窗上的加号。
- **牌组 / 卡组（deck）**：Anki 里一组卡片；**笔记类型（note type）/ 模板**：决定一张卡有哪些字段、正反面怎么显示。Fushi 默认用 **Lapis** 模板。
- **Kaishi 1.5k**：给零基础准备的 1500 词启动卡组，背到能看懂简单句子就开始沉浸。

## 日语相关

- **假名 / 五十音**：平假名、片假名各 46 个基本音，日语书写的基础，唯一必须先背的东西。
- **振假名（ふりがな / furigana）**：标在汉字上方的读音小字。Fushi 的阅读器和词典都能显示。
- **音调（アクセント / pitch accent）**：日语单词里音高的高低变化，比如「はし」高低不同是「箸」还是「橋」。查词弹窗里的音调标记、音调词典说的就是它。
- **词频（frequency）**：一个词在语料里出现的频繁程度，数字越小越常用。用来判断值不值得做卡、[给新卡排序](/faq/anki-basics)。
- **日日 / 日中 / 日英 / 双解**：词典按解释语言分类。日日 = 日语解释日语（国语辞典），双解 = 日语解释外加翻译。学到中期建议主用日日。
- **国语辞典**：日本人自己用的日语词典（明镜、大辞泉、新明解这类）。
- **罗马音（romaji）**：用拉丁字母拼日语，`Sousou no Frieren`。[搜资源要用它](/faq/search-tips)。
- **生肉 / 熟肉**：没翻译字幕的原片 / 带翻译的版本，学日语要生肉。[更多资源名词](/faq/release-names)。

## 查词与词典

- **查词弹窗**：点词后弹出的词典窗口，释义、音调、词频、发音、加号都在里面。
- **Yomitan**：浏览器查词扩展（前身 Yomichan），它的词典格式成了事实标准，Fushi 直接用。[Shift 查词是什么](/faq/browser-lookup)。
- **Yomitan 词典 / MDX / DSL**：Fushi 认的三种词典格式，[怎么导入](/faq/dictionaries)。
- **推荐包**：新手引导里一键下载的那 9.5 GB：词典、音调、词频、发音库。[能不能不装](/faq/pack)。
- **发音库 / 音频来源**：查词时点喇叭放的单词读音从哪来；本地发音库和在线来源都可以配。
- **全局查词**：在别的应用里选中文字，用快捷键（Windows）或文字菜单（Android）叫出 Fushi 查词。
- **变形还原**：把「食べなかった」还原成「食べる」再查。词典按原形收词，点到哪个形态都能查到靠的是它。

## 字幕与视频

- **外挂 / 内封 / 内嵌**：字幕放在视频旁边的文件里 / 打包在 mkv 里的轨 / 直接画进画面。[哪种能点词](/faq/subtitle-types)。
- **SRT / ASS / VTT**：三种文本字幕格式。[区别](/faq/subtitle-formats)。
- **主字幕 / 副字幕**：Fushi 里同时显示的两条字幕，主字幕用来点词，副字幕当翻译参考。[怎么用副字幕过渡](/faq/secondary-subtitle)。
- **调轴**：把字幕整体提前或延后，让它和声音对上。[对不上怎么办](/faq/subtitle-sync)。
- **Jimaku**：社区维护的日语字幕站，Fushi 番剧下载能自动去配。
- **mkv / mp4、H.264 / HEVC、1080p、码率**：容器、编码、分辨率、清晰度。[视频的这些词](/faq/video-basics)。
- **BDRip / WEB-DL / TVRip、字幕组、合集**：资源来源和发布形式。[资源名怎么看](/faq/release-names)。
- **刮削**：按文件名认出作品，去网上拉海报、简介、集列表。[是什么、怎么用](/faq/scraping)。
- **元数据（metadata）**：刮削拉回来的那些资料。**NFO**：把它们存在视频旁边的文件格式，Jellyfin / Kodi 也认。
- **Jellyfin / Emby / Plex**：媒体服务器，装在 NAS 上把视频串流给各设备。[是什么](/faq/media-servers)、[怎么接](/faq/jellyfin-setup)。
- **串流 / 转码**：边传边播 / 服务器实时把视频转成客户端认的格式。

## 漫画与书

- **OCR**：把图片上的文字识别成文本。漫画要先 OCR 才能点字查词，Fushi 内置模型本机跑。[在线看漫画](/faq/manga-online)。
- **mokuro / .mokuro**：一种带 OCR 结果的漫画格式（每页文字的位置和内容），Fushi 的漫画点字靠它；内置 Mokuro 目录里的漫画已经带好了。
- **EPUB / TXT**：Fushi 认的电子书格式；其他格式（mobi、azw3）用 Calibre 转。
- **有声书 / 对齐文件**：朗读音频 + 一份把音频和正文对上的字幕。[三者关系](/faq/audiobook)。
- **转录（ASR）**：让机器听音频把文字写出来。Fushi 用它给没字幕的有声书生成对齐文件，全在本机。
- **匹配率**：有声书的字幕在正文里找到落点的比例，低了要调搜索窗口。

## 在线源与下载

- **扩展（extension）/ 源（source）/ 仓库（repo）**：扩展是一个 APK 文件，里面装着若干在线源（某网站的适配器）；仓库是列出可安装扩展的地址。Fushi 兼容 **Mihon**（漫画）和 **Aniyomi**（视频）的扩展。[怎么装](/faq/mihon)。
- **线路（hoster）**：视频源里同一集的不同播放来源，画质、可用性各异。
- **BT / 种子 / 磁力链接 / 做种 / Tracker / DHT**：[BT 那篇](/faq/bittorrent)全讲了。
- **Nyaa**：最大的日本动漫资源索引站，Fushi 番剧下载的默认搜索来源；**Torznab**：统一的索引站接口，Jackett / Prowlarr 提供。
- **qBittorrent**：常见的 BT 客户端，Fushi 可以外接它。
- **订阅 / 追更**：让 Fushi 定期检查有没有新集，自动下载。
- **AniList / MAL / AniDB / VNDB / Bangumi**：作品数据库，Fushi 用它们认作品、拉资料、记进度。

## Galgame

- **Galgame / 视觉小说（VN）**：以文字 + 立绘 + 语音推进的游戏，沉浸材料里信息最全的一种。[怎么接进 Fushi](/faq/galgame)。
- **hook / 文本钩子**：从游戏进程里把正在显示的台词抓出来。**特殊码（H-code）**：针对某个游戏手写的抓取规则，引擎不认时用。
- **文本线程**：hook 抓到的各路文字流，要挑出干净的台词那一条。
- **转区 / Locale Emulator**：让不转系统语言也能以日文区域启动老游戏，避免乱码。
- **超分 / Magpie**：把低分辨率的游戏窗口放大到全屏的工具。

## Fushi 自己的

- **互联**：Fushi 设备之间的局域网直连，一台当**主机**开放库，其他当**客户端**。[怎么配](/faq/interconnect)。
- **fushi_server**：没有界面的 Fushi 主机，跑在 NAS 上。
- **正式版 / 调试版**：两个下载渠道，调试版先拿到新功能。[区别](/faq/channels)。
- **新手引导**：第一次启动的配置向导，设置 → 系统 里能重跑。
- **浏览器扩展**：Fushi 自带的、在任意网页查词的扩展。[Shift 查词](/faq/browser-lookup)。
- **云备份 / 同步与备份**：把数据备份到 Google Drive / WebDAV 或本地文件，[数据存在哪](/faq/data)。
