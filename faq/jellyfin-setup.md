家里有 Jellyfin 或 Emby 的话，不用把番剧再拷一份到 Fushi 里：登录一次，服务器上的视频直接在 Fushi 里播，该点词点词、该制卡制卡。Jellyfin 和 Emby 的接口是一套，下面的步骤两家通用。（不知道它们是什么？先看[Jellyfin、Emby、Plex 是什么](/faq/media-servers)。）

## 准备

- 服务器已经装好、扫过库，能在它自己的网页或 app 里看到番剧。
- 知道服务器地址：局域网里一般是 `http://192.168.x.x:8096`（Jellyfin 和 Emby 默认端口都是 8096；开了 HTTPS 的 Jellyfin 是 8920，反代过的就是你自己的域名）。
- 一个服务器上的账号（用户名 + 密码）。Emby 用 Emby Connect 登录的话，要在服务器上给这个用户设一个本地密码。

## 第 1 步：登录

**设置 → 服务 → 媒体服务器（Jellyfin / Emby）**

1. **服务器地址** 填上面那个地址。中文输入法下注意冒号和点别打成全角。
2. 填 **用户名**、**密码**，点 **登录**。成功后这一块变成服务器名和账号，下面多出两项设置。

登录用的令牌存在本机；**退出登录** 会删掉它和这台服务器的全部缓存清单。

## 第 2 步：选要看的媒体库

登录后展开 **要列出的媒体库**，是服务器上「电影 / 剧集 / 动漫」这类视频库的勾选表（音乐、图书、照片库不会出现）。

- 不勾 = 列出全部视频库，小库用户不用管；
- 服务器很大（几万条以上、或者是公共服）就**只勾你真正会看的那一两个库**——Fushi 列条目要一页页翻服务器的清单，整台服务器枚举一遍既慢，也容易被服务器当成滥用。

**进入视频页时自动列出条目** 默认开着：进视频库就去服务器拉一次清单。超大服务器建议关掉，改成在视频库里**下拉刷新**时才列。

## 第 3 步：看

回到视频库，服务器上的作品就和本地的排在一起，卡片带一个云角标（和互联的远端条目一样是占位卡，「同步」设置里的 **显示远端条目** 关了就不显示）。点一部：

- **直接串流**：不转码，服务器把原文件流过来，Fushi 用自己的播放器解，所以 HEVC / 10-bit / mkv 都不挑；
- **字幕**：服务器上这条视频的文本字幕（外挂 `.srt` / `.ass`，或 mkv 里的文本轨）会自动取下来当外挂字幕加载，**能点词、能制卡**；PGS 这类图形字幕轨取不到文字，见[外挂、内封、内嵌字幕](/faq/subtitle-types)。服务器上没日语字幕的，和本地视频一样手动导入一份或让 Jimaku 配。
- **进度双向同步**：看到哪服务器就记到哪（和 Jellyfin 网页端一样每 10 秒报一次），Fushi 里也读服务器上的断点——手机 Jellyfin app 看了一半，Fushi 打开接着播；反过来也一样。
- **下载到本机**：想离线看、或者要导出片段，卡片菜单里下载整个文件；导出片段只对本机文件可用。

## 常见状况

- **登录失败**：先在手机 / 电脑浏览器里打开同一个地址确认能进；地址要带端口；反代 + HTTPS 的写 `https://`；用户名密码是服务器账号，不是 Emby Connect / Plex 那种云账号。
- **列表是空的**：勾选的库不是视频类型（Jellyfin 里库类型要是 电影 / 剧集 / 混合内容），或者「自动列出」关着——下拉刷新一下。
- **只列出了一部分**：几十万条的服务器会触发翻页熔断，Fushi 会提示拿到的不是全部；勾少几个库。
- **换了服务器上的库、勾选没生效**：改完勾选 Fushi 会清缓存重新列，如果还是旧的，退出登录再登一次。
- **Plex**：不支持。把文件用 WebDAV 共享给 Fushi（视频来源里加 WebDAV 远程库），或者旁边装个 Jellyfin 指向同一目录。
- **不想装服务器**：电脑上的 Fushi 自己就能当主机，见[Fushi 互联](/faq/interconnect)。
