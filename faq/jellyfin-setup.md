家里有 Jellyfin、Emby 或 Plex 的话，不用把番剧再拷一份到 Fushi 里：登录一次，服务器上的视频直接在 Fushi 里播，该点词点词、该制卡制卡。Jellyfin 和 Emby 的接口是一套，下面的步骤两家通用；Plex 见文末。（不知道它们是什么？先看[Jellyfin、Emby、Plex 是什么](/faq/media-servers)。）

## 准备

- 服务器已经装好、扫过库，能在它自己的网页或 app 里看到番剧。
- 知道服务器地址：局域网里一般是 `http://192.168.x.x:8096`（Jellyfin 和 Emby 默认端口都是 8096；开了 HTTPS 的 Jellyfin 是 8920，反代过的就是你自己的域名）。手机上用 IP 地址，Android / iOS 解析不了 `.local` 或 Windows 计算机名。
- 一个服务器上的账号（用户名 + 密码）。Emby 用 Emby Connect 登录的话，要在服务器上给这个用户设一个本地密码。

## 第 1 步：登录

**设置 → 在线服务 → Jellyfin · Emby**

1. **添加服务器**，**服务器地址** 填上面那个地址。中文输入法下注意冒号和点别打成全角。
2. 填用户名、密码，点 **登录**。成功后它出现在「已登录的服务器」里。可以登录好几台服务器。

登录用的令牌存在本机；**退出登录** 会删掉它和这台服务器的缓存。

同一台服务器有好几个地址（局域网、公网、反代）的话，在它的 **线路** 里「添加线路」，之后随时切换，登录状态在每条线路上通用。

## 第 2 步：在「媒体服务器」分区里看

视频库顶上有一个 **媒体服务器** 分区：选服务器 → 媒体库 → 剧 → 季 → 集，按服务器自己的目录一层层浏览，也能「搜索此服务器」。点一集：

- **直接串流**：不转码，服务器把原文件流过来，Fushi 用自己的播放器解，所以 HEVC / 10-bit / mkv 都不挑；
- **字幕**：服务器上这条视频的文本字幕（外挂 `.srt` / `.ass`，或 mkv 里的文本轨）会自动取下来当外挂字幕加载，**能点词、能制卡**；PGS 这类图形字幕轨没有文字，要靠 OCR，见[外挂、内封、内嵌字幕](/faq/subtitle-types)。服务器上没日语字幕的，和本地视频一样手动导入一份或让 Jimaku 配。
- **进度双向同步**：看到哪服务器就记到哪（和 Jellyfin 网页端一样每 10 秒报一次），Fushi 里也读服务器上的断点——手机 Jellyfin app 看了一半，Fushi 打开接着播；反过来也一样。
- **下载到本机**：想离线看、或者要导出片段，卡片菜单里下载整个文件；导出片段只对本机文件可用。
- 在线流制卡会慢一些，「设置 → 制卡 → 在线视频制卡」可以选后台制卡或看完再制卡，见[在线看番那篇](/faq/anime-online#在线视频制卡)。

## 想和本地视频混在一起看

默认媒体服务器的条目只在「媒体服务器」分区里。想让它们和本地视频一起出现在首页、系列、全部视频里，打开服务器设置里的 **在视频库中混排显示**，再按需调两项：

- **要列出的媒体库**：不勾 = 列出全部视频库。服务器很大（几万条以上、或者是公共服）就**只勾你真正会看的那一两个库**——混排要把清单一页页翻下来，整台服务器枚举一遍既慢，也容易被服务器当成滥用。
- **进入视频页时自动列出条目**：超大服务器建议关掉，改成在视频库里**下拉刷新**时才列。

## Plex

**设置 → 在线服务 → Plex**：**使用 Plex 账号登录**（浏览器里授权 Fushi，账号下能连上的服务器自动加进来），或者 **手动连接**，填服务器地址和 X-Plex-Token。之后同样在「媒体服务器」分区里浏览；播放直接串流原文件，不用 Plex 转码。

## 常见状况

- **登录失败**：先在手机 / 电脑浏览器里打开同一个地址确认能进；地址要带端口；反代 + HTTPS 的写 `https://`；Jellyfin / Emby 的用户名密码是服务器账号，不是 Emby Connect 那种云账号。
- **列表是空的**：库类型不是视频（Jellyfin 里库类型要是 电影 / 剧集 / 混合内容）；混排模式下还可能是「自动列出」关着——下拉刷新一下。
- **混排只列出了一部分**：几十万条的服务器会触发翻页熔断，Fushi 会提示拿到的不是全部；勾少几个库，或者直接用「媒体服务器」分区浏览。
- **服务器拒绝了本应用的访问**：有的服务器只允许特定客户端，找服务器管理员。
- **不想装服务器**：电脑上的 Fushi 自己就能当主机，见[Fushi 互联](/faq/interconnect)。
