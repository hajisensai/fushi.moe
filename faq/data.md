默认全部存在你自己的设备上。Fushi 不需要注册，也不会把你的书、词典、进度或卡片记录上传到任何服务器。

唯一默认开着的是**使用统计**：Android / Windows / macOS / Linux 版每天向 fushi.moe 发一次匿名报告，只含安装 ID（由系统的机器标识单向哈希得出，重装 Fushi 也不变；机器标识原值不会离开设备）、应用版本、平台和更新通道，用来统计有多少人在用、旧版本还剩多少；不含账户、书库或阅读内容，也不保存你的 IP 地址。不想发的话，在 **设置 → 系统与关于 → 更新设置** 关掉 **发送使用统计** 即可。iOS 版不发。

下面这些会联网的功能，都要你自己打开才会用：

- **同步与备份**：走你自己配置的 Google Drive / OneDrive / Dropbox、WebDAV / FTP / SFTP，或 [Fushi 互联](/faq/interconnect)（自己的电脑或 Fushi 服务端）；凭据只存在本机。
- **Fushi 账户与排行榜**（实验性）：用邮箱验证码注册后才会上传，注册之前什么都不传。上传并公开的是昵称、头像，读完与在读作品的标题、作者、封面、读完时间，每部作品的阅读字数与时长，以及每日阅读字数；邮箱只用来收验证码，服务端只存不可逆的哈希。单部作品可以设为不公开。
- **AI 功能**：用的是你在 **设置 → 模型 → LLM** 里自己配的提供商，相关内容（比如查词时的句子、漫画文字框）会发给那家提供商，由它计费，见[AI 下载是什么？](/faq/ai-download)。
- **Anki 同步（无需安装 Anki）**：直接同步到你填的 Anki 同步服务器，账号密码只存在本机。
- **反馈**：你在应用内提交反馈时，写的内容和你选择附带的截图、日志、录屏、设备信息会发给开发者，只用于排查问题。附带设备信息且开着使用统计时，安装 ID 也会一起发送，方便开发者看到这台设备用过哪些版本、修复是否已经装上。

详见[隐私政策](/privacy)。
