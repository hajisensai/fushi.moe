文本字幕本質上都是一張表：**這句話從幾分幾秒顯示到幾分幾秒**。格式的差別在於表裡還能寫多少別的東西。

| 格式 | 字尾 | 能寫什麼 | 常見來源 |
|---|---|---|---|
| SubRip | `.srt` | 時間 + 文字，頂多粗體斜體 | 流媒體抽出、Jimaku、自動生成 |
| SubStation Alpha | `.ass` / `.ssa` | 字型、顏色、描邊、位置、動畫、卡拉 OK | 字幕組、BDRip |
| WebVTT | `.vtt` | 時間 + 文字，少量樣式 | 網頁播放器、線上源 |

## SRT：最簡單的那種

```
12
00:01:04,520 --> 00:01:07,180
魔法使いといえば、たったひとつ。
```

序號、起止時間、文字，完了。沒有字型、沒有位置，怎麼顯示全看播放器。因為什麼都不帶，所以**哪都能放、誰都能改**——用記事本就能修一個錯字或者把時間整體挪兩秒。

Jimaku 上的日語字幕、從 Netflix 之類流媒體抽出來的字幕，大多是 SRT。

## ASS：字幕組的標配

```
[V4+ Styles]
Style: Default,Noto Sans JP,60,&H00FFFFFF,...

[Events]
Dialogue: 0,0:01:04.52,0:01:07.18,Default,,0,0,0,,{\an8}魔法使いといえば、たったひとつ。
```

ASS 檔案先定義一組**樣式**（字型、字號、顏色、描邊、陰影），每句對白引用一個樣式；文字裡還能塞 `{\an8}` 這樣的**特效標籤**——放到螢幕頂部、換顏色、淡入淡出、卡拉 OK 逐字變色。字幕組翻譯螢幕上的招牌、簡訊、OP/ED 歌詞時，靠的都是這套東西，所以字幕組釋出的幾乎都是 ASS。`.ssa` 是它的舊版，能讀的播放器都一起讀。

代價是它對播放器要求高：一份 ASS 在不同播放器裡可能長得不一樣，用的字型沒裝就會退回預設字型。

## VTT：網頁版 SRT

```
WEBVTT

00:01:04.520 --> 00:01:07.180
魔法使いといえば、たったひとつ。
```

和 SRT 幾乎一樣，只是給瀏覽器 `<video>` 標籤設計的（時間用點不用逗號，開頭多一行 `WEBVTT`）。網頁播放器、Aniyomi 影片源那種線上線路自帶的字幕軌，基本都是 VTT。

## 在 Fushi 裡有什麼區別？

**沒有本質區別**——四種 Fushi 都能讀，不管是外掛檔案還是 mkv 裡的內封軌。

Fushi 拿到字幕後做的第一件事是**把樣式和文字分開**：查詞、制卡、寫進 Anki 的都是純文字，`{\an8}` 這類標籤不會混進句子裡。ASS 的一部分樣式會照著渲染（對齊位置 `\an`、`\pos`、斜體粗體、顏色、字號、換行），卡拉 OK、動畫、向量繪圖這些會被靜默去掉——Fushi 的字幕是逐字可點的一層，不能像 mpv 那樣把字幕畫進畫面，否則就點不了詞了。

所以學日語的話，**字幕格式不用挑**，挑的是內容：一份逐句對得上臺詞的日語字幕，比什麼特效都重要。字幕組的中文 ASS 再漂亮也只能當參考，制卡要日語的。

## 順帶：圖形字幕

PGS（藍光）、VobSub（DVD）不是文本，是一張張點陣圖，沒有「格式」可言——Fushi 能顯示但不能點詞，詳見[外掛、內封、內嵌字幕是什麼？](/faq/subtitle-types.zh-HK#內封字幕)。
