預設全部存在你自己的裝置上。Fushi 不需要註冊，也不會把你的書、詞典、進度或卡片記錄上傳到任何伺服器。

唯一預設開著的是**使用統計**：Android / Windows / macOS / Linux 版每天向 fushi.moe 發一次匿名報告，只含安裝 ID（由系統的機器標識單向雜湊得出，重灌 Fushi 也不變；機器標識原值不會離開裝置）、應用版本、平臺和更新通道，用來統計有多少人在用、舊版本還剩多少；不含賬戶、書庫或閱讀內容，也不儲存你的 IP 地址。不想發的話，在 **設定 → 系統與關於 → 更新設定** 關掉 **傳送使用統計** 即可。iOS 版不發。

下面這些會聯網的功能，都要你自己開啟才會用：

- **同步與備份**：走你自己配置的 Google Drive / OneDrive / Dropbox、WebDAV / FTP / SFTP，或 [Fushi 互聯](/faq/interconnect.zh-HK)（自己的電腦或 Fushi 服務端）；憑據只存在本機。
- **Fushi 賬戶與排行榜**（實驗性）：用郵箱驗證碼註冊後才會上傳，註冊之前什麼都不傳。上傳並公開的是暱稱、頭像，讀完與在讀作品的標題、作者、封面、讀完時間，每部作品的閱讀字數與時長，以及每日閱讀字數；郵箱只用來收驗證碼，服務端只存不可逆的雜湊。單部作品可以設為不公開。
- **AI 功能**：用的是你在 **設定 → 模型 → LLM** 裡自己配的提供商，相關內容（比如查詞時的句子、漫畫文字框）會發給那家提供商，由它計費，見[AI 下載是什麼？](/faq/ai-download.zh-HK)。
- **Anki 同步（無需安裝 Anki）**：直接同步到你填的 Anki 同步伺服器，賬號密碼只存在本機。
- **反饋**：你在應用內提交反饋時，寫的內容和你選擇附帶的截圖、日誌、錄屏、裝置資訊會發給開發者，只用於排查問題。附帶裝置資訊且開著使用統計時，安裝 ID 也會一起傳送，方便開發者看到這臺裝置用過哪些版本、修復是否已經裝上。
