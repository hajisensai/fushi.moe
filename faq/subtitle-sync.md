外挂字幕不是跟着这个视频文件做的，对不上很正常。先分清是哪一种偏，再对症调。

## 两种偏法

**整体偏一段**：从头到尾字幕都比声音早（或晚）固定的几秒。原因是字幕和视频的**版本不一样**：

- 蓝光版和电视 / WEB 版剪辑不同——BD 版可能多了几秒黑场、少了广告位的过场，OP 前有没有冷开场也不一样；
- 有的版本把 OP / ED 剪掉了，字幕是按完整版做的。

**越往后差越多**：开头是对的，看到二十分钟时字幕晚了两三秒。这是**帧率不同**——字幕按 25 fps 的 PAL 版做，视频是 23.976 fps，或者反过来；每分钟差几帧，累计到一集末尾就是几秒。这种调一个固定偏移不够，需要把字幕整体拉伸。

还有一种是**只有几句对不上**：那是字幕本身打轴不准，换一份字幕吧。

## 在 Fushi 里调

播放器的快速设置里有 **字幕调轴**：

- **滑条 / 步进**：直接拖，或者按 ±100 ms 之类的步长点。字幕早了就往正调（延后），晚了就往负调。看着一句台词开口的瞬间和字幕出现的瞬间对齐即可。
- **自动对轴**：让 Fushi 自己算一个偏移。
- **波形对轴**（本地视频）：点开后能看到整条音频的波形，字幕的每句起点画成一条条线，横向拖动、把线对到说话的峰值上。肉眼对一次比反复试滑条快得多；手机上可能生成不了波形，那就用滑条。

调好的偏移**按集记住**：换集、重进都还在。制卡时截的音频和画面也会按这个偏移取，做出来的卡不会串句。

## 对轴后还是慢慢漂

那就是帧率问题，固定偏移救不了。办法：

- 去 [Jimaku](https://jimaku.cc) 找**和你的视频同版本**的字幕——条目下常常同时有 BD 版和 WEB 版，文件名里会写；
- 或者换一份和字幕同版本的视频；
- 实在要自己修，用 [Aegisub](https://aegisub.org/) 或 [Subtitle Edit](https://www.nikse.dk/subtitleedit) 做「帧率转换」或「两点同步」，把字幕拉伸到正确的时长后再放回来。

## 一开始就选对版本能省很多事

用 Fushi 番剧下载勾「附带字幕」自动配到的字幕不合适时，可以手动补一条：看一眼资源名里是 **BDRip** 还是 **WEB-DL**（[怎么看资源名](/faq/release-names)），到 Jimaku 找对应版本的字幕导入。
