Fushi 不需要註冊，所有資料預設都只在你自己的裝置上（見[我的資料存在哪裡？](/faq/data.zh-HK)）。好處是隱私，壞處是：手機丟了、電腦重灌了，如果你什麼都沒做，書架、閱讀進度、學習統計就一起沒了。所以值得花五分鐘設好一條備份通道。

Fushi 裡和「備份」有關的東西都在 **設定 → 同步與備份**（副標題「雲端、區域網與本地備份」），另外還有一個獨立的 **設定 → Fushi 互聯**。下面按用途分開講。

## 三種備份方式，怎麼選

| 方式 | 適合誰 | 特點 |
|---|---|---|
| **本地備份檔案**（匯出備份） | 一次性遷移、偶爾留個底 | 打包成一個 `fushi-backup-日期.fushi.zip`，自己保管；不聯網 |
| **雲同步**（同步方式選雲盤 / 網盤） | 想要自動、持續備份 | Google Drive、OneDrive、Dropbox、WebDAV、FTP、SFTP 任選一個；憑據只存在本機 |
| **Fushi 互聯** | 家裡有一臺常開的電腦或 NAS | 資料直接放到你自己的電腦或 [Fushi 服務端](/faq/server.zh-HK)上，不經過任何雲盤 |

三者不衝突：可以平時開雲同步，換裝置前再匯出一個備份檔案兜底。

## 方法一：匯出 / 匯入備份檔案

### 匯出

**設定 → 同步與備份 → 本地備份 → 匯出備份**。

點開後先彈「選擇要匯出的內容」，可以逐項勾選：

- **詞典**（已匯入的詞典及其檔案）
- **書籍內容**（EPUB 及解壓內容）——還可以點「選擇書籍」只打包其中幾本
- **有聲書音訊**（有聲書音訊與對齊資料）
- **自定義字型**
- **影片**（本地影片檔案）——同樣可以「選擇影片」
- **本地音訊資料庫**（本地發音音訊庫）
- **遊戲**（遊戲庫、後設資料來源與封面）
- **閱讀進度**、**統計資料**、**設定**、**配置方案**

影片、有聲書、本地發音庫通常是最大的幾項。只想遷移閱讀記錄的話，把這幾項取消勾選，備份會小很多；這些大檔案可以之後直接複製過去重新匯入。

注意提示裡的那句：**取消勾選「書籍」會連同這些書的正文和記錄一併移除**——也就是說備份裡不會有這本書的進度。想保留進度就要連書一起打包。

匯出完成後：

- **Android / iOS**：彈出系統分享面板，存到「檔案」、網盤，或者發給自己；
- **Windows / macOS**：彈出儲存對話方塊，選個位置存成 `.zip`。

如果有詞典的原檔案在這臺裝置上已經找不到了，會提示「匯出完成，但有 N 本詞典被跳過」，其它內容照常匯出。

### 匯入

在新裝置上裝好 Fushi（[下載頁](/zh-hk/download)），**設定 → 同步與備份 → 本地備份 → 匯入備份**，選那個 `.zip`。Fushi 會先校驗並預覽備份內容，然後讓你選：

- **匯入方式**：
  - **合併到現有庫**——新裝置上已經有書時用這個，會提示「合併將新增 N 本書、更新 N 條閱讀進度」；
  - **覆蓋整庫**——用備份替換當前全部資料，適合全新安裝的裝置。
- **此備份包含**：列出備份裡的各項，取消勾選某項即可跳過它。
- **匯入設定與 Profile**：開啟就是完整恢復（字型、外觀、Profile 都來自備份）；關掉就保留本機的字型 / 外觀 / Profile，只恢復書籍與閱讀資料。

確認後應用會自動重啟。本裝置的同步配置（賬戶與憑據）會保留，不會被備份裡的覆蓋掉。

常見提示：

- **「無效的備份檔案」**：選錯了檔案，或者檔案沒下載完整。Hibiki 時代匯出的 `*.hibiki.zip` 老備份仍然可以匯入。
- **「此備份需要更新版本的應用」**：備份是用更新的 Fushi 匯出的，先把這臺裝置上的 Fushi 更新到同一版本或更新。
- 匯入過程中介面會顯示「正在恢復資料，請勿關閉應用」，大備份可能要幾分鐘，別中途退出。

## 方法二：雲同步（自動備份）

**設定 → 同步與備份 → 同步方式**，在「儲存後端」裡選一個：

- **Google Drive / OneDrive / Dropbox**：點「登入」，在瀏覽器裡授權。桌面端會開啟預設瀏覽器；沒開啟或頁面報錯時，可以「複製登入連結」到別的瀏覽器開啟。
- **WebDAV / FTP / SFTP**：進「伺服器設定」填伺服器地址、使用者名稱、密碼（SFTP 還可以填私鑰），點「測試連線」。支援 WebDAV 的網盤、群暉等 NAS、自建伺服器都可以用。

選好之後看下面三組：

**同步內容**

- **同步統計**：學習時長、字數這些統計也跟著同步。
- **上傳書籍檔案**、**同步有聲書檔案**、**上傳影片檔案**：把檔案本體也傳上去。預設不傳大檔案的話，雲端只有進度和記錄，換裝置後需要自己再匯入一次書；開啟後才會把書本身也放到雲端（會佔雲盤空間和流量）。

**何時同步**

- **自動同步**：開啟後，Fushi 會在開啟應用、切到後臺、關書這些時機自動推送；
- **立即同步**：手動做一次完整雙向同步；
- **對比資料**：並排看「本地 vs 遠端」，每本書可以選用本地、用遠端或跳過，適合兩臺裝置進度打架時手動裁決。

**詞典與本地音訊傳輸**

詞典、本地發音庫、字型這幾樣體積大，**不會自動同步**，在這一組裡點「傳輸」手動選「上傳」（把本機有、遠端沒有的推上去）或「下載」（把遠端有、本機沒有的取回來）。新裝置上第一件事就是在這裡把詞典「下載」下來，比重新下推薦包省事。

幾點說明：

- 雲端的憑據只存在本機，備份恢復時也不會被覆蓋。
- 自己從原始碼構建的版本可能沒有內建 Google 登入憑據，會提示「此構建未配置谷歌同步憑據」，換 WebDAV 等其它後端即可。
- 雲盤滿了會提示「雲端儲存空間已滿」，關掉影片 / 有聲書檔案上傳或清理雲盤。

## 方法三：用 Fushi 互聯放到自己的電腦上

如果你已經按[互聯教程](/faq/interconnect.zh-HK)配好了手機和電腦，可以完全不用雲盤：

- **與已配對裝置共享**：閱讀 / 觀看進度、統計（「共享統計」）、收藏的詞與句子兩邊雙向合併，預設開啟。一臺裝置壞了，另一臺上還有完整記錄。
- **上傳到互聯對端**：書籍、詞典、有聲書、影片四個開關預設全關，想把手機上的內容存一份到電腦就勾上對應的。
- **用互聯做備份後端**：在互聯設定裡點「設為備份後端」，原本寫到雲盤的備份與同步改寫到已配對的電腦或服務端。
- **配置檔案**：「上傳配置到對端」/「從對端下載配置」可以把一整套 Profile（閱讀器、查詞、制卡設定）搬到另一臺裝置，落成一份新配置，不覆蓋原有的。

沒有常開電腦的話，可以在 NAS 上跑一個 [Fushi 服務端](/faq/server.zh-HK)當這臺「家裡的主機」。

## 換手機 / 換電腦：推薦步驟

1. **舊裝置上**：先「立即同步」一次（用了雲同步或互聯的話），再「匯出備份」留一份檔案。
2. **新裝置上**：裝 Fushi。打算從舊裝置搬詞典的話，先不急著下[推薦包](/faq/pack.zh-HK)，等恢復完再看缺什麼。
3. 按你用的方式恢復：
   - 用備份檔案：**匯入備份 → 覆蓋整庫**（新裝置沒資料時）；
   - 用雲同步：選同一個儲存後端、登入同一個賬號，點「立即同步」，再在「詞典與本地音訊傳輸」裡把詞典和發音庫「下載」下來；
   - 用互聯：配對後在書架 / 影片庫裡的 Fushi 互聯來源直接看電腦上的內容，進度會自動合併。
4. 檢查 Anki 連線：卡片本身存在 Anki 裡，不在 Fushi 的備份裡——換裝置後在 **設定 → 制卡** 重新連上 Anki（見[怎麼連線 Anki？](/faq/anki.zh-HK)），Anki 那邊的牌組用 Anki 自己的同步（AnkiWeb 或自建同步伺服器）遷移。
5. AI 提供商的配置是裝置本地的，不進備份和同步，新裝置上要在 **設定 → 模型 → LLM** 裡重新填。

### 從別的閱讀器搬過來

- **Hoshi Reader**：**設定 → 同步與備份 → 本地備份 → 第三方匯入**，選 Hoshi Reader 匯出的 `.hoshi` 書庫備份，書、閱讀位置和統計都會匯入；同一份備份重複匯入不會重複計數。
- **舊版 Hibiki（Android）**：Android 上這一組裡有「從 Hibiki 匯入」，匯入舊版 Hibiki 匯出的資料。

## 常見問題

- **備份檔案存在哪？** 匯出時你自己選的位置；Fushi 不會自動替你存一份。匯出過程中的臨時包如果殘留，會出現在 **設定 → 儲存** 的「遺留的備份包」裡，可以清掉。
- **資料目錄能放到別的盤嗎？** 可以，**設定 → 儲存**（資料位置與磁碟佔用）。資料位置所在的盤暫時讀不到時，Fushi 會提示「資料位置未響應」，可以重試，或「仍用預設位置啟動」——不會改動原來的資料。
- **兩臺裝置進度不一致**：用「對比資料」手動選，或在兩邊都點一次「立即同步」。
- **備份能跨平臺嗎？** 能。Android 匯出的備份可以在 Windows / macOS / iOS 上匯入，反過來也一樣。
