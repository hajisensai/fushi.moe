- **Windows / macOS**: install Anki, then the [AnkiConnect](https://ankiweb.net/shared/info/2055492159) add-on, and keep Anki open while mining.
- **Android**: install AnkiDroid.
- **iOS**: install AnkiMobile.

Once connected in the onboarding wizard or under **Settings → Anki**, you can create a deck with the built-in Lapis note type in one tap.

From then on, whenever you look a word up while watching, reading or gaming, the plus next to the definition makes a card carrying the original sentence, a screenshot / GIF and the original audio.
