在 Nyaa 或者 Fushi 的番剧下载里搜一部番，会出来一长串标题差不多、后面一堆方括号的结果。它们各说了什么、学日语该挑哪个，这篇讲清楚。

## 生肉 / 熟肉

- **生肉（Raw）**：没有翻译字幕的原片。可能完全没字幕，也可能带日语字幕（CC 字幕、蓝光自带）。
- **熟肉**：带翻译（中文、英文…）字幕的版本。字幕可能是[外挂、内封或内嵌](/faq/subtitle-types)。

学日语**要生肉**：翻译字幕在画面上会不自觉去读，学不到东西。生肉配一份日语字幕（Fushi 能从 [Jimaku](https://jimaku.cc) 自动配）是查词制卡最顺的组合。Fushi 番剧下载里的「生肉 / 英译 / 非英译」筛选就是按这个分的。

## 来源：BDRip、WEB-DL、TVRip

| 缩写 | 来自 | 特点 |
|---|---|---|
| **BDRip / BDMV / Remux** | 蓝光碟 | 画质最好，无修正、无台标；播出结束几个月后才有 |
| **WEB-DL / WEBRip** | 流媒体（Crunchyroll、Netflix、B 站…） | 播出当天就有，画质中等；常带该平台的字幕 |
| **TVRip / HDTV** | 电视台录制 | 最早出，有台标、跑马灯、可能有和谐光 |

- **BDMV** 是蓝光原盘目录，几十 GB；**Remux** 是把原盘的流原样重新封装成 mkv，不重新压制，画质等于原盘、体积还是很大；**BDRip** 是压制过的，一集一两 GB，最常见。
- **WEB-DL** 是直接从流媒体拿下来的流，**WEBRip** 是录屏或二压，稍差一点。
- 资源名里的 **CR / NF / AMZN / B-Global** 指来源平台（Crunchyroll、Netflix、Amazon、Bilibili 国际版）。

## 画质那一段

`1080p`、`x265`、`Hi10P`、`FLAC` 这些讲画面编码和音轨，见[视频的这些词是什么意思](/faq/video-basics)。简单说：

- 挑 **1080p** 或 **720p** 都行，动画原生分辨率通常不到 1080p；
- **x265 / HEVC** 体积小，老设备可能解不动，那就选 x264；
- **10-bit** 色彩更细腻，手机硬解要看支持。

## 发布组

方括号里最前面一般是发布组的名字。BDRip 界的老牌组（VCB-Studio、Moozzi2、Beatrice-Raws…）以画质稳定出名；字幕组（各种 Sub）出的是熟肉；**Erai-raws、SubsPlease** 这类是搬运流媒体 WEB 版的组，出得最快，通常带多语言外挂字幕。

## 字幕标记

- **CHS / CHT / JPN / ENG**：字幕语言，简中 / 繁中 / 日 / 英；
- **Multi-Subs**：多语言字幕；**Dual Audio**：双音轨（一般是日语 + 英语配音）；
- **CC**：Closed Caption，为听障观众做的同语言字幕，会写出「（ドアの音）」这类环境音。日本流媒体的日语 CC 字幕对学日语很好用。

## 合集与做种

- **Batch / 合集**：整季打包一个种子，Fushi 番剧下载会标「合集」。追完结的番直接下合集最省事。
- **做种数（Seeders）**：越多下得越快；几年前的老资源可能没人做种，下不动就换一个。
- **Trusted**：Nyaa 认证过的可信发布者，Fushi 搜索里可以只看它们。

## 学日语怎么挑

按这个顺序：

1. **生肉**优先，有日语 CC 字幕的 WEB 版更好；
2. 完结番选 **BDRip 合集**，追更选 **WEB-DL**；
3. 分辨率 1080p / 720p 随意，设备老就避开 x265 和 10-bit；
4. 下载时勾上 Fushi 的「附带字幕」让 Jimaku 自动配日语字幕——BD 版和 WEB 版的字幕时间轴可能不一样，配错了看[字幕对不上怎么办](/faq/subtitle-sync)。

下载的具体操作见[番剧是在线看还是下载？](/faq/anime-download)。
