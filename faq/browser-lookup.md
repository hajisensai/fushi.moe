## 先说「Shift 查词」

在 Fushi 的阅读器和视频里查词，是**点**一下那个词。但在浏览器网页上，点击会触发链接、按钮、选中文字，没法拿来查词。所以浏览器查词工具（[Yomitan](https://yomitan.wiki/)、以前的 Yomichan）用的是另一套习惯：

> **按住 Shift，把鼠标移到词上**，词典就弹出来；松开 Shift、移开鼠标，弹窗关掉。不用点、不用选。

用过 Yomitan 的人对这个动作有肌肉记忆；没用过的第一次会以为扩展装坏了——它在等你按 Shift。

Fushi 里三种地方，触发方式不一样：

| 在哪 | 怎么查 |
|---|---|
| app 内阅读器、视频 / 番剧字幕、漫画 | **点击**词（桌面还可以在 设置 → 查词 里开「悬停即查词」，鼠标停上去就查） |
| 视频网站上，扩展叠在视频上的 **Fushi 字幕** | **点击** 和 **Shift 悬停** 都行（扩展设置里开「悬浮字幕自动查词」就不用按 Shift） |
| 浏览器扩展（任意网页的文字） | **Shift 悬停** |

## 浏览器扩展：在任意网页查词

Fushi 自带一个浏览器扩展，让你在任何网页上用 app 里的词典查词、制卡。桌面专用（Windows / macOS），Chrome / Edge 这类 Chromium 浏览器；手机上直接在 app 内读。

### 安装

**设置 → 查词 → 外部集成 → 浏览器扩展**，跟着页面上的步骤走：

1. 点 **准备扩展文件**。Fushi 会自动开启查词服务（Yomitan API 服务器），把扩展解压到本机，并把文件夹路径复制到剪贴板。
2. 在浏览器地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，粘贴刚才复制的路径，选那个文件夹。
5. 回 Fushi 点 **检测连接**，显示「插件已连接」就好了。扩展不需要再配任何东西，连接信息已经自动写好。

不放心的话点 **打开试用网页**：Fushi 自己提供的一张网页，右上角点扩展图标应该弹面板，按住 Shift 移到练习句的词上应该弹词典。

### 使用

- **按住 Shift，鼠标移到词上** → 弹出和 app 里一样的词典弹窗（同一套词典、同一个排版）。
- 弹窗里点 **加号** 就制卡，整句会自动带上，卡进你连的 Anki。
- 释义里还有不认识的词，继续 Shift 移上去，嵌套查。
- 弹窗大小在 **设置 → 查词** 里的「扩展弹窗最大宽度 / 高度」调，可以和 app 内弹窗分开设。

### 装不上 / 没反应

- **「查词服务未开启」**：在浏览器扩展那一页先开「Yomitan API 服务器」，或者再点一次「准备扩展文件」。
- **端口 19633 被占用**：多半是你之前装的 Yomitan 拉起的 yomitan-api 组件（一个 Python 进程）。Fushi 会提示，可以直接结束它，或在 Yomitan 高级设置里关掉 Yomitan API 再重开 Fushi 的服务器。
- **「浏览器中加载的扩展不是最新版本」**：Fushi 更新后扩展文件也更新了，去 `chrome://extensions` 点那个扩展的「重新加载」。
- **某些网页取不到词**：文字是画在 canvas 上或者嵌在图片里的页面（一些漫画站、PDF 预览）扩展没法取字，属正常。
- Fushi 关了扩展也就断了——它查的是本机 Fushi 的词典。

## 网页视频：扩展的 Fushi 字幕

流媒体、YouTube 这类网页视频，扩展可以直接在浏览器里帮你边看边查：

- **在视频上显示 Fushi 字幕**：把当前字幕轨叠在视频上，点词或 Shift 悬停就查；字幕可以拖到任意位置、调大小；YouTube 自动字幕这类逐词蹦出来的，开「替代站点原生字幕」改成按整句显示。字幕外观（字体、颜色、底板）在扩展设置里改，字体可以用 Fushi 字体库里的。
- **字幕侧边栏**：Netflix、YouTube、TVer、Bilibili.tv、Hulu（日本）、Prime Video 播放时会自动抓整集字幕进字幕列表，可以从工具栏菜单打开，点一句跳过去；其它站点走通用采集。播放器控制栏里也有一颗 Fushi 按钮。
- **站点没给日语字幕**：扩展的字幕面板里可以搜在线字幕（Jimaku / OpenSubtitles / AJATT），或者把 SRT / ASS / VTT 文件直接拖到视频上。
- **制卡**：查词弹窗里点制卡，卡先进制卡队列，之后在扩展菜单里一次生成（带这一句的画面和声音）。
- 网页上看视频也会计入 Fushi 的沉浸时间。

app 以前的「内置网页播放器」（在 Fushi 里打开网页视频）目前已暂时停用，网页视频请用浏览器扩展。

## 已经在用 Yomitan？

两边可以共存，也可以只留一边：

- **继续用 Yomitan 查网页**没问题，Fushi 的扩展只是多一个选择；两者都用 Shift，装在一起会各弹各的，建议网页查词只留一个。
- 想让 **GameSentenceMiner 之类走 yomitan-api 协议的工具** 改查 Fushi 的词典：开 Fushi 的 Yomitan API 服务器（端口 19633，可设密钥），把工具指向它。
- Textractor / LunaTranslator / mpv 这类抓文本的工具，可以直接把文本推给 Fushi 的「文本钩子（接收文本）」（设置 → 查词 → 外部集成里连它们的 WebSocket），在 Fushi 里逐词点查、制卡，不再需要 texthooker 网页 + Yomitan 那一套。

## 浏览器之外

- **Windows / macOS 全局查词**：在任何应用里选中一个词，按「应用外查词快捷键」（**设置 → 快捷键设置 → 全局（应用外）**），查词卡片在鼠标旁弹出；macOS 第一次要给 Fushi 授权「辅助功能」。同一组里还有「唤起主窗并打开查词页」。
- **Android 全局查词**：在其他应用里长按选中文字，文字菜单里点 Fushi（没有就走分享），弹窗盖在原应用上；也可以用系统级悬浮球。
