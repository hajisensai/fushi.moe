Galgame 的文本 Hook 只能在 Windows 上做（见[Galgame 怎么接进 Fushi？](/faq/galgame)），但很多人更想躺着用手机或 iPad 玩。Fushi 的 **游戏串流** 就是为这个场景做的：游戏照常在电脑上跑、Hook 照常在电脑上抓台词，Fushi 把游戏窗口的画面和声音、连同 Hook 到的台词一起推到另一台设备上，你在那台设备上看、听、点词查词、制卡，触屏和手柄的操作再送回电脑上的游戏。

这个功能目前是**实验性**的：音视频、台词同步和查词已经在真实游戏和安卓设备上跑通过，但输入实效、远程启动和真卡写入的端到端验收还没全部完成。遇到问题欢迎[反馈](/faq/feedback)。

## 它是怎么工作的？谁负责什么？

理解分工能少走很多弯路：

- **Windows 电脑（主机）**：运行游戏、注入 Hook、采集游戏窗口画面和游戏声音、保存词典、连着 Anki，制卡也在这里完成；
- **手机 / 平板（接收端）**：只负责显示画面、播放声音、显示台词、发送输入。接收端**不需要装词典**——你点的词会发回电脑，由电脑上的词典查好再把结果送回来；
- **连接方式**：两边通过 [Fushi 互联](/faq/interconnect)配对，经加密连接协商，然后在**局域网**里直连传输音视频。目前不支持跨互联网串流（不经中转服务器），手机和电脑要在同一个局域网里。

串流的是**游戏那一个窗口**，不是整个桌面：游戏窗口被别的窗口挡住也能继续串（最小化则会停）。同一时刻一个串流只接一台接收设备。

## 哪些设备能当接收端？

游戏模块在不同平台上是两种形态：

- **Windows**：本机游戏库 + 文本 Hook 工作台；游戏页里另有 **串流** 分区，也能当接收端去看另一台 Windows 电脑；
- **Android、iOS / iPadOS、macOS**（以及从源码构建的 Linux 版）：游戏模块就是串流客户端，副标题写着「在电脑上启动游戏并串流到这里」。

所以主机永远是 Windows 电脑；接收端用手机、平板、Mac 都行。iOS 版在 App Store 合规上少了几样在线功能（见[iOS 版少了哪些功能？](/faq/ios-limits)），但游戏串流客户端是保留的。

## 第一次怎么连上？

1. **配对**：先按[Fushi 互联](/faq/interconnect)把手机和电脑配对。接收端游戏页显示「还没有配对的 Windows 主机」时，点 **打开互联设置** 去配。
2. **主机开加密**：Windows 端的互联设置里打开 **互联加密（HTTPS/TLS）**。没开的话接收端会提示「主机未开启 HTTPS」。
3. **主机开着游戏模块**：Windows 端要启用「游戏」模块；否则接收端会提示主机没有开启游戏库。
4. **电脑上开始串流**：照常 **启动并捕获** 一个游戏（Hook 连上之后才能串，否则会提示「请先启动一个已连接 Hook 的游戏」），在捕获工作台点 **开始串流**，状态变成「串流已开启，等待已配对设备加入」。
5. **手机上加入**：打开接收端的 **游戏** 页，它按主机列出「在线 · N 款游戏」和 **正在串流** 的会话，点 **加入**。

也可以从 Fushi 互联设置里的「加入游戏串流」入口进。

## 从手机直接启动电脑上的游戏

不想每次跑去电脑前点「启动并捕获」，可以在 Windows 端的互联设置里打开 **允许远程启动**（默认关闭）：已配对的设备就能从主机的游戏库里选一款游戏直接启动并串流。手机上会依次显示「正在启动游戏…」「等待游戏窗口…」「正在连接串流…」。

几个常见提示：

- 「这台主机未开启远程启动」：去电脑上打开上面那个开关；没开也不影响加入电脑上已经开始的串流；
- 「主机正在运行另一款游戏」：同一时间只跑一款，先在电脑上关掉它，或者直接加入它的串流；
- 「主机缺少捕获组件」：电脑上的 Fushi 需要重新安装或更新；
- 「游戏已启动，但游戏窗口没有及时出现」：有启动器、更新弹窗或加载很慢的游戏会这样，去电脑上看一眼。

远程启动的会话只留给发起启动的那台设备。

## 在手机上怎么玩、怎么查词、怎么制卡？

- **台词**：画面旁边是 **当前台词** 面板——横屏显示在侧边栏，竖屏显示在底部，可以拖动调整大小，也可以用「展开或收起查词面板」收起来只看画面。
- **查词**：点台词里的字，就从你点的位置开始交给电脑的词典查词，弹窗和视频字幕查词是同一套。接了键盘时也能用方向键在台词里移动光标、按 Enter 查词。
- **制卡**：在查词结果里点加号，卡由**电脑**做好写进**电脑的 Anki**，提示「主机已创建卡片」。卡上用的是这一句台词当时的截图和这句的语音（有语音的话）；没有对应语音时照常写入不带句子音频的卡，不会拿别的台词的声音凑数。如果台词已经翻过很久，会提示「这句台词在主机上已过期，请对当前台词查词」。
- **触屏**：有两种方式，菜单里切换——**直接点击**（点哪里就是点游戏的哪里；双指点按是右键、双指拖动是滚轮）和 **触控板**（像笔记本触控板一样移动光标，点按是左键）。
- **手柄**：屏幕上可以显示虚拟手柄（「显示或隐藏手柄」），**配置手柄按键** 可以调按键映射，只对本次串流有效；接实体手柄、硬件键盘也能用，还有软键盘。部分游戏不接受触控点击，会提示改用手柄按键。
- **声音**：可以随时静音 / 播放游戏声音。

## 画质卡顿、操作没反应怎么调？

串流设置（**串流设置**，带「推荐值」一键恢复）里能调：

- **分辨率上限**：360p 到 4K，默认 1080p，不会超过主机游戏窗口本身的尺寸；
- **帧率**：30 / 60 / 90 / 120，默认 60；Galgame 画面大多是静止的，降到 30 也够用；
- **码率**：0.5–150 Mbps，默认 20 Mbps；**自适应码率** 默认开，从一半码率起步再逐步提升；
- **带宽不足时**：均衡 / 保持帧率 / 保持清晰度，默认保持清晰度，文字类游戏建议保持清晰度，字更清楚；
- **视频编码**：自动 / H.264 / VP8 / VP9 / AV1，下次连接生效，设备不支持时自动回退；
- **游戏窗口输入**：默认 **仅窗口**（游戏可以留在后台，输入直接投给游戏窗口）；部分引擎在后台不接收输入，触控无效时改成 **切到前台**。

打开「显示性能统计」可以看到实际分辨率、帧率、码率、丢包、丢帧。提示「输入未送达」时，看后面跟的原因：游戏窗口被最小化或隐藏、或者需要切到前台。电脑上窗口被最小化、游戏关闭、Hook 会话结束，或者 10 分钟没有接收端活动，串流都会自动停止。
