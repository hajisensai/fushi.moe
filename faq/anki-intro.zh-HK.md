## Anki 是什麼

**Anki**（取名自日語「暗記」）是一個免費的**間隔重複**（SRS）記憶軟體：你把想記的東西做成卡片，它算出每張卡快要忘的時候再讓你複習——記得牢的越來越少出現，記不住的反覆出現。用最少的複習時間換最好的記憶效果，是沉浸學習裡唯一必須的"主動學習"工具。

Fushi 和它的關係：**Fushi 負責產卡，Anki 負責複習**。看番、讀書時點詞查到的東西，點加號就做成一張帶例句、原聲、截圖的卡送進 Anki；每天開啟 Anki 把到期的卡過一遍。兩個軟體各幹各的，Fushi 不做複習。

## 裝哪個

| 裝置 | 裝什麼 | 說明 |
|---|---|---|
| Windows / macOS / Linux | **Anki 桌面版** | 去官網 [apps.ankiweb.net](https://apps.ankiweb.net/) 下，免費；再裝 [AnkiConnect](https://ankiweb.net/shared/info/2055492159) 外掛，Fushi 靠它送卡 |
| Android | **AnkiDroid** | Google Play 或 [GitHub](https://github.com/ankidroid/Anki-Android/releases)，免費 |
| iOS / iPadOS | **AnkiMobile** | App Store，付費買斷（幾十美元），是官方給開發籌經費的方式 |

**只從官網和上面這幾個地方下。** 國內搜「Anki 下載」排前面的往往是第三方站放的**多年前的舊版**——最常見的後果就是：別人分享的卡組（`.apkg`）一匯入就報錯、Fushi 建的 Lapis 牌組認不出來、FSRS 找不到開關。裝錯了就卸掉，去官網重灌，資料不會丟（卡在 `collection.anki2` 裡，重灌會保留；不放心先在 Anki 裡「檔案 → 匯出」備份一次）。

多裝置同步：註冊一個免費的 **AnkiWeb** 賬號，桌面和手機都登入，每次複習完點同步。電腦上 Fushi 做的卡，手機上就能複習。

裝好之後怎麼和 Fushi 連：[怎麼連線 Anki？](/faq/anki.zh-HK)

## 卡片長什麼樣

Fushi 一鍵建立的牌組用 **Lapis** 模板（沉浸學習圈最常用的日語卡模板之一）。一張卡分兩面：

**正面**：只有一個詞。

```
   気配
```

你要做的是：看著這個詞，回憶它的讀音和意思。**正面故意什麼都不放**——沒有例句、沒有發音——因為你在字幕和書裡遇到它時也只有這個詞。

**背面**（翻過去之後，從上到下）：

- 詞 + 振假名 + **音調**標記（高低音在哪個位置）；
- **發音**：單詞的讀音音訊，來自你的發音庫；
- **例句**：你制卡時那句臺詞 / 那行文字，詞在句裡高亮，旁邊是那一幕的**截圖**和這一句的**原聲**；
- **釋義**：你選的那本詞典的解釋（預設日日在前）；
- 詞頻等輔助資訊。

例句、圖片、音訊在背面的位置和高亮樣式，在 Fushi 的 **Anki 設定** 裡的 Lapis 外觀選項裡調，不用碰 Anki 的模板程式碼。Lapis 模板本身還支援「正面顯示整句、猜句中加粗的詞」的句子卡，那是模板欄位層面的開關，進階再折騰。

## 每天怎麼複習

1. 開啟 Anki，點 Fushi 建的那個牌組。
2. 它會按順序給你**今天到期的舊卡**和**一定數量的新卡**（預設每天 20 張新卡，可以在牌組選項裡改；建議 10–20，堅持比數量重要）。
3. 每張卡：看正面回憶 → 翻面 → 按「重來」或「良好」（怎麼按見[Anki 怎麼用](/faq/anki-basics.zh-HK)）。
4. 牌組顯示 0 就完事，一般 15–30 分鐘。做多了就減新卡，別停。

**卡片來源始終是你自己看的東西**。不要去下別人的"N1 詞彙卡組"當主力——那些詞沒有你的上下文，背起來又慢又枯燥；唯一的例外是入門時的 [Kaishi 1.5k](/zh-hk/immersion) 這種為零基礎準備的啟動卡組。

## 常見狀況

- **卡組匯入報錯 / 「檔案格式不支援」**：裝的是第三方站的舊版 Anki，去官網重灌最新版。
- **Fushi 說連不上 Anki**：桌面版要開著 Anki 且裝了 AnkiConnect；手機看[連線 Anki](/faq/anki.zh-HK)。
- **卡進了但是空的 / 欄位錯位**：Fushi 的 Anki 設定裡重新對映欄位，或直接讓 Fushi 重建 Lapis 牌組。
- **複習堆到幾百張**：降新卡數、開 [FSRS](/faq/anki-basics.zh-HK)，然後照常做——積壓是習慣斷了的結果，不是軟體的問題。
