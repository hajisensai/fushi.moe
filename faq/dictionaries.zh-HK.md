Fushi 認三種詞典格式，都是直接匯入、不用轉換：

- **Yomitan（Yomichan）詞典 zip**——瀏覽器查詞生態的通用格式，網上為 Yomitan 整理的辭典庫 Fushi 都能用；
- **MDict 的 `.mdx`**——GoldenDict / 歐路 / DictTango 那一大批詞典用的格式，帶圖片和發音的還有一個同名 `.mdd`，一起選上；
- **Lingvo 的 `.dsl`**。

Yomitan 詞典的結構化欄位最全（音調、詞頻、變形），MDX 勝在存量大——很多國語辭典、雙解辭典只有 MDX 版。

## 推薦包已經給了什麼

新手引導裡的[推薦包](/faq/pack.zh-HK)（約 9.5 GB）裝好之後有：

- **日語單詞詞典**（日日 / 日中）；
- **音調詞典**（查詞彈窗裡的音調標記）；
- **詞頻詞典**（詞條旁的頻率角標、[按詞頻重排新卡](/faq/anki-basics.zh-HK)靠它）；
- **本地發音音訊庫**（日語 + 英語），查詞時點喇叭、制卡時自動帶單詞發音。

只是學日語看番讀書的話，推薦包夠用很久，不急著加。

## 自己加詞典

**設定 → 詞典**，從檔案匯入（可以多選，後臺匯入），也可以把 `.zip` / `.mdx` / `.dsl` 檔案直接拖進詞典頁；MDX 詞典自帶的 CSS 要和詞典包一起導。導進來的詞典按類別歸組——日日 / 日英 / 雙語 / 語法 / 詞頻 / 漢字 / 人名 / 補充——每本可以：

- **排序**：彈窗裡釋義按這個順序出現，把最常看的放前面；
- **隱藏**：暫時不用的藏起來，不裝載、不佔查詞時間；
- **摺疊**：預設收起，點開才看。

裝多少合適？Yomitan 玩家動輒七八十本，但每多一本查詞就慢一點、彈窗就長一點。一個夠用的組合：

| 類別 | 裝幾本 | 幹什麼用 |
|---|---|---|
| 國語辭典（日日） | 1–2 | 主力。學習向的小型辭典釋義簡單、有振假名；中型辭典收詞多 |
| 日中 / 雙解 | 1 | 日日看不懂時兜底；越早少看越好 |
| 音調 | 1 | 彈窗裡標高低音，跟讀靠它 |
| 詞頻 | 1–2 | 判斷一個詞值不值得做卡、重排新卡 |
| 文法 | 1 | 查「〜てならない」這類句型，語法書不用翻 |
| 漢字 | 0–1 | 想看筆順、音訓讀時加 |

日中雙解辭典、物書堂那些商業辭典的電子版都是有版權的，去哪找我不列；Yomitan 社群裡公開維護的免費辭典（JMdict 系、頻率表、文法辭典、Wikipedia 摘要之類）夠搭起這套骨架。手頭已經有 MDX 詞典（以前給 GoldenDict / 歐路裝的）的，直接拖進來就行，不用再找 Yomitan 版。

## 發音從哪來

**設定 → 查詞 → 管理音訊來源**，可以有好幾個來源、按順序取：

- **本地音訊資料庫**：推薦包裡的發音庫就是這種；它和 Yomitan「本地音訊伺服器」（NHK / 新明解 / jpod / forvo 那套）用**同一種資料庫**——已經為 Yomitan 下過那份資料的，「新增本地音訊資料庫」指向它的 `entries.db` 就能直接用，可以選引用原檔案不復制。
- **自定義連結**：任何返回音訊的 http(s) 地址，連結裡用 `{term}` / `{reading}` 佔位。
- **Fushi 互聯**：用電腦上的發音庫，手機不用裝 9.5 GB，見[互聯](/faq/interconnect.zh-HK)。

「查詞時自動朗讀」開著的話，彈窗一出來就播第一個來源的發音。

## 常見狀況

- **無法識別的詞典格式**：Yomitan 詞典要是 zip（裡面有 `index.json`，舊版 Yomichan 的也認）；MDX 只選 `.mdx`（和它旁邊的 `.mdd`），不要先解壓。
- **MDX 詞典沒有圖 / 沒有發音**：少選了同名的 `.mdd`，補導一次。
- **查詞變慢 / 彈窗太長**：隱藏用不到的詞典，或者摺疊。
- **同一個詞幾本辭典重複太多**：把日中放到最後並摺疊，先看日日。
- **彈窗裡的字型、顏色、佈局**：設定 → 查詞 裡改樣式，每本詞典可以單獨設。
