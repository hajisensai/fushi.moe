文本字幕本质上都是一张表：**这句话从几分几秒显示到几分几秒**。格式的差别在于表里还能写多少别的东西。

| 格式 | 后缀 | 能写什么 | 常见来源 |
|---|---|---|---|
| SubRip | `.srt` | 时间 + 文字，顶多粗体斜体 | 流媒体抽出、Jimaku、自动生成 |
| SubStation Alpha | `.ass` / `.ssa` | 字体、颜色、描边、位置、动画、卡拉 OK | 字幕组、BDRip |
| WebVTT | `.vtt` | 时间 + 文字，少量样式 | 网页播放器、在线源 |

## SRT：最简单的那种

```
12
00:01:04,520 --> 00:01:07,180
魔法使いといえば、たったひとつ。
```

序号、起止时间、文字，完了。没有字体、没有位置，怎么显示全看播放器。因为什么都不带，所以**哪都能放、谁都能改**——用记事本就能修一个错字或者把时间整体挪两秒。

Jimaku 上的日语字幕、从 Netflix 之类流媒体抽出来的字幕，大多是 SRT。

## ASS：字幕组的标配

```
[V4+ Styles]
Style: Default,Noto Sans JP,60,&H00FFFFFF,...

[Events]
Dialogue: 0,0:01:04.52,0:01:07.18,Default,,0,0,0,,{\an8}魔法使いといえば、たったひとつ。
```

ASS 文件先定义一组**样式**（字体、字号、颜色、描边、阴影），每句对白引用一个样式；文字里还能塞 `{\an8}` 这样的**特效标签**——放到屏幕顶部、换颜色、淡入淡出、卡拉 OK 逐字变色。字幕组翻译屏幕上的招牌、短信、OP/ED 歌词时，靠的都是这套东西，所以字幕组发布的几乎都是 ASS。`.ssa` 是它的旧版，能读的播放器都一起读。

代价是它对播放器要求高：一份 ASS 在不同播放器里可能长得不一样，用的字体没装就会退回默认字体。

## VTT：网页版 SRT

```
WEBVTT

00:01:04.520 --> 00:01:07.180
魔法使いといえば、たったひとつ。
```

和 SRT 几乎一样，只是给浏览器 `<video>` 标签设计的（时间用点不用逗号，开头多一行 `WEBVTT`）。网页播放器、Aniyomi 视频源那种在线线路自带的字幕轨，基本都是 VTT。

## 在 Fushi 里有什么区别？

**没有本质区别**——四种 Fushi 都能读，不管是外挂文件还是 mkv 里的内封轨。

Fushi 拿到字幕后做的第一件事是**把样式和文字分开**：查词、制卡、写进 Anki 的都是纯文字，`{\an8}` 这类标签不会混进句子里。ASS 的一部分样式会照着渲染（对齐位置 `\an`、`\pos`、斜体粗体、颜色、字号、换行），卡拉 OK、动画、矢量绘图这些会被静默去掉——Fushi 的字幕是逐字可点的一层，不能像 mpv 那样把字幕画进画面，否则就点不了词了。

所以学日语的话，**字幕格式不用挑**，挑的是内容：一份逐句对得上台词的日语字幕，比什么特效都重要。字幕组的中文 ASS 再漂亮也只能当参考，制卡要日语的。

## 顺带：图形字幕

PGS（蓝光）、VobSub（DVD）不是文本，是一张张位图，没有「格式」可言——Fushi 能显示但不能点词，详见[外挂、内封、内嵌字幕是什么？](/faq/subtitle-types#内封字幕)。
