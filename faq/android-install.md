Fushi 的安卓版不在应用商店里，直接从[下载页](/zh-cn/download)下载 APK 安装。最低要求 **Android 7.0（API 24）**，比这更老的系统装不上。

## APK 该下哪一个？

下载页「正式版」下面有三行安卓包，区别只在 CPU 架构：

| 下载页那一行 | 文件名结尾 | 适合谁 |
|---|---|---|
| Android (arm64) | `-arm64-v8a.apk` | 绝大多数手机选这个，需 Android 7.0+ |
| Android (arm32) | `-armeabi-v7a.apk` | 较老的 32 位机型 |
| Android (x86_64) | `-x86_64.apk` | 模拟器 / x86 平板 |

拿不准就选 **arm64**：近几年的手机、平板、大部分电子墨水阅读器都是 64 位 ARM。只有它装不上（系统提示与设备不兼容、解析包出错之类）时，再换 arm32 试试。在电脑上用安卓模拟器跑 Fushi 的，选 x86_64。

切到「调试版」后，安卓只剩**一行 arm64 包**（文件名结尾 `-debug.apk`），不用再挑；32 位老机型和 x86 模拟器装不了调试版，请用正式版对应的包。正式版和调试版的区别见[正式版和调试版有什么区别？](/faq/channels)。

## 安装步骤

1. 用手机浏览器打开[下载页](/zh-cn/download)，点对应那一行的「下载」。下载页会分段并发拉取并做 SHA-256 校验，看到「SHA-256 校验通过」说明文件完整。网络慢可以改用旁边的「GitHub 直链」，见[下载很慢或者打不开怎么办？](/faq/download)。也可以在电脑上下载好，再传到手机里。
2. 点开下载好的 APK。第一次从浏览器或文件管理器装应用时，系统会要求允许它「安装未知应用」，按提示去打开，再回来点安装。各家系统措辞不同，有的还会额外弹一次安全扫描，选继续安装即可。
3. 装好后打开 Fushi，第一次启动会进入新手引导：选界面语言和主题、勾选要用的功能、下载推荐包、连接 AnkiDroid。详见[新手引导中途关掉了，怎么重新打开？](/faq/onboarding)。

推荐包（日语词典 + 日 / 英发音音频库）约 9.5 GB，在手机上下载前先确认存储空间够、最好连着 Wi-Fi。只学别的语言可以跳过，自己导入词典，见[只能学日语吗？](/faq/languages)。

## 安卓上怎么更新？

不用每次回下载页手动下载。Fushi 会自己检查新版本，**设置 → 系统与关于** 的「更新设置」里有：

- **更新通道**：稳定版 / 测试版 / 调试版。
- **首选下载源**：自动（推荐）/ Cloudflare 镜像 / GitHub 直连，所选来源不可用时会自动回退。
- **检查更新**：手动立刻检查一次；「查看更新日志」可以看各版本改了什么。
- **自动安装更新**：打开后发现新版会自动下载并拉起安装。

应用内更新会**按你手机的架构自动挑包**：装的是 arm64 就继续拿 arm64，不会给你下错。第一次走应用内更新时，系统会弹「允许安装更新」——这是安卓要求每个能装 APK 的应用单独授权，去系统设置里允许 Fushi 安装应用，回来点「重试安装」就行。

## 平板和墨水屏阅读器能用吗？

能。安卓平板装的是同一个 APK，界面会按屏幕宽度自动排版，横屏看番、分栏读书都没问题；接上键盘或手柄也能操作，大部分页面可以用方向键和确认键走完。

用文石、掌阅这类安卓系统的电子墨水阅读器读轻小说、看漫画时，到 **设置 → 外观与交互 → 界面** 打开「墨水屏模式」：它会换成纯黑白主题、关掉动画、把高亮改成线式，减少墨水屏刷新时的残影。查词设置里还有一项「查词弹窗瞬时滚动」，配合起来刷新会少很多。这类设备大多也是 64 位 ARM，下 arm64 包即可；少数老款是 32 位，装不上时换 arm32。

## 常见问题和坑

- **正式版和调试版不能同时装**。两者是同一个应用（同一个包名），装调试版会直接覆盖正式版、数据接着用，反过来也一样。
- **从新版退回旧版会装不上**。安卓不允许用版本号更低的包覆盖安装，所以从较新的调试版退回较早的正式版，系统会拒绝。这时只能先在 **设置 → 同步与备份** 导出备份，卸载后装旧版，再导入备份。换通道前先导出一份备份，就是为了这一刻。
- **卸载会删掉数据**。安卓上 Fushi 的数据库（阅读进度、学习记录、设置）、导入进来的词典和书都放在应用自己的存储空间里，卸载即清空；只有你直接从手机存储里引用的视频这类原文件还留在原处。卸载前务必先备份，或者开好云备份 / [互联备份](/faq/interconnect)。
- **AnkiDroid 制卡**：安卓上制卡连的是 AnkiDroid，先从应用商店装好 AnkiDroid，再在引导或 **设置 → 制卡** 里连接，见[怎么连接 Anki？](/faq/anki)。
- **桌面才有的功能**：Galgame 文本 / 语音捕获只在 Windows 上，手机上可以用[游戏串流](/faq/game-streaming)玩电脑里的游戏；书库很大、不想在手机上重复导入的，让电脑当 [Fushi 互联](/faq/interconnect)主机，手机直接浏览、拉流。

其他平台见 [Windows 怎么安装 Fushi？](/faq/windows-install)、[iOS 版怎么装？为什么少了一些功能？](/faq/ios-limits)，全平台对比见[支持哪些平台？](/faq/platforms)。
