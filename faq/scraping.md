## 刮削是什么

你的硬盘上有一个文件叫

```
[VCB-Studio] Sousou no Frieren [01][Ma10p_1080p][x265_flac].mkv
```

对电脑来说它只是一串字符。**刮削**（scrape）做的事是：先从文件名里认出「这是《葬送的芙莉莲》第 1 集」，再去在线资料库把这部作品的**海报、简介、评分、季和集的列表、放送时间**拉下来存到本地。刮完之后，你的视频库就从一堆文件名变成带封面的作品墙，点进一部能看到每集的标题和缩略图。

这个词来自 Jellyfin / Plex / Kodi 那类媒体库软件（英文 scraper，"刮取" 网页上的资料），资料库则是 [TMDB](https://www.themoviedb.org/)、[MAL](https://myanimelist.net/)、[AniDB](https://anidb.net/)、[Bangumi](https://bgm.tv/) 这些站。

## Fushi 刮什么

| 类型 | 资料来源 | 拿到什么 |
|---|---|---|
| **视频**（番剧、剧集、电影） | MAL（经 Jikan）为主，TMDB 兜底；可选 AniDB 文件识别 | 海报、简介、评分、季 / 集列表、放送信息 |
| **书、漫画** | Bangumi | 封面 |
| **游戏**（galgame） | VNDB、Bangumi | 封面、简介、发行日等 |

视频是刮削的主战场，下面主要讲它。

## 视频：默认就是自动的

导入本地文件夹时有两种组织方式：

- **按作品**（默认）：按文件名识别作品与分集，再匹配作品资料——**会刮削**。
- **按文件夹**：每个一级子文件夹一个合集，只整理不刮。适合按难度、课程、主题分的目录。

选了「按作品」，扫描完成后 Fushi 就自动开始刮（来源的「扫描后自动刮削」和全局「自动刮削条目资料」默认都开着）；番剧下载来的视频在入库前也会自动刮一遍（`下载 → 整理 → 字幕 → 刮削 → 入库`）。刮完还有一步 **刮削后自动补字幕**：没字幕的视频自动从已配置的在线字幕源取一条。

刮削是按**置信度**来的：文件名解析出的标题在资料源里有**唯一精确命中**才自动应用；有好几个同名候选、或者两边都查不到，就不瞎猜，丢进 **待确认** 等你点。视频库顶上会有一条「N 部作品还没确认身份」提示，点「去确认」。

## 待确认：手动指定作品

视频来源页的 **后台任务** 面板分 **当前任务 / 待确认 / 最近任务** 三栏。在「待确认」里点一部作品：

- **按标题**搜：搜索结果带封面和年份，选中即绑定；
- **按作品 ID**：选 MAL、TMDB 电影或 TMDB 电视剧，输入 ID，或者直接把作品页的官方链接贴进来。

已经刮错的作品也能改：合集菜单 → **重新刮削资料与封面** → 选正确的条目。手动指定过的绑定受保护，以后自动刮不会再改它；自己设的封面（手动选的本地图、目录里自带的 poster）也一律不覆盖。

## 文件名怎么起才认得准

Fushi 的文件名解析和 Jellyfin / anitomy 一路：能剥掉字幕组 tag、画质、编码，认 `S01E01`、`第2季`、`2nd Season`、`Season 2` 这些写法。稳妥的布局：

```
番剧/
  葬送的芙莉莲/
    [VCB-Studio] Sousou no Frieren [01][Ma10p_1080p].mkv
    [VCB-Studio] Sousou no Frieren [02][Ma10p_1080p].mkv
  Hibike! Euphonium/
    Season 2/
      Hibike! Euphonium - 01.mkv
```

几条经验：

- **一部作品一个文件夹**，季号可以只写在子文件夹名上（`Season 2` / `S02` / `第2季`）；
- 集号**两位补零**（`01` 而不是 `1`）——`Show 2.mkv` 到底是第 2 季还是第 2 集是猜不准的，不过同一目录下 `Show 1 … Show 12` 这种成批的文件 Fushi 会拿兄弟文件对比出集号；
- 标题用**原名或官方英文名**比自己起的中文简称好认；
- 文件名认不出来又不想改名，用 **识别词**（下面）或者开 AniDB 文件识别。

## 进阶设置

都在 **设置 → 服务 → 元数据刮削** 和各来源的 **来源刮削设置** 里：

- **主资料源**：默认 MAL；主源没有唯一命中时自动问另一个源。资料语言（简介、TMDB 海报的语言）可以按来源单独设。
- **识别词**：刮之前先改写文件名，一行一条规则——屏蔽直接写正则；替换 `A => B`；集偏移 `前 <> 后 >> EP+1`（比如把从 13 开始编号的第二季偏回 1）。
- **通过 AniDB ED2K 识别文件**：按文件内容的哈希去 AniDB 认作品和集号，文件名乱成什么样都认得出。需要自己的 AniDB 账号，AniDB 的 UDP 登录不加密，只在可信网络下开。
- **TMDB API Key**：内置了一个，刮不动或想用自己的配额时再填。
- **NFO 与图片写入策略**：刮到的资料可以写成 `.nfo` 文件和 `poster.jpg` 放到视频旁边——Jellyfin / Kodi 也认这套格式。默认「仅缺失时写入」，第三方或你改过的文件受保护，不会被覆盖。
- **锁定字段**：作品详情里锁住标题、封面等字段，下次重刮保留你改的值。
- **清理全部刮削记录**：把资料、绑定和 Fushi 自己生成的 NFO / 封面全清掉，视频文件、观看进度、字幕不动。

## 书、漫画、游戏

- **书 / 漫画**：编辑对话框里 **在线匹配封面**，按书名 / 作者搜 Bangumi，选一个用。
- **游戏**：卡片菜单 **刮削元数据**，打开就按当前名字自动搜 VNDB / Bangumi，候选带封面，点「使用」封面和简介一起落。
- 库页菜单里的 **全部刮削** 可以批量跑：视频按标题、年份综合打分，书和游戏要求标题唯一且完全一致才自动应用，其余进待确认。

## 用互联时

手机连着电脑主机看远端视频，资料以主机刮的为准，会自动同步到手机；某部没刮的可以在手机上选 **在主机上刮削**，或 **本机刮削并回写主机**。见[Fushi 互联](/faq/interconnect)。

## 常见状况

- **认错作品**：待确认 / 重新刮削里手动指定；反复认错的文件名加一条识别词。
- **一部番被拆成好几部**：一般是文件名里的季 / 集写法不一致（有的 `S02E01`、有的 `- 13`），统一一下或者用识别词的集偏移。
- **海报是别的语言**：改来源的「资料语言」。
- **搜索失败 / 限流**：MAL 走 Jikan 有速率限制，批量刮会慢一点是正常的；连不上就在设置里配代理。
- **刮削和「Bangumi 同步」不是一回事**：刮削是把资料拉进来，Bangumi 同步是把你的观看 / 阅读进度记到 Bangumi 账号上。
