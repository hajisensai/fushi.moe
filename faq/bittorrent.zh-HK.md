## BT 是什麼

平時下載是「一臺伺服器發、你來收」。**BT**（BitTorrent）反過來：**沒有伺服器，所有正在下這個檔案的人互相傳**——你下到的每一塊資料，馬上就可以傳給別人；你從幾十個人那裡各拿一點，拼成完整檔案。

幾個詞：

- **種子（.torrent）/ 磁力連結（magnet:）**：不是檔案本身，是檔案的「身份證」——檔名、大小、每一塊的校驗值。有了它才能去找持有這個檔案的人。磁力連結就是把這些資訊壓成一行文字，比 .torrent 檔案方便傳。
- **做種（seed）**：檔案下完了還開著、繼續傳給別人的人。**做種數**越多，下得越快；做種數為 0 的老資源就下不動了。
- **吸血 / 分享率**：只下不傳叫吸血；分享率 = 上傳量 ÷ 下載量。BT 靠互相上傳才能活。
- **Tracker**：幫你找人的「電話簿」伺服器；**DHT** 是不靠 Tracker、節點之間互相打聽的方式——兩者都開，找到的人最多。
- **索引站**：列出「有哪些種子」的網站，本身不存檔案。番劇圈最大的是 **Nyaa**；電影劇集有各種公共索引；**Torznab** 是一種統一的索引介面，Jackett / Prowlarr 這類工具把上百個索引站翻譯成它。
- **埠對映（UPnP / NAT-PMP）**：讓路由器把外面的連線轉給你，別人才能主動連上你；連不上也能下，只是慢一點。
- **IPv6**：新一代的網路地址。IPv4 下大多數人躲在路由器後面互相連不上，要靠埠對映；IPv6 每臺裝置都有公網地址，做種的人之間直接能連——開了 IPv6 通常能多找到一大批做種。

BT 本身只是一種傳輸協議，傳什麼內容是另一回事——它下 Linux 映象和下番劇是同一套東西。

## Fushi 整合了什麼

Fushi 不需要你另外開一個下載器，整條鏈在 app 裡：

| 環節 | Fushi 裡的東西 |
|---|---|
| 下載引擎 | **內建 libtorrent**（Windows / macOS / Android）；或 **外接 qBittorrent**（連它的 WebUI） |
| 搜尋來源 | **Nyaa**（動漫）、**apibay**、**Knaben**（電影與劇集），加自己的 **Torznab 索引器**（Jackett / Prowlarr） |
| 作品識別 | AniList 搜作品、AniDB 確認身份，搜尋詞按原名 / 別名自動填 |
| 字幕 | 勾「附帶字幕」自動去 **Jimaku** 配日語字幕；也接了 OpenSubtitles |
| 入庫 | 下載完成 → 整理改名 → 配字幕 → [刮削](/faq/scraping.zh-HK)資料 → 進影片庫，全自動 |
| 追更 | **訂閱**：每 15 分鐘檢查一次，新集自動下 |
| 有聲書 | 有聲書目錄的下載也走同一個引擎，下完按素材庫自動配對齊檔案 |
| 互聯 | 訂閱和下載可以「執行在主機」——交給電腦或 NAS 上的 fushi_server 跑 |

## 怎麼用

### 內建引擎：什麼都不用配

底欄 **下載 → 番劇下載**，搜作品名，點 **下載** 就進隊列了。第一次會問你要不要 **啟用上傳 / 做種**——預設關，開了會佔上傳頻寬，但對 BT 網路更友好。

- 可以 **邊下邊播**：任務開始後先入庫，從影片庫開啟。
- 有磁力連結或 .torrent 檔案？**貼上連結下載** / **選擇種子檔案**。
- 任務詳情裡能看節點、Tracker 狀態、做種時長。

用法細節（篩生肉、只看 Trusted、合集、訂閱）見[番劇是線上看還是下載？](/faq/anime-download.zh-HK)。

### 外接 qBittorrent

已經有一臺常開的機器跑著 qBittorrent（NAS 常見），或者平臺沒有內建引擎（iOS）：

**設定 → 下載 → 引擎與做種**，下載引擎選 **外接 qBittorrent**，填 **qBittorrent WebUI 地址**（比如 `http://192.168.1.10:8080`）、使用者名稱密碼，可選一個 **qBittorrent 分類**（Fushi 的任務會打上它，方便在 qB 裡分辨）。

qBittorrent 跑在別的機器上時，它看到的路徑和你這臺機器不一樣，要配 **qBittorrent 路徑對映**：把 qB 的下載根目錄（比如 `/downloads`）對映到本機能訪問的位置（比如 `\\nas\downloads` 或掛載的磁碟機代號），下完 Fushi 才能找到檔案入庫。

搜尋結果裡也可以直接 **推送下載** 交給 qB，其餘流程一樣。

### 引擎與做種設定

都在 **設定 → 下載 → 引擎與做種**：

- **上傳 / 做種**：開關、上傳限速、分享率上限、做種時長上限——想回饋就開，到了上限自動停。
- **限速**：下載 / 上傳 KB/s；預設**不作用於區域網**（互聯對端之間全速）。
- **監聽埠**（預設 6881）、**UPnP / NAT-PMP** 埠對映、**DHT**、**本地節點發現（LSD）**：預設都合理，連線數少就檢查路由器有沒有攔埠。
- **反吸血**：封掉只下不傳、偽造進度的客戶端。
- **Tracker 訂閱**：填一個 Tracker 列表地址，新任務自動加進去，對做種少的老資源有幫助。
- **記憶體佔用上限**、**最大活躍下載 / 做種數**：手機上可以調小。
- **代理**：設定 → 網路代理裡，P2P 流量預設**直連**；「走代理」全部經代理（很多代理商禁 BT），「混合」只有 Tracker 請求走代理、節點直連。只對內建引擎生效，外接 qB 在它自己那邊配。

### Torznab 索引器

內建的幾個來源不夠（比如想搜某個私有站或小眾索引），**設定 → 服務 → Torznab 索引器 → 新增索引器**：填 Jackett / Prowlarr 給的端點和 API 金鑰，可選分類 ID 和優先順序。金鑰不隨備份匯出，會經互聯同步給已配對裝置（可關）。

內建來源被關掉了搜尋會提示「本次搜尋沒有可用的來源」，去 **設定 → 下載 → 外部資源與字幕來源** 重新啟用。

## 常見狀況

- **下不動 / 速度 0**：先看做種數，0 就換資源；再看路由器有沒有攔監聽埠、UPnP 有沒有開；試著開一下 Tracker 訂閱。還有一個常被忽略的：**IPv6 沒開**。現在很多做種的人只在 IPv6 上可達，路由器和系統都開了 IPv6（運營商一般都給）之後，能連上的做種數往往一下多出好幾倍，而且 IPv6 不用埠對映也能被主動連上。
- **搜不到**：Nyaa 只有動漫，電影劇集看 apibay / Knaben；連不上索引站就配代理（代理隻影響搜尋和 Tracker，節點連線看上面）。
- **推送到 qBittorrent 失敗**：WebUI 地址、賬號密碼、qB 有沒有開「Web 使用者介面」；跨機器的路徑對映沒配就會下完找不到檔案。
- **改名後不做種了**：在 Fushi 裡改名 / 移動是通過引擎做的，做種不斷；在檔案管理器裡手動改就斷了。
- **iOS**：按 App Store 規定沒有搜尋和下載功能。
- **本次安裝缺少內建引擎執行庫**：裝的是不完整的包，重灌完整安裝包或改用外接 qB。
