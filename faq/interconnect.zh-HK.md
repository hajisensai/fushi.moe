Fushi 互聯是**你自己裝置之間的直連**（在家走區域網，出門也能連回來）：一臺裝置當**主機**（把自己的庫開放出去），其他裝置當**客戶端**連上它。最常見的用法就是電腦當主機——番劇、書、漫畫、9.5 GB 的詞典包、Anki 都在電腦上；手機當客戶端，躺著看、隨手查、制的卡進電腦的 Anki，進度和統計兩邊一起走。

同一臺裝置同一時間只能當主機或客戶端之一。互聯和雲備份（Google Drive / WebDAV…）是兩條獨立通道，可以同時開。

## 準備

- 第一次配對時手機和電腦最好連**同一個 Wi-Fi / 區域網**（不在同一網路也能配，見下面「不在同一區域網」）。
- 兩邊都裝好 Fushi 並更新到同一個大版本，舊版本配對會提示「對方版本過舊」。
- 電腦端在 Windows / macOS 都可以當主機；手機端 Android / iOS 當客戶端（iOS 不能當主機）。

## 第 1 步：電腦開主機服務

電腦上：**設定 → Fushi 互聯**

1. 開啟 **啟用互聯**。
2. 進 **主機服務**，開啟 **啟用同步服務**。預設埠 **38765**，新裝置第一次開主機會預設開啟 **互聯加密（HTTPS/TLS）**——留著，後面「制卡到主機的 Anki」「同步主機服務配置」之類的功能要它。
3. 狀態變成「執行中 · 埠 38765」就行了。Windows 第一次會彈防火牆詢問，勾上專用 / 私有網路允許。

主機是被動的一方：它自己不需要點「同步」，一切由客戶端發起。

## 第 2 步：手機配對

手機上：**設定 → Fushi 互聯 → 啟用互聯 → 配對與裝置**

- 下方 **區域網裝置** 列表會自動發現同網路裡開了主機的電腦，**點它**；
- 電腦上彈出「配對請求」，點 **允許**；
- 手機提示「配對成功，已自動填入 token」。完成。

之後「已新增的對端」裡就有這臺電腦，電腦的「已配對裝置」裡也有這臺手機。配對是一次性的，以後自動連上。

**掃碼 / 連結 / NFC 配對**：電腦的主機服務裡點 **顯示配對二維碼**，手機上點 **掃碼配對** 掃一下就配好，不用在電腦上再點允許，也不用手輸地址（二維碼 5 分鐘內有效、只能配一臺）。掃不了碼的裝置用「複製配對連結」+「貼上配對連結」。Android 上已經配對過的手機還能 **寫入 NFC 貼紙**，之後別的手機碰一下貼紙就能發起配對（仍要主機確認）。

**列表裡沒發現電腦？** 多半是路由器開了 AP 隔離、或者電腦防火牆攔了 mDNS。改成手動新增對端地址：在電腦上看一眼本機區域網 IP（Windows：`ipconfig`；macOS：系統設定 → Wi-Fi → 詳細資訊），在手機上填

```
https://192.168.1.23:38765
```

主機開了 TLS 就用 `https://`，沒開用 `http://`（只寫 `IP:埠` 會按 http 處理）——填反了 Fushi 會直接提示該用哪個。

### 不在同一區域網（出門在外、Tailscale、公網等）

配好之後，手機會自動學到電腦的全部地址（區域網、IPv6、Tailscale 這類虛擬網絡卡、你填的公網地址），每次連線同時探測、挑能通的那條，不用你手動切換：

- 電腦有公網地址或反代域名的話，填進主機服務的 **公網 / 反代地址**，已配對裝置會自動學到；
- 兩邊都沒有公網 IP，開啟 **允許經 P2P 隧道遠端連線**：直連都不通時走 P2P 隧道（會用到 iroh 的中繼與發現伺服器，走中繼時看影片可能較慢；也可以填自建中繼）。

不在同一網路時第一次配對，最省事的是掃配對二維碼；也可以手動填一個手機能連到的地址（比如兩邊都裝了 [Tailscale](https://tailscale.com/)），這時會多一道 **PIN**：電腦點「允許」後螢幕上會常駐顯示一個 6 位 PIN，手機上輸入它。PIN 不經過網路傳輸，是防止別人冒充配對的。

第一次連上時手機會記住電腦的證書指紋；以後再連時如果證書變了（電腦重灌過 Fushi），會彈「證書已變更」——確認是自己重灌的，就點「清除已存指紋並重新信任」重新配對。

## 第 3 步：手機上能做什麼

配好之後手機上什麼都不用再設，各處會自動多出來一些東西：

**看電腦上的東西**

- 影片、書、漫畫各自的來源列表裡多一個 **Fushi 互聯** 來源，點進去就是電腦的庫：影片直接流播，書直接讀，漫畫（含電腦上 OCR 過的 mokuro）直接翻。
- 想離線帶走就點 **下載到本機**。
- 網路差的時候，電腦的互聯設定裡開啟 **為對端轉碼影片**，手機播電腦的影片時即時轉成低位元速率（需要 ffmpeg，會佔電腦 CPU）。
- 「同步」設定裡的 **顯示遠端條目**（預設開）會把電腦有、手機沒有的書和影片顯示成帶雲角標的佔位卡，書架上一眼看到，點了就播 / 下載。

**用電腦的詞典和發音**

- **查詞 → 遠端詞典查詢**：手機本地查不到的詞去電腦上查。手機不裝 9.5 GB 的推薦包，也能查到電腦上裝的所有詞典。
- **管理音訊來源 → Fushi 互聯**：單詞發音從電腦的本地發音庫拿。

**制的卡進電腦的 Anki**

- 手機的 **Fushi 互聯 → 交給 Fushi 互聯服務端** 裡開啟 **制卡到 Fushi 互聯服務端**（制卡設定裡也有同一個開關）：手機上點加號做的卡走電腦，用電腦的牌組和欄位設定，進電腦那個 Anki。手機上不用裝 AnkiDroid / AnkiMobile 也行。
- 漫畫 OCR 引擎也可以選 **交給已配對的 Fushi 互聯服務端來跑**，手機不下任何模型。

**讓電腦替手機幹活**

- 下載的「下載到」/「下載執行裝置」選電腦，番劇、書等就下在電腦上；[AI 下載](/faq/ai-download.zh-HK)也能交給電腦辦。
- 電腦上的 Galgame 可以[串流到 Android 手機](/faq/galgame.zh-HK#手機上玩電腦裡的遊戲)上玩、查詞。

**進度和統計自動同步**

- 閱讀 / 觀看進度、閱讀與觀看時長、查詞與制卡計數、收藏的詞和句子，兩邊**雙向合併**（「與已配對裝置共享」裡的兩個開關，預設開）。

**手機往電腦傳**

- **上傳到互聯對端** 裡有書籍 / 詞典 / 有聲書 / 影片四個開關，**預設全關**：想把手機上的東西同步給電腦再勾對應那個。
- **用互聯做備份後端**：把雲備份那條通道也指到電腦上，不用雲盤。

## 電腦當客戶端也可以

角色不是綁死的：家裡桌上型電腦當主機、筆記本當客戶端，筆記本上一樣能流播桌上型電腦的番劇、用它的詞典。只是一臺裝置不能同時既開主機服務又連別的主機——想換角色先把主機服務關掉。

## 沒有電腦常開？用無頭服務端

NAS / 家用伺服器 / VPS 上可以跑 [fushi_server](https://github.com/hajisensai/Fushi/blob/develop/packages/fushi_server/README.md)：沒有介面的 Fushi 主機，帶 WebUI，手機和電腦都當它的客戶端。配對方式一樣（設定 → 互聯 → 新增 `<host>:38765`，PIN 顯示在它的終端和 WebUI「配對」頁），還能把漫畫整卷 OCR、字幕識別、番劇下載和追更、小說 / 漫畫 / 有聲書下載、AI 下載都丟給它跑，也能託管有聲書音訊庫。

## 常見狀況

- **區域網裝置一直「未發現裝置」**：確認同一個 Wi-Fi、電腦主機服務確實在「執行中」；路由器 AP 隔離 / 訪客網路會擋廣播，改手動填地址。
- **手動填了地址連不上**：埠 38765 有沒有被電腦防火牆攔；`https://` 和 `http://` 有沒有和主機的 TLS 開關對上。
- **切換了主機的 TLS 開關**：已配對裝置要重新配對一次（主機頁上有提示）。
- **遠端影片載入失敗**：對端裝置是不是線上；電腦休眠了主機也就停了。在外面連不上的話，看看主機有沒有填公網地址或開啟 P2P 隧道。
- **想解除某臺裝置**：主機的 **主機服務 → 已配對裝置 → 移除**；客戶端側在「已新增的對端」裡刪掉。
- **「重新配對」**：對端列表裡每臺裝置都有這個按鈕，token 出問題時點一下重走一遍配對即可。
