Fushi 互聯是**區域網裡的裝置直連**：一臺裝置當**主機**（把自己的庫開放出去），其他裝置當**客戶端**連上它。最常見的用法就是電腦當主機——番劇、書、漫畫、9.5 GB 的詞典包、Anki 都在電腦上；手機當客戶端，躺著看、隨手查、制的卡進電腦的 Anki，進度和統計兩邊一起走。

同一臺裝置同一時間只能當主機或客戶端之一。互聯和雲備份（Google Drive / WebDAV…）是兩條獨立通道，可以同時開。

## 準備

- 手機和電腦連**同一個 Wi-Fi / 區域網**（不在同一網路也能配，見下面「不在同一區域網」）。
- 兩邊都裝好 Fushi 並更新到同一個大版本，舊版本配對會提示「對方版本過舊」。
- 電腦端在 Windows / macOS 都可以當主機；手機端 Android / iOS 當客戶端。

## 第 1 步：電腦開主機服務

電腦上：**設定 → Fushi 互聯**

1. 開啟 **啟用互聯**。
2. 進 **主機服務**，開啟 **啟用同步服務**。預設埠 **38765**，新裝置第一次開主機會預設開啟 **互聯加密（HTTPS/TLS）**——留著，後面「制卡到主機的 Anki」「同步主機服務配置」之類的功能要它。
3. 狀態變成「執行中 · 埠 38765」就行了。Windows 第一次會彈防火牆詢問，勾上專用 / 私有網路允許。

主機是被動的一方：它自己不需要點「同步」，一切由客戶端發起。

## 第 2 步：手機配對

手機上：**設定 → Fushi 互聯 → 啟用互聯 → 配對與裝置**

- 下方 **區域網裝置** 列表會自動發現同網路裡開了主機的電腦，**點它**；
- 電腦上彈出「配對請求」，點 **允許**；
- 手機提示「配對成功，已自動填入 token」。完成。

之後「已新增的對端」裡就有這臺電腦，電腦的「已配對裝置」裡也有這臺手機。配對是一次性的，以後兩邊在同一網路就自動連上。

**列表裡沒發現電腦？** 多半是路由器開了 AP 隔離、或者電腦防火牆攔了 mDNS。改成手動新增對端地址：在電腦上看一眼本機區域網 IP（Windows：`ipconfig`；macOS：系統設定 → Wi-Fi → 詳細資訊），在手機上填

```
https://192.168.1.23:38765
```

主機開了 TLS 就用 `https://`，沒開用 `http://`（只寫 `IP:埠` 會按 http 處理）——填反了 Fushi 會直接提示該用哪個。

### 不在同一區域網（Tailscale、公網等）

只要手機能連到電腦的地址（比如兩邊都裝了 [Tailscale](https://tailscale.com/)），手動填地址照樣能配，只是多一道 **PIN**：電腦點「允許」後螢幕上會常駐顯示一個 6 位 PIN，手機上輸入它。PIN 不經過網路傳輸，是防止別人冒充配對的。

第一次連上時手機會記住電腦的證書指紋；以後再連時如果證書變了（電腦重灌過 Fushi），會彈「證書已變更」——確認是自己重灌的，就點「清除已存指紋並重新信任」重新配對。

## 第 3 步：手機上能做什麼

配好之後手機上什麼都不用再設，各處會自動多出來一些東西：

**看電腦上的東西**

- 影片、書、漫畫各自的來源列表裡多一個 **Fushi 互聯** 來源，點進去就是電腦的庫：影片直接流播，書直接讀，漫畫（含電腦上 OCR 過的 mokuro）直接翻。
- 想離線帶走就點 **下載到本機**。
- 「同步」設定裡的 **顯示遠端條目**（預設開）會把電腦有、手機沒有的書和影片顯示成帶雲角標的佔位卡，書架上一眼看到，點了就播 / 下載。

**用電腦的詞典和發音**

- **查詞 → 遠端詞典查詢**：手機本地查不到的詞去電腦上查。手機不裝 9.5 GB 的推薦包，也能查到電腦上裝的所有詞典。
- **管理音訊來源 → Fushi 互聯**：單詞發音從電腦的本地發音庫拿。

**制的卡進電腦的 Anki**

- 手機的 **Fushi 互聯 → 交給 Fushi 互聯服務端** 裡開啟 **制卡到 Fushi 互聯服務端**（制卡設定裡也有同一個開關）：手機上點加號做的卡走電腦，用電腦的牌組和欄位設定，進電腦那個 Anki。手機上不用裝 AnkiDroid / AnkiMobile 也行。
- 漫畫 OCR 引擎也可以選 **交給已配對的 Fushi 互聯服務端來跑**，手機不下任何模型。

**進度和統計自動同步**

- 閱讀 / 觀看進度、閱讀與觀看時長、查詞與制卡計數、收藏的詞和句子，兩邊**雙向合併**（「與已配對裝置共享」裡的兩個開關，預設開）。

**手機往電腦傳**

- **上傳到互聯對端** 裡有書籍 / 詞典 / 有聲書 / 影片四個開關，**預設全關**：想把手機上的東西同步給電腦再勾對應那個。
- **用互聯做備份後端**：把雲備份那條通道也指到電腦上，不用雲盤。

## 電腦當客戶端也可以

角色不是綁死的：家裡桌上型電腦當主機、筆記本當客戶端，筆記本上一樣能流播桌上型電腦的番劇、用它的詞典。只是一臺裝置不能同時既開主機服務又連別的主機——想換角色先把主機服務關掉。

## 沒有電腦常開？用無頭服務端

NAS / 家用伺服器 / VPS 上可以跑 [fushi_server](https://github.com/hajisensai/Fushi/blob/develop/packages/fushi_server/README.md)：沒有介面的 Fushi 主機，帶 WebUI，手機和電腦都當它的客戶端。配對方式一樣（設定 → 互聯 → 新增 `<host>:38765`，PIN 顯示在它的終端和 WebUI「配對」頁），還能把漫畫整卷 OCR、字幕識別、番劇下載和追更都丟給它跑。

## 常見狀況

- **區域網裝置一直「未發現裝置」**：確認同一個 Wi-Fi、電腦主機服務確實在「執行中」；路由器 AP 隔離 / 訪客網路會擋廣播，改手動填地址。
- **手動填了地址連不上**：埠 38765 有沒有被電腦防火牆攔；`https://` 和 `http://` 有沒有和主機的 TLS 開關對上。
- **切換了主機的 TLS 開關**：已配對裝置要重新配對一次（主機頁上有提示）。
- **遠端影片載入失敗**：對端裝置是不是線上、在不在同一網路；電腦休眠了主機也就停了。
- **想解除某臺裝置**：主機的 **主機服務 → 已配對裝置 → 移除**；客戶端側在「已新增的對端」裡刪掉。
- **「重新配對」**：對端列表裡每臺裝置都有這個按鈕，token 出問題時點一下重走一遍配對即可。
