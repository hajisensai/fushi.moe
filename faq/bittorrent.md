## BT 是什么

平时下载是「一台服务器发、你来收」。**BT**（BitTorrent）反过来：**没有服务器，所有正在下这个文件的人互相传**——你下到的每一块数据，马上就可以传给别人；你从几十个人那里各拿一点，拼成完整文件。

几个词：

- **种子（.torrent）/ 磁力链接（magnet:）**：不是文件本身，是文件的「身份证」——文件名、大小、每一块的校验值。有了它才能去找持有这个文件的人。磁力链接就是把这些信息压成一行文字，比 .torrent 文件方便传。
- **做种（seed）**：文件下完了还开着、继续传给别人的人。**做种数**越多，下得越快；做种数为 0 的老资源就下不动了。
- **吸血 / 分享率**：只下不传叫吸血；分享率 = 上传量 ÷ 下载量。BT 靠互相上传才能活。
- **Tracker**：帮你找人的「电话簿」服务器；**DHT** 是不靠 Tracker、节点之间互相打听的方式——两者都开，找到的人最多。
- **索引站**：列出「有哪些种子」的网站，本身不存文件。番剧圈最大的是 **Nyaa**；电影剧集有各种公共索引；**Torznab** 是一种统一的索引接口，Jackett / Prowlarr 这类工具把上百个索引站翻译成它。
- **端口映射（UPnP / NAT-PMP）**：让路由器把外面的连接转给你，别人才能主动连上你；连不上也能下，只是慢一点。

BT 本身只是一种传输协议，传什么内容是另一回事——它下 Linux 镜像和下番剧是同一套东西。

## Fushi 整合了什么

Fushi 不需要你另外开一个下载器，整条链在 app 里：

| 环节 | Fushi 里的东西 |
|---|---|
| 下载引擎 | **内置 libtorrent**（Windows / macOS / Android）；或 **外接 qBittorrent**（连它的 WebUI） |
| 搜索来源 | **Nyaa**（动漫）、**apibay**、**Knaben**（电影与剧集），加自己的 **Torznab 索引器**（Jackett / Prowlarr） |
| 作品识别 | AniList 搜作品、AniDB 确认身份，搜索词按原名 / 别名自动填 |
| 字幕 | 勾「附带字幕」自动去 **Jimaku** 配日语字幕；也接了 OpenSubtitles |
| 入库 | 下载完成 → 整理改名 → 配字幕 → [刮削](/faq/scraping)资料 → 进视频库，全自动 |
| 追更 | **订阅**：每 15 分钟检查一次，新集自动下 |
| 有声书 | 有声书目录的下载也走同一个引擎，下完按素材库自动配对齐文件 |
| 互联 | 订阅和下载可以「运行在主机」——交给电脑或 NAS 上的 fushi_server 跑 |

## 怎么用

### 内置引擎：什么都不用配

底栏 **下载 → 番剧下载**，搜作品名，点 **下载** 就进队列了。第一次会问你要不要 **启用上传 / 做种**——默认关，开了会占上传带宽，但对 BT 网络更友好。

- 可以 **边下边播**：任务开始后先入库，从视频库打开。
- 有磁力链接或 .torrent 文件？**粘贴链接下载** / **选择种子文件**。
- 任务详情里能看节点、Tracker 状态、做种时长。

用法细节（筛生肉、只看 Trusted、合集、订阅）见[番剧是在线看还是下载？](/faq/anime-download)。

### 外接 qBittorrent

已经有一台常开的机器跑着 qBittorrent（NAS 常见），或者平台没有内置引擎（iOS）：

**设置 → 下载 → 引擎与做种**，下载引擎选 **外接 qBittorrent**，填 **qBittorrent WebUI 地址**（比如 `http://192.168.1.10:8080`）、用户名密码，可选一个 **qBittorrent 分类**（Fushi 的任务会打上它，方便在 qB 里分辨）。

qBittorrent 跑在别的机器上时，它看到的路径和你这台机器不一样，要配 **qBittorrent 路径映射**：把 qB 的下载根目录（比如 `/downloads`）映射到本机能访问的位置（比如 `\\nas\downloads` 或挂载的盘符），下完 Fushi 才能找到文件入库。

搜索结果里也可以直接 **推送下载** 交给 qB，其余流程一样。

### 引擎与做种设置

都在 **设置 → 下载 → 引擎与做种**：

- **上传 / 做种**：开关、上传限速、分享率上限、做种时长上限——想回馈就开，到了上限自动停。
- **限速**：下载 / 上传 KB/s；默认**不作用于局域网**（互联对端之间全速）。
- **监听端口**（默认 6881）、**UPnP / NAT-PMP** 端口映射、**DHT**、**本地节点发现（LSD）**：默认都合理，连接数少就检查路由器有没有拦端口。
- **反吸血**：封掉只下不传、伪造进度的客户端。
- **Tracker 订阅**：填一个 Tracker 列表地址，新任务自动加进去，对做种少的老资源有帮助。
- **内存占用上限**、**最大活跃下载 / 做种数**：手机上可以调小。
- **代理**：设置 → 网络代理里，P2P 流量默认**直连**；「走代理」全部经代理（很多代理商禁 BT），「混合」只有 Tracker 请求走代理、节点直连。只对内置引擎生效，外接 qB 在它自己那边配。

### Torznab 索引器

内置的几个来源不够（比如想搜某个私有站或小众索引），**设置 → 服务 → Torznab 索引器 → 添加索引器**：填 Jackett / Prowlarr 给的端点和 API 密钥，可选分类 ID 和优先级。密钥不随备份导出，会经互联同步给已配对设备（可关）。

内置来源被关掉了搜索会提示「本次搜索没有可用的来源」，去 **设置 → 下载 → 外部资源与字幕来源** 重新启用。

## 常见状况

- **下不动 / 速度 0**：先看做种数，0 就换资源；再看路由器有没有拦监听端口、UPnP 有没有开；试着开一下 Tracker 订阅。
- **搜不到**：Nyaa 只有动漫，电影剧集看 apibay / Knaben；连不上索引站就配代理（代理只影响搜索和 Tracker，节点连接看上面）。
- **推送到 qBittorrent 失败**：WebUI 地址、账号密码、qB 有没有开「Web 用户界面」；跨机器的路径映射没配就会下完找不到文件。
- **改名后不做种了**：在 Fushi 里改名 / 移动是通过引擎做的，做种不断；在文件管理器里手动改就断了。
- **iOS**：按 App Store 规定没有搜索和下载功能。
- **本次安装缺少内置引擎运行库**：装的是不完整的包，重装完整安装包或改用外接 qB。
