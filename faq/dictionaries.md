Fushi 认三种词典格式，都是直接导入、不用转换：

- **Yomitan（Yomichan）词典 zip**——浏览器查词生态的通用格式，网上为 Yomitan 整理的辞典库 Fushi 都能用；
- **MDict 的 `.mdx`**——GoldenDict / 欧路 / DictTango 那一大批词典用的格式，带图片和发音的还有一个同名 `.mdd`，一起选上；
- **Lingvo 的 `.dsl`**。

Yomitan 词典的结构化字段最全（音调、词频、变形），MDX 胜在存量大——很多国语辞典、双解辞典只有 MDX 版。

## 推荐包已经给了什么

新手引导里的[推荐包](/faq/pack)（约 9.5 GB）装好之后有：

- **日语单词词典**（日日 / 日中）；
- **音调词典**（查词弹窗里的音调标记）；
- **词频词典**（词条旁的频率角标、[按词频重排新卡](/faq/anki-basics)靠它）；
- **本地发音音频库**（日语 + 英语），查词时点喇叭、制卡时自动带单词发音。

只是学日语看番读书的话，推荐包够用很久，不急着加。

## 自己加词典

**设置 → 词典**，从文件导入（可以多选，后台导入），也可以把 `.zip` / `.mdx` / `.dsl` 文件直接拖进词典页；MDX 词典自带的 CSS 要和词典包一起导。导进来的词典按类别归组——日日 / 日英 / 双语 / 语法 / 词频 / 汉字 / 人名 / 补充——每本可以：

- **排序**：弹窗里释义按这个顺序出现，把最常看的放前面；
- **隐藏**：暂时不用的藏起来，不装载、不占查词时间；
- **折叠**：默认收起，点开才看。

装多少合适？Yomitan 玩家动辄七八十本，但每多一本查词就慢一点、弹窗就长一点。一个够用的组合：

| 类别 | 装几本 | 干什么用 |
|---|---|---|
| 国语辞典（日日） | 1–2 | 主力。学习向的小型辞典释义简单、有振假名；中型辞典收词多 |
| 日中 / 双解 | 1 | 日日看不懂时兜底；越早少看越好 |
| 音调 | 1 | 弹窗里标高低音，跟读靠它 |
| 词频 | 1–2 | 判断一个词值不值得做卡、重排新卡 |
| 文法 | 1 | 查「〜てならない」这类句型，语法书不用翻 |
| 汉字 | 0–1 | 想看笔顺、音训读时加 |

日中双解辞典、物书堂那些商业辞典的电子版都是有版权的，去哪找我不列；Yomitan 社区里公开维护的免费辞典（JMdict 系、频率表、文法辞典、Wikipedia 摘要之类）够搭起这套骨架。手头已经有 MDX 词典（以前给 GoldenDict / 欧路装的）的，直接拖进来就行，不用再找 Yomitan 版。

## 发音从哪来

**设置 → 查词 → 管理音频来源**，可以有好几个来源、按顺序取：

- **本地音频数据库**：推荐包里的发音库就是这种；它和 Yomitan「本地音频服务器」（NHK / 新明解 / jpod / forvo 那套）用**同一种数据库**——已经为 Yomitan 下过那份数据的，「添加本地音频数据库」指向它的 `entries.db` 就能直接用，可以选引用原文件不复制。
- **自定义链接**：任何返回音频的 http(s) 地址，链接里用 `{term}` / `{reading}` 占位。
- **Fushi 互联**：用电脑上的发音库，手机不用装 9.5 GB，见[互联](/faq/interconnect)。

「查词时自动朗读」开着的话，弹窗一出来就播第一个来源的发音。

## 常见状况

- **无法识别的词典格式**：Yomitan 词典要是 zip（里面有 `index.json`，旧版 Yomichan 的也认）；MDX 只选 `.mdx`（和它旁边的 `.mdd`），不要先解压。
- **MDX 词典没有图 / 没有发音**：少选了同名的 `.mdd`，补导一次。
- **查词变慢 / 弹窗太长**：隐藏用不到的词典，或者折叠。
- **同一个词几本辞典重复太多**：把日中放到最后并折叠，先看日日。
- **弹窗里的字体、颜色、布局**：设置 → 查词 里改样式，每本词典可以单独设。
