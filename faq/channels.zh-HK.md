[下載頁](/zh-hk/download)有兩個**渠道**：

| | 正式版 | 除錯版 |
|---|---|---|
| 更新節奏 | 攢一批改動再發，幾週一次 | 每次程式碼合併後自動構建，幾乎每天有新包 |
| 新功能 | 等下一個正式版 | **先在這裡出現**——比如影片源擴充套件、互聯刮削同步，都是先進除錯版 |
| 穩定性 | 經過一輪測試 | 偶爾會撞上剛引入的 bug |
| 適合誰 | 只想安安靜靜看番的 | 想第一時間用新東西、遇到問題願意到 Discord / QQ 群說一聲的 |

## 怎麼換

下載頁頂部把渠道切到「除錯版」，下載對應平臺的包安裝即可；除錯版是每次程式碼合併後自動構建的，版本號帶 `debug` 字樣。換渠道前先在 **設定 → 同步與備份** 裡匯出一份備份——正常情況下資料是接著用的，但除錯版可能已經用上正式版還沒有的新資料格式，萬一要退回正式版，有備份才穩。

## 用除錯版的建議

- 常見問題裡說「目前只在除錯版」的功能，就是還沒進正式版的意思，等下一個正式版釋出會自動帶上。
- 遇到問題先看是不是當天的包：除錯版的 bug 通常第二天就修了，更新一下再試。
- 報 bug 時帶上版本號（設定 → 關於）和復現步驟，去哪報見[反饋](/faq/feedback.zh-HK)。
- 備份不嫌多：設定 → 同步與備份 裡匯出一份，或者開雲備份 / [互聯備份](/faq/interconnect.zh-HK)。
